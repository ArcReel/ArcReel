# 剪映草稿导出 {#jianying-export}

把一集的剪辑时间线导出为剪映（Jianying）草稿，在剪映桌面版中打开后继续精修：调整节奏、字幕样式、转场和配音等。剪映草稿与成片从同一条剪辑时间线生成，截取、片段顺序、原声音量和定格延长都与成片一致。

ArcReel 当前导出的是面向中国大陆版剪映桌面端的草稿格式。CapCut 是剪映的国际版，但属于不同产品；ArcReel 尚未验证导出草稿与 CapCut 的兼容性。

## 前置条件 {#prerequisites}

- 这一集至少有一个已生成的视频
- 本地已安装 **剪映桌面版**（5.x 或 6+）

## 操作步骤 {#steps}

### 1. 找到剪映草稿目录 {#locate-draft-directory}

下载前需要知道本地剪映草稿的存放路径。

**macOS：**
```
/Users/<用户名>/Movies/JianyingPro/User Data/Projects/com.lveditor.draft
```

**Windows：**
```
C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft
```

> **提示**：可在剪映的「设置 → 草稿位置」查看。如果修改过默认路径，请使用实际的草稿目录。

### 2. 打开这一集的剪辑视图 {#open-edit-view}

1. 打开目标项目，进入要导出的集
2. 在集页顶部切换到 **剪辑** 视图

如果这一集还没有剪辑时间线，剪辑视图会显示两个入口：

- **交给 Agent 剪辑**：把剪辑请求填进对话输入框，由 Agent 剪一版
- **新建剪辑时间线**：按脚本直接新建一条，每个视频单元整段使用，片段之间全部硬切

两个入口都要求这一集至少有一个已生成的视频。出片不会自动新建剪辑时间线。

> **提示**：顶栏的 **导出项目** 只用于打包下载整个项目。成片与剪映草稿都在各集的剪辑视图中导出。

### 3. 导出剪映草稿 {#start-export}

1. 在剪辑视图顶部的标签中选中要导出的剪辑时间线
2. 点击 **出片**，打开「出片 · <剪辑时间线名称>」对话框
3. 选择 **剪映草稿**
4. 对话框会显示这条剪辑时间线已有剪映草稿的状态：
   - **已是最新**：可以直接下载，不需要重新导出
   - **已落后于剪辑时间线**：剪辑时间线或素材在导出之后改过；旧草稿仍可下载，重新导出后会被替换
   - **尚未生成**：点击 **导出剪映草稿** 开始导出
5. 导出在后台执行，对话框内显示进度，完成后即可下载

当前剪辑时间线有阻断出片的问题（例如某个视频单元还没有可用视频）时，**出片** 按钮不可点。将鼠标悬停在按钮上可以查看原因，点击旁边的 **查看问题** 可跳到问题列表。

### 4. 填写下载参数并下载 {#export-parameters}

| 参数 | 说明 |
|------|------|
| **草稿目录路径** | 填入第 1 步找到的剪映草稿路径（首次填写后会自动记忆） |
| **剪映版本** | 选择 **剪映 6.0 及以上** 或 **剪映 5.x**，需与本地安装的剪映版本匹配 |

点击 **下载**，浏览器会下载一个 ZIP 文件。草稿目录和剪映版本在下载时才代入，同一份草稿换台电脑下载时重新填写即可。

### 5. 解压到草稿目录 {#unzip-to-draft-directory}

将下载的 ZIP 文件解压到上面填写的剪映草稿目录中。解压后的结构如下：

```
com.lveditor.draft/
├── ... (其他已有草稿)
└── {两位播出位置}_{集标题}_{剪辑时间线名称}/   ← 解压出来的文件夹
    ├── draft_info.json        (剪映 6+) 或 draft_content.json (5.x)
    ├── draft_meta_info.json
    └── assets/
        └── ...                 (视频、音频与定格静帧)
```

文件夹名开头是集在播出顺序中的位置（两位数字，如 `01`）和集标题，集没有标题时用「第 N 集」代替；接着是剪辑时间线名称。带旁白版本的文件夹名另有「_带旁白」后缀。

### 6. 在剪映中打开 {#open-in-jianying}

1. 打开（或重启）剪映桌面版
2. 在「草稿」列表中找到新出现的草稿
3. 双击打开即可在时间线上看到所有剪辑片段

## 导出内容说明 {#export-contents}

剪映草稿按剪辑时间线的修订生成，并与成片使用同一套规则：

- **视频轨**：剪辑片段按剪辑时间线的顺序排列，保留截取、原声音量和定格延长；每个片段使用视频单元当前选用的视频版本
- **字幕轨**：按旁白与台词生成字幕，可在剪映中继续调整样式、位置和时序
- **旁白轨**：只在带旁白版本中出现。TTS 配音项目默认导出带旁白版本，其他项目导出不带旁白版本

手动上传的视频没有生成来源证明，会按原始视频导出，并明确视为“来源不可用”；ArcReel 不自动为它生成 TTS 或字幕。上传的视频本身即成品，改提示词不会让它过期。

含转场或 BGM 的剪辑时间线暂时不能导出剪映草稿，导出时会提示原因。

### 画布尺寸 {#canvas-size}

自动根据项目设置确定：
- 竖屏（9:16）→ 1080×1920
- 横屏（16:9）→ 1920×1080

如项目未设置宽高比，会从首个视频文件自动检测。

## 常见问题 {#troubleshooting}

### 剪映中看不到导出的草稿？ {#draft-not-visible}

- 确认 ZIP 解压到了正确的草稿目录
- 确认解压后的文件夹直接位于草稿目录下（不要多套一层文件夹）
- 尝试重启剪映

### 版本不匹配怎么办？ {#version-mismatch}

下载时选择的剪映版本必须与本地安装版本对应：
- 剪映 6.0 及以上 → 选择 **剪映 6.0 及以上**
- 剪映 5.x → 选择 **剪映 5.x**

如果选错了版本，在对话框中改选正确的版本后重新下载即可，不需要重新导出。

### 出片按钮不可点？ {#render-blocked}

当前剪辑时间线有阻断出片的问题时，**出片** 按钮不可点。将鼠标悬停在按钮上查看原因，例如哪些视频单元还没有可用视频；在问题列表中逐条处理后即可出片。
