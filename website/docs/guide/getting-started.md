# 完整入门教程 {#getting-started}

本教程带你从零开始部署 ArcReel，并完成第一条可预览、可回滚、可导出的 AI 视频。

## 你将完成什么 {#what-you-will-build}

你将创建一个短项目、制作一小段视频，并在剪辑视图中渲染成片或导出剪映草稿。如果你已经部署好 ArcReel，可以直接从[首次配置](#first-time-setup)开始。

## 预计时间与费用 {#time-and-cost}

首次体验建议先用一个短章节或一段剧本试跑几条分镜。生成耗时取决于所选模型与供应商队列；文本、图片、视频和配音调用均可能产生费用。提交前可查看费用预估，结束后在[使用记录](#tasks-and-cost)核对实际用量。

## 1. 准备环境 {#prepare-environment}

### 1.1 系统要求 {#system-requirements}

推荐运行环境：

- Linux
- macOS
- Windows + WSL2
- Docker Desktop

建议准备：

- Docker
- Docker Compose
- 建议从 2 GB 可用内存起步
- 可访问所选模型供应商的网络环境
- 足够的磁盘空间保存图片、视频、项目归档和日志

默认工作流使用远程模型 API，通常不要求本机 GPU。接入本地模型服务时，CPU、GPU 和内存要求由该服务决定。

### 1.2 准备模型凭据 {#prepare-credentials}

ArcReel 中有两类凭据，职责不同。

#### Agent 凭据 {#assistant-credentials}

Agent（智能体）用于驱动项目对话、内容理解、分集规划、脚本规划（含资产识别）和工作流编排。

可使用 Anthropic 官方服务或 ArcReel 支持的兼容服务，并按需配置 Base URL 和模型名称。Agent 只接受 Anthropic Messages 兼容接口，协议要求与外部网关接入见[供应商与模型配置 · Agent 供应商](./providers.md#agent-protocol)。

#### 媒体与文本生成凭据 {#media-and-text-credentials}

为项目准备文本、图片、视频以及可选的旁白配音能力，你可以按需从不同供应商选择模型。打开[供应商与模型配置](./providers.md#capability-matrix)即可查看如何在设置页确认可用模型。

## 2. 部署 ArcReel {#deploy-arcreel}

### 2.1 克隆项目 {#clone-repository}

```bash
git clone https://github.com/ArcReel/ArcReel.git
cd ArcReel
```

### 2.2 使用 SQLite 默认部署 {#deploy-with-sqlite}

默认部署方案适合首次体验、个人创作和轻量级使用。

```bash
cd deploy
cp .env.example .env
```

编辑 `.env`：

```dotenv
AUTH_USERNAME=admin
AUTH_PASSWORD=请设置一个强密码
AUTH_TOKEN_SECRET=请设置一个长期固定的随机密钥
```

`AUTH_TOKEN_SECRET` 可以使用以下命令生成：

```bash
openssl rand -hex 32
```

启动：

```bash
docker compose up -d
```

检查状态：

```bash
docker compose ps
docker compose logs --tail=100 arcreel
curl http://localhost:1241/health
```

健康检查返回成功后，在浏览器打开：

```text
http://localhost:1241
```

> `AUTH_PASSWORD` 留空时，首次启动会自动生成密码并回写到 `.env`。正式使用时仍建议主动设置强密码并妥善保存。

### 2.3 使用 PostgreSQL 生产部署 {#deploy-with-postgresql}

如需长期运行或正式部署，建议改用 PostgreSQL。请先按[生产部署步骤](../ops/deployment.md#postgresql-deployment)完成启动，再回到本页进行首次配置。ArcReel 实例面向相互信任的使用者。

## 3. 完成首次配置 {#first-time-setup}

登录后，建议先完成首次使用引导并打开只读演示项目。它可以帮助你认识项目大厅、工作台、Agent 和设置入口，而不需要先消耗模型额度。

随后进入 **设置** 页面。

### 3.1 配置 Agent {#configure-assistant}

在「设置 → ArcReel Agent」中添加凭证并将其设为生效，按供应商提供的信息填写 API Key、接口地址与模型名称。

### 3.2 配置媒体供应商 {#configure-media-providers}

在「设置 → 供应商」添加需要的生成凭证，再在「默认模型」选择文本、图片和视频模型。请先确认所选视频模型支持你要使用的[生成模式](./workflows.md#video-production-routes)，再创建项目。生成配置与 Agent 凭证分别保存。全局与项目的选择顺序见[配置层级](./providers.md#configuration-layers)。

### 3.3 配置并发和费用 {#configure-concurrency-and-cost}

初次使用时建议先跑少量任务，确认供应商额度、耗时与参考费用符合预期后再扩大批量。如果遇到限流，可参考[供应商故障排查](./providers.md#frequent-rate-limits)检查实例并发数与账号配额限制。

## 4. 创建第一个项目 {#create-first-project}

在项目列表页点击 **新建项目**。

### 4.1 选择项目来源 {#choose-project-source}

#### 小说原文 {#source-novel}

上传一个短章节作为整本源文，再规划要制作的集。也可以把一段完整内容用作一集的原文。

#### 成品剧本 {#source-screenplay}

选择剧情演绎模式，上传已包含角色、场景和台词的原稿。为对应原文选择「剧本」类型，并在内容确认阶段对照原稿核对台词与画外音。

#### 广告或短片 {#source-ad}

选择广告/短片模式后，在项目概览中填写创作灵感与目标总时长。如果需要展示具体商品，先添加商品条目并上传商品原图。

### 4.2 选择创作类型 {#choose-content-mode}

创作类型决定脚本的组织方式，生成模式决定是先出分镜图再生成视频，还是直接使用参考素材生成视频。项目创建后这两项不可更改，选择前建议先查看[模式选择表](./workflows.md#mode-selection-table)。

## 5. 使用 Agent 推进工作流 {#run-workflow-with-assistant}

打开项目工作台右侧的 Agent 面板。先发送一条简短消息确认 Agent 能正常回复。

建议分阶段稳步推进，不要一上来就要求「直接生成全部成片」。

### 5.1 内容分析 {#content-analysis}

在 Agent 对话中说明目标画幅、受众和片长。旁白/解说或剧情演绎项目先在「分集」确认原文和制作范围。广告/短片可从概览中的创作灵感与商品开始。

### 5.2 分集和剧本 {#episodes-and-script}

在「分集」中点击「停止规划」后，可以关闭弹层或离开页面。正在规划的这一段会完成，已规划出的集会保留。重新规划时，点击「停止生成」会保留已生成的候选。之后可以从保留的进度继续。

进入要制作的集。旁白/解说和剧情演绎项目先运行「脚本规划」，再在「内容确认」界面核对分镜时长、台词及本集新增资产，确认无误后点击「确认并继续」转为正式脚本。广告/短片项目会直接生成正式脚本，生成后在工作台检查即可。详细审核要点见[内容结构](./workflows.md#stage-content-structure)。

### 5.3 角色、场景和道具资产 {#character-scene-prop-assets}

在「资产」处理脚本引用的角色、场景和道具，先生成并核对主要资产图。可用已有图片时，也可以上传为资产图。角色造型或商品外观确认后再继续生成。

### 5.4 分镜图 {#storyboard-images}

分镜图生视频先为少量分镜编写视觉提示词并生成分镜图。确认构图和资产外观后再扩大批量。选择参考生视频的项目直接进入[视频片段](#video-clips)。

### 5.5 视频片段 {#video-clips}

先为一个分镜或视频单元试生成视频：分镜图生视频会以选中的分镜图作为起始画面，参考生视频则会使用剧本引用的图片等素材。确认动作、时长和声音符合预期后，再从生成入口提交剩余片段。多宫格分镜和参考图选择见[生成模式](./workflows.md#video-production-routes)。

Agent 回复中的分镜或视频单元链接可以在新标签页打开，也可以复制到地址栏。集页加载后会选中对应单元，并将列表滚动到该单元可见的位置。链接带有时间点时，视频预览会定位到该处。

### 5.6 旁白和 TTS {#narration-and-tts}

旁白/解说项目在项目设置中选择「TTS 配音」后，配置好 TTS 模型、音色与语速。建议先试听或单段生成检查读音，确认无误后再批量生成。若选择「后期配音」，则在导出后自行处理旁白，详见[配音说明](./faq.md#voice-over-support)。

## 6. 查看任务和费用 {#tasks-and-cost}

从工作台顶栏打开「使用记录」，可查看进行中的调用、结束状态、用量与参考费用。项目概览中的费用预估基于当前脚本计算，最终费用以供应商账单为准。

生成失败时先展开错误和相关任务。视频已生成但下载失败时，优先用任务面板提供的「重试下载」。其他故障见[任务状态和恢复](./faq.md#task-states)。

## 7. 剪辑和出片 {#compose-and-export}

### 7.1 剪辑并渲染成片 {#compose-final-video}

视频生成后，在集页顶部切换到 **剪辑** 视图。一集的成片形态由剪辑时间线决定：可以交给 Agent 剪一版，也可以按脚本新建一条剪辑时间线，再在对话中让 Agent 调整。所有剧本布局都使用同一套入口。

点击剪辑视图顶部的 **出片**，在「出片 · <剪辑时间线名称>」对话框中选择 **成片**。已是最新的成片可以直接下载；还没有成片或成片已落后于剪辑时间线时，点击渲染，对话框内会显示进度，完成后即可下载。

对话框中可以选择成片的版本，每种组合是一份独立的成片：

- **旁白版本**：只有 TTS 配音项目可以选择，默认 **带旁白**。如果旁白比所在片段长，系统会按原长度混入成片（既不截短，也不顺延后续旁白），并在问题列表中提示重叠；超出成片末尾的部分会被截断。
- **烧入字幕**：默认勾选。字幕会直接烧录进视频画面，播放时无法关闭，使用随包附带的思源黑体。如果字幕中包含该字体缺少的字符，问题列表会将这些字符逐一列出。

需要背景音乐时，点击剪辑视图 BGM 轨名称旁的上传按钮，上传 MP3、WAV 或 M4A 音频（不超过 100 MB）。上传时 ArcReel 测量一次响度，把每首 BGM 统一到相同的响度水平；几乎无声的音频无法上传。BGM 属于整个项目，各集的剪辑时间线都能使用。上传后，在对话中让 Agent 把 BGM 摆进剪辑时间线；BGM 比时间线短时，Agent 会接着摆下一段。同一时刻只有一首 BGM，超出剪辑时间线末尾的部分会被截掉，并在截断处淡出 1 秒。成片与剪映草稿都会混入 BGM。目前不支持在页面上删除已上传的 BGM。

建议在出片前检查：

- 片段顺序；
- 画面比例；
- 每个片段的实际时长；
- 旁白和画面的对齐；
- 是否需要背景音乐；
- 相邻片段是否需要转场。

预览中的转场可能与导出成片不同。选中带转场的片段时，片段详情会提示以导出效果为准。

### 7.2 导出剪映草稿 {#export-jianying-draft}

如果需要在剪映中继续精修字幕、音轨、转场与节奏，可在同一个出片对话框中选择 **剪映草稿**。详细步骤见 [剪映草稿导出指南](./jianying-export.md)。

顶栏的 **导出项目** 只用于打包下载整个项目，不导出成片或剪映草稿。

## 8. 第一次项目的完成标准 {#first-project-checklist}

不要以“所有素材都生成过”为完成标准。建议至少达到：

- 角色设计已审核；
- 关键道具和场景参考已审核；
- 分镜结构合理；
- 相邻分镜主体和运动方向可衔接；
- 视频片段没有明显崩坏；
- 费用在预期范围内；
- 至少一集可以成功出片；
- 项目完成一次备份或归档。
