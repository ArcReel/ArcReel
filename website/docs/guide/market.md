# 市场 {#market}

市场让你从一个或多个市场源浏览别人已经适配好的调用端点，确认后一键安装为本地自定义调用端点，之后还能跟随上游更新。本页介绍如何管理市场源、安装前要检查什么，以及更新与卸载。调用端点本身的概念与测试方法见[供应商与模型配置](./providers.md#custom-providers)。

## 1. 市场与市场源是什么 {#what-is-market}

- **市场**：设置页 Configuration 组里的「市场」小节，位于「调用端点」之后。它只靠你本地的 ArcReel 和市场源仓库运转，不依赖 ArcReel 方运营的中心服务，也不需要注册账号。首期唯一的市场条目类型是调用端点。
- **市场源**：一个 GitHub 仓库（或等价的 `https://` 直链），仓库根目录的索引文件 `arcreel-market.json` 列出其中的市场条目。ArcReel 由后端代你抓取索引和定义，只访问 raw 文件地址。
- **官方市场源**：[`ArcReel/arcreel-market`](https://github.com/ArcReel/arcreel-market) 随版预置，可以禁用、改名和排序，但不能删除。除它之外，你自行添加的都是第三方市场源。
- **市场条目**：索引中的一项可安装内容，载荷是一份调用端点定义。条目在所属市场源内以 slug 唯一标识；不同市场源里的同名 slug 不代表同一份定义，会各自并列显示。

市场是用户功能：内嵌 Agent 不会替你浏览或安装市场条目。

## 2. 管理市场源 {#manage-sources}

在「市场」小节头部点击「管理市场源」打开弹窗。列表顺序就是条目网格的展示顺序，每行显示状态、显示名（官方源带「官方」徽标）、地址和上次成功刷新时间。

### 2.1 添加市场源 {#add-source}

在弹窗底部的「市场源地址」中填写以下任一形式，然后点击「添加」：

| 形式 | 示例 |
|---|---|
| `owner/repo` | `ArcReel/arcreel-market` |
| `owner/repo@ref`（分支、标签或提交） | `ArcReel/arcreel-market@main` |
| GitHub 仓库地址（可带 `/tree/<ref>`） | `https://github.com/ArcReel/arcreel-market` |
| 以 `arcreel-market.json` 结尾的 `https://` 直链 | `https://raw.githubusercontent.com/ArcReel/arcreel-market/main/arcreel-market.json` |

GitHub 形态不写 ref 时跟随仓库默认分支。不接受 `http://`、本地路径和 `git@` 地址；已登记的市场源不能重复添加。

添加时会立即抓取一次索引，抓取失败或索引无效时直接拒绝添加并给出原因。显示名默认取索引中的名称，添加后可以在列表中直接修改。

添加表单下方固定显示第三方提示：

> **添加第三方市场源**
>
> 该市场源由第三方维护，其中的内容未经 ArcReel 审核。安装前请先确认来源可信。

市场条目决定了你的 API Key 会被发往哪里，只添加你信任的市场源。

### 2.2 启用、禁用、排序、刷新与删除 {#source-actions}

- **启用开关**：禁用的市场源保留登记，但其条目不再显示；从该源安装的端点会显示「市场中不可用」，端点本身继续可用。
- **排序**：拖拽行首抓手，或聚焦抓手后按上下方向键。
- **改名**：直接编辑行内的显示名。
- **刷新**：单个源点击刷新图标；小节头部的「全部刷新」会并行刷新所有已启用的市场源。
- **删除**：点击删除图标。官方市场源的删除按钮不可用，需要时改为禁用。
- **主页**：索引提供主页时，行内会显示外链。

打开「市场」小节时，距上次刷新超过 1 小时的已启用市场源会在后台自动刷新，页面先显示缓存内容。刷新失败时保留上一次成功的快照，网格上方的横幅会逐源列出状态、错误原因和快照时间。市场源状态包括：「正常」「尚未刷新」「无法访问」「索引无效」「需升级 ArcReel」。

### 2.3 GitHub raw 代理前缀 {#github-proxy-prefix}

如果部署环境无法直连 `raw.githubusercontent.com`，在设置页「模型选择」小节中找到「GitHub raw 代理前缀」。非空时，ArcReel 会把前缀拼接到所有 `raw.githubusercontent.com` 地址前，覆盖索引、定义和图标的抓取；留空即直连。

该设置是全局单值，默认为空，ArcReel 不预置任何代理地址。设置后请求失败时不会回退直连。代理服务能看到经过的请求，请只使用你信任的代理。

## 3. 浏览与安装 {#browse-and-install}

也可以从「调用端点」小节点击「从市场获取」进入「市场」小节。

### 3.1 浏览条目 {#browse-entries}

条目网格按市场源顺序平铺全部已启用源的条目，不按源分组。每张卡片显示图标、名称、`作者 · v版本`、描述、所属市场源，以及右下角的主按钮（「安装」「更新」或「已安装」）。

- **搜索**：按名称、作者和描述过滤。
- **条目类型**：当前只有「调用端点」可用，「提示词」「风格模板」标注为即将推出。
- **按来源筛选**：每个已启用的市场源一个筛选项，可多选，默认全选。
- **仅已安装**：只显示已经安装的条目。

条目要求更高的应用版本时，整张卡片变暗，按钮不可用，并标注「需要 ArcReel ≥ x.y.z」。升级 ArcReel 后才能安装。

### 3.2 确认安装 {#confirm-install}

点击卡片或「安装」打开安装确认弹窗。安装前请逐项检查：

1. **头部**：名称、作者、版本、所属市场源和主页。条目来自第三方市场源时，会显示「该来源未经 ArcReel 审核」。
2. **Validation（校验结果）**：定义的错误与警告。索引与定义不一致、校验有错误，或应用版本低于「需要 ArcReel ≥ x.y.z」时，「确认安装」不可用，弹窗会显示原因。
3. **Hints（配置建议）**：作者建议的接口地址和模型。它们只是建议，用于之后新建供应商时参考。
4. **Trust（信任信息）**：这是安装前最重要的一块。
   - **凭证发往**：定义中 `submit.url` 的原文，即提交请求时 API Key 随请求发往的地址；
   - **轮询地址**：定义中 `poll.url` 的原文；
   - **凭证携带方式（auth 原文）**：定义中 `auth` 的 JSON 原文，默认展开，说明 API Key 以何种方式、放在请求的哪个位置发送。

   确认这些地址属于你要使用的供应商或网关，再继续安装。

如果本地已经有同作者、同名的端点，弹窗会列出这些端点供你选择：

- **覆盖**：选中某个已有端点，用市场定义原地覆盖它。端点的键和已挂接的模型保持不变，此后该端点跟随这个市场条目。
- **新建副本**：另建一个新的调用端点，已有端点不受影响。
- **已从 X 安装**：该端点已经跟随另一个市场源的条目，只展示来源，不能选择覆盖。
- 不想安装时点击底栏的「取消」。

点击「确认安装」后，成功提示下方提供「用此端点新建供应商」和「打开端点」两个入口。

只有经市场安装的端点才算「已安装」。从本地文件导入的定义不与市场条目绑定，即使作者和名称相同也不算已安装。

## 4. 更新与本地修改 {#updates-and-local-changes}

已安装的端点带有两轴状态徽标，出现在市场卡片、安装确认弹窗和「调用端点」小节的端点详情头部：

| 市场状态 | 含义 |
|---|---|
| 已安装 | 安装的版本与市场源当前版本一致 |
| 可更新 | 市场源中的版本与安装时的版本不同（包括作者回退了版本） |
| 市场中不可用 | 市场源已禁用或删除，或条目已从索引中移除；只出现在端点详情中，端点本身仍可使用 |

与市场状态独立的另一轴是「已修改」：当前定义与安装时的定义不同即显示。已安装的端点可以像其他自定义调用端点一样直接编辑，编辑不会解除与市场条目的绑定。

端点详情头部的元信息行显示「来自市场 <市场源显示名>」。市场源被禁用时追加「（来源已禁用）」；被删除时改为显示市场源地址的规范形式，并追加「（来源已删除）」。

### 4.1 执行更新 {#run-update}

状态为「可更新」时，点击市场卡片上的「更新」，或端点详情动作行中的「更新」，打开同一个确认弹窗：

- 头部显示「已安装 vX → 市场 vY」，校验结果、配置建议和信任信息与安装时相同，更新前同样需要重新检查凭证发往的地址；
- 端点带「已修改」徽标，或详情中有未保存的修改时，主按钮上方会提示「你的本地修改会被覆盖」，可以先点击「先导出当前定义」保存一份；
- 点击「更新到 vY」后，市场定义原地覆盖本地定义，端点的键和已挂接的模型不变，之后新提交的任务立即使用新定义。

更新会丢弃你对该端点的本地修改。如果想长期保留自己的版本，先导出当前定义，再通过「调用端点」小节的「导入」以「导入为副本」的方式导入：导入的端点不跟随市场条目。

## 5. 卸载 {#uninstall}

卸载就是删除这个调用端点，以下两个入口效果相同：

- 在已安装条目的安装确认弹窗底栏点击「卸载」，点击后立即执行；
- 在「调用端点」小节的端点详情中点击「删除」，确认后执行。

端点与它的安装记录一起被删除。仍有模型使用该端点时无法删除，界面会列出引用它的模型，先把这些模型改用其他端点再卸载。

禁用或删除市场源不会卸载已安装的端点。

## 6. 投稿与开自己的市场源 {#contribute-and-host}

投稿流程、内容准则和开设自己的市场源，以官方市场源仓库的文档为准：

- [官方市场源 README](https://github.com/ArcReel/arcreel-market#readme)：浏览条目与开自己的市场源；
- [官方市场源 CONTRIBUTING](https://github.com/ArcReel/arcreel-market/blob/main/CONTRIBUTING.md)：投稿流程与内容准则。

「市场」小节末尾的「阅读投稿指引」，以及端点详情中「导出」旁的「投稿到市场」，也都指向上述 CONTRIBUTING。
