# 供应商与模型配置 {#providers}

ArcReel 把 Agent（智能体）、文本生成、图像生成、视频生成和 TTS 分成独立能力。你可以为不同项目和媒体类型选择不同供应商，而不必把整条生产链绑定到一家平台。

## 1. 先区分两类供应商 {#two-provider-categories}

### 1.1 Agent 供应商 {#assistant-providers}

在「设置 → ArcReel Agent」添加并启用一个 Agent 供应商凭证，用于项目对话、内容分析、脚本规划和任务编排。Agent 基于 Claude Agent SDK，可以接 Anthropic 官方服务或兼容网关。

每个 Agent 供应商对应一个 Anthropic 兼容网关，同一时间只有一个生效。供应商按会话连接确定：连接建立时读取当时生效的凭证，切换生效供应商后新发起的会话使用新供应商；仍在运行的会话保持原连接，网络中断后重连常驻会话也不更换供应商；但 actor 进程退出或服务重启后再恢复的会话属于新连接，会使用恢复时生效的供应商。

#### 模型、供应商与接口协议 {#agent-protocol}

模型、供应商与接口协议是三件事：模型是模型厂商发布的生成能力，供应商是提供模型调用服务的一方，接口协议是双方约定的请求与响应格式。同一个模型可以由多家供应商提供，同一家供应商也可以对不同能力使用不同协议。

内置 Agent 只按 Anthropic Messages 协议调用：它向「API 代理地址 + `/v1/messages`」发请求，并要求收到 Anthropic 协议格式的响应。普通文本任务支持 OpenAI 兼容等多种协议，不代表 Agent 也能使用同一地址——只提供 OpenAI Chat Completions 兼容接口的供应商，不能直接当作 Agent 供应商使用。

#### 接入兼容网关 {#agent-gateway}

优先选择直接提供 Anthropic Messages 兼容入口的供应商。添加 Agent 供应商时，预设列表已经收录 Anthropic 官方与 GLM、DeepSeek、Kimi、MiniMax、Xiaomi MiMo、火山方舟 Coding Plan 和 Agent Plan 等兼容入口：选中预设后地址自动填好，只需填入密钥和默认模型。

要接入的兼容入口不在预设中时，选择「自定义配置」自行填写：

- 「API 代理地址」填兼容入口的网关地址。输入框下方实时显示 Agent 实际请求的完整 Messages 地址；从供应商文档复制整条 `…/v1/messages` 端点时可以直接粘贴，保存时末尾这一段会被去掉。地址须是 http(s) 绝对地址，不能带查询参数、锚点或用户名密码。
- 「密钥」填该入口要求的凭证。
- 「默认模型」填该入口实际提供的模型名。「高级模型路由」可以把不同能力等级与子智能体分流到其他模型；每个档位按顺序取值：先用凭证上该档位填写的值，留空时回退到对应的旧系统设置（如 Haiku 档位的 `anthropic_default_haiku_model`），仍为空再按供应商类型处理——非官方供应商使用默认模型名，Anthropic 官方预设交给 Claude Code 决定。
- 填好地址与密钥后可用「获取模型列表」从入口的 `/v1/models` 读取它报告的模型填充候选，仅供参考：入口不实现这个接口、或列表与实际可用模型不一致时，按其文档手动填写模型名。

保存前用「测试连接」验证：它向 Agent 实际请求的 Messages 地址发一次最小请求（上限 30 秒），并检查响应是否为 Anthropic 协议格式。返回成功但格式不符时提示「该端点返回 OpenAI 兼容协议」，说明地址指向了其他协议的入口；模型相关提示优先核对模型名；限流与超时按提示稍后重试，超时说明服务可达、可直接保存后重试；其余情况对照状态码与原始错误信息核对密钥与地址。

#### 接入外部协议转换网关 {#agent-external-gateway}

供应商不提供 Anthropic Messages 兼容入口、但你仍想用它驱动 Agent 时，可以自行运行一个提供该入口的外部协议转换网关，把其他协议的模型服务包装成兼容接口，再按上文「自定义配置」接入。常见方案与其官方文档入口：

- LiteLLM：[Claude Agent SDK with LiteLLM](https://docs.litellm.ai/docs/tutorials/claude_agent_sdk)
- Claude Code Router：[项目说明](https://github.com/musistudio/claude-code-router/blob/main/README.md)

以 LiteLLM 为例：

1. 按 LiteLLM 文档编写 `config.yaml` 并启动代理：启动前必须先设置 master key，可以用环境变量 `LITELLM_MASTER_KEY`，也可以在 `config.yaml` 中设置 `general_settings.master_key`；当前版本的 LiteLLM 在 master key 未设置、为空或是已知不安全值时拒绝启动。代理默认监听 `http://localhost:4000`，它就是对外提供的 Anthropic 兼容入口地址；
2. 在「设置 → ArcReel Agent」添加 Agent 供应商，选择「自定义配置」；
3. 「API 代理地址」填 `http://localhost:4000`（须是 ArcReel 服务实际可达的地址：容器部署时 `localhost` 指容器自身，应填网关所在主机对 ArcReel 可达的地址）；
4. 「密钥」填第 1 步设置的 master key；改用虚拟密钥（virtual key）时，代理还须配置 PostgreSQL 数据库（`DATABASE_URL` 或 `general_settings.database_url`），并通过 `/key/generate` 创建密钥；
5. 「默认模型」填 `config.yaml` 中 `model_list` 暴露的 `model_name`；
6. 「测试连接」通过后保存，并将该供应商设为生效。

外部协议转换网关是可选方案，不是 ArcReel 的内置功能：兼容性取决于模型、供应商与网关版本（包括流式响应与工具调用等细节），ArcReel 未对这些组合做端到端验证，不作为官方支持的接入方式。网关的搭建、升级与模型支持范围以各项目官方文档为准；接入后先用「测试连接」和几轮真实对话确认可用，再投入项目使用。

### 1.2 媒体与文本供应商 {#media-and-text-providers}

在「设置 → 供应商」配置文本、图片、视频和语音合成（TTS）用的凭证，再在「默认模型」选择每种用途所需的模型。生成模型使用各自的供应商配置，独立于 Agent 供应商。

## 2. 查看可用的供应商与模型 {#capability-matrix}

在「设置 → 供应商」打开内置供应商详情，按文本、图片、视频或音频查看模型。列表显示当前版本开放的模型、价格摘要与状态。同一厂商有多个接入渠道时，左侧合并为一个入口并在详情页顶部提供渠道切换标签：在「Google Gemini」下切换「AI Studio」与「Vertex AI」，在「火山方舟」下切换「按量付费」与「Agent Plan」；各渠道的密钥、倍率与模型列表独立维护。要接入私有网关、本地模型服务或内置供应商未提供的协议，请看[自定义供应商](#custom-providers)。

方舟 Agent Plan 优先使用订阅额度，ArcReel 默认不估算调用费用。如果在方舟控制台为支持的模型开启超额后付费，套餐额度用尽后，方舟会对超额调用另行出账，实际费用以方舟账单为准。参见方舟的[超额后付费管理说明](https://docs.volcengine.com/docs/ark/agent-plan-personal-over-quota-postpaid-management?lang=zh)。使用限制以火山方舟[服务条款](https://docs.volcengine.com/docs/ark/subscription-package-service-terms-conditions?lang=zh)为准：限于最终用户交互式调用（未经明确支持或授权不得用于应用后端、批量处理、自动化或定时任务等非交互式调用），文本模型仅限用于认可的 AI 工具，API Key 仅限本人单席位使用，个人版含数据授权，视频生成需 Large 及以上套餐。

## 3. 配置层级 {#configuration-layers}

ArcReel 会按用途选择生成模型：优先采用项目设置中的选择，其次是「设置 → 默认模型」中的全局配置。没有设置默认模型时，符合用途的自定义供应商默认模型可以用作回退。没有可用模型时，请先开通供应商并补齐设置。

内置供应商的「推荐」标签标示建议使用的模型。为某个内置供应商添加第一条凭证时，ArcReel 会自动用它的推荐模型填补尚未设置的全局默认模型；已有的全局默认模型不会被覆盖，由你自行调整。推荐变化时，「默认模型」可提示切换或保留当前选择。

从旧版本升级时，ArcReel 会尽量保留升级前实际使用的模型。旧设置无法还原时，需要重新选择，见[项目结构迁移](../ops/deployment.md#project-schema-migrations)。

### 3.1 启用与停用模型 {#enable-models}

内置供应商的详情页按文本、图片、视频、音频分组列出它的全部模型，每行显示模型名称、模型 ID 与价格摘要，即将下线、已下线或调用会记为「未定价」的模型另有标记，即将下线的标记写明关停日期。用「全部 / 已启用」切换显示范围。关停日期当天（按 UTC 日期）起模型视为已下线：它仍留在列表里，但即使手动启用过，也不再出现在任何模型候选里，也不再作为供应商的推荐模型；已选了它的地方调用时报错，写明下线日期与推荐替代模型。关停日期之前已经提交给厂商的视频任务不受影响：服务重启后续跑时照常取回结果。关停日期之后才提交的任务照常报错，包括关停前已排队、关停后才轮到提交的任务。

需要更新版本 ArcReel 才能调用的模型同样列在这里，排在所在分组末尾，标注「需要 ArcReel ≥ 版本号」。当前版本调用不了它：开关不可用，也不能打开模型设置；它不出现在任何模型候选里，也不作为供应商的推荐模型。升级到所需版本后，它和其他模型一样可以启用。

全局设置与项目设置里，默认模型、按用途指定的模型与配音模型选中了即将下线或已下线的模型时，下拉下方会写明下线日期与推荐替代模型。推荐替代模型在同一个供应商下、并且可以用在这一处时，提示旁有「切换到 …」按钮：点击只改这一处的选择，保存后生效。推荐替代模型在别的供应商下、已停用或不适用于这一处时，只显示它的名称。ArcReel 不会替你换模型。选中的模型已不在供应商的模型清单里时，下拉下方同样有提示：ArcReel 收到过它的下线信息的，写明它已下线以及推荐替代模型（如果有）；没有收到过的，提示它已不可用，需要重新选择。

按用途指定模型时，下拉只能选中可以用在这一处的模型。默认模型的候选里有、但不能用在这一处的模型列在下拉末尾，写明原因，例如「不接受首帧」「不接受参考图」，不能选中。停用和已下线的模型不在其中。

- 关掉一个模型的开关即停用，立即生效：停用的模型不再出现在全局与项目的默认模型候选里，供应商的推荐模型被停用时，不会写进默认模型，也不会提示切换到它；
- 已经在设置或项目里选中的模型停用后照常可用，需要换掉时到默认模型设置里另选；
- 旧版本中隐藏的 Agnes 旧模型升级后显示为停用，需要时可以重新启用。

价格摘要是各计费项的单价范围，按分辨率、时长等分档的模型显示最低到最高档。实际费用还要乘以供应商的倍率，倍率在同一页上方设置。

### 3.2 模型设置 {#model-settings}

在供应商详情点选模型，检查右侧的「供应商设置」与「模型信息」。两处修改使用同一个保存栏。

| 要改什么 | 在哪里改 |
|---|---|
| 中转站只允许部分时长、参考图或分辨率 | 在「这个供应商支持的参数」修改当前供应商的限制。修改会整项替换，可以恢复原值。 |
| 目录里记载的模型参数或价格有误 | 修改「模型信息」。使用同一条目的供应商都受影响。 |
| 中转站换了模型名称，ArcReel 没找到对应条目 | 在「模型信息」点「关联其他模型」。找不到条目时，可以手动填写。 |
| 更换协议、修改请求路径或调整价格倍率 | 在「供应商设置」改调用端点、请求地址或倍率。可修改的字段取决于供应商与端点。 |

**检查当前供应商的能力**

界面显示当前能用的参数。一般取模型目录与调用端点都支持的范围，数量上限取较小值。「未收录」表示 ArcReel 没有该限制的数据。

调用端点是否支持音轨开关由协议决定。对可编辑的视频模型，可以指定模型成片有声或无声；参考生视频默认继承主路径，也可以单独设置。可灵 v3 Omni 的多图主体参考生视频固定无声。ComfyUI 端点固定时长时，可选时长只读。

提交前的参考费用与使用记录采用相同的音频计费档。Gemini AI Studio 始终按有声档计费，即使项目关闭音频或模型标记为无声。其他供应商按本次请求的预期成片音轨计费。

模型没有对应的目录条目、且沿用供应商默认参数时，视频模型能否接受纯文本或首帧、能接受多少张参考图，都取决于调用端点。尾帧和参考音频默认不可用。图片模型能否用于文生图或图生图取决于调用端点，画质选项则需要有对应的目录条目。参考图上限为 0 的图片模型不可用于图生图。ComfyUI 以 [workflow 节点绑定](./comfyui.md#bindings)判断能力。

官方收录的供应商模型支持启用或停用，它的供应商参数由官方维护；自定义供应商的模型，以及在内置供应商下自行添加的模型，则可以修改调用端点和参数。更换视频端点会清理不兼容的能力覆盖和原有请求路径覆盖，保存后请重新核对新端点配置。自定义供应商模型改模型 ID 后，ArcReel 会同步全局和项目引用。内置供应商下自行添加的模型改 ID 后，请核对原来的选择。

**维护共享模型信息**

可修改显示名称、能力、时长、分辨率、最大输出长度和价格。价格按计费项、币种与条件维护。缺少适用条件或单价时，会在使用记录里显示「未定价」。

保存对官方数据的修改后，这个条目使用自定义值，官方同步不覆盖。可逐项采用官方值，也可一次「恢复官方数据」。手工创建的条目后续被官方收录时，可「改用官方数据」。恢复或改用官方数据会立即覆盖当前自定义内容，确认前请核对受影响的供应商。

手动关联优先于按模型名查找。点「解除关联」恢复自动对应。关联和手动填写随底部保存栏生效。

### 3.3 添加模型与获取模型 {#add-models}

模型列表上方提供「添加模型」与「获取模型」两个入口，内置供应商与自定义供应商均可使用。

「添加模型」可以搜索模型名称，或直接输入模型 ID，并按媒体类型筛选：

- 「未启用的模型」：只在内置供应商下出现，列出停用的官方收录模型，选中即启用；
- 「按模型 ID 添加」：按输入的模型 ID 添加。媒体类型先按模型目录对应，对应不上时按模型名称推断，筛选了媒体类型时按所选类型；
- 「模型目录」：从模型目录选一个模型添加，这个模型的价格与模型信息都按所选条目计。已在列表里的条目标为「已添加」；内置供应商已收录这个模型时（API 模型名可能与目录里的名字不同），选中即启用收录的那个模型。

添加完成后会自动打开新模型的设置面板，方便你继续调整调用端点等配置。

升级前已提交的内置供应商视频任务在完成前，请勿更改该模型的调用端点。旧任务未记录端点标识，更换端点可能导致续跑失败，且系统不会重新提交生成。

「获取模型」调用供应商的模型列表接口，只列出还没有添加的模型，已添加的只显示数量。结果分两组：

- 「已识别」：对应上模型目录中的已知模型，默认勾选；
- 「未识别」：默认不勾选。名字能对应上模型目录中的条目的，行里显示对应的模型名，添加后按它计价；对应不上条目、或条目没有价格的，行里提示调用费用会记为「未定价」。可以为每一行点「对应模型」从模型目录选一个，添加后按所选模型计价。

自定义供应商的每一行另有调用端点下拉，默认值按模型名称推断，选了对应模型时改按它的媒体类型推断。获取失败时显示失败原因，可以检查接口地址与密钥后重试。

内置供应商中，AI Studio、Vertex AI、OpenAI、Grok、阿里百炼、MiniMax 与 Agnes 支持获取模型，需要先添加密钥。供应商返回的模型 ID 必须与官方收录模型的 API 模型名完全一致才算「已识别」。供应商列出某个模型，不代表当前账号或地区一定能调用它；同样，没有列出的官方收录模型也照常保留在列表里。

## 4. 选模型并验证样片 {#six-selection-dimensions}

1. 在「这个供应商支持的参数」确认创作流程所需的输入。分镜图生视频需要模型接收首帧，参考生视频需要模型接收参考图。
2. 用同一个短分镜试跑候选模型。检查角色与商品外观、动作、声音和交付分辨率，再决定是否在项目里替换默认模型。
3. 通过[使用记录](#cost-tracking)比较生成及返工的用量与参考费用。参考费用可能没有计入外部订阅和超额费用，账号可用性、合规条款或账单请到供应商处核对。

## 5. 图像供应商配置 {#image-providers}

图像能力主要用于：

- 角色设计；
- 场景和道具设计；
- 商品标准参考图；
- 单个分镜；
- 多宫格分镜；
- 风格分析和图像编辑。

选择时重点关注：

- 多参考图支持；
- 角色和商品身份保持；
- 文字和 Logo 表现；
- 目标比例和分辨率；
- 图像编辑能力；
- 失败时返回的错误信息。

建议：

- 角色资产图尽量使用背景简单、主体完整的构图；
- 商品参考图优先使用真实素材和多角度输入；
- 普通分镜不必全部使用最高成本模型；
- 先固定角色和风格，再批量生成。

在项目设置的「模型」分页和创建项目向导里，图片模型下方可以选择分辨率。文生图和图生图使用不同模型时，可以按各自支持的档位分别设置分辨率。两者使用同一模型时，共用一个分辨率设置。文生图模型支持画质参数时，还可以设置「画质」，与分辨率分别选择；画质选「自动（按分辨率档位）」时，由分辨率档位决定画质。不支持画质参数的模型不显示这一项。

已保存的分辨率或画质不在当前模型的可选值中时，例如模型不再提供某个分辨率档位，设置页会在对应字段下方提示。生成时仍按已保存的值请求，可能被供应商拒绝；点提示旁的按钮可以恢复默认分辨率或自动画质。

## 6. 视频供应商配置 {#video-providers}

视频能力可能覆盖：

- 文生视频；
- 图生视频；
- 参考生视频；
- 首尾帧；
- 视频延展；
- 原生音频；
- 固定种子；
- 不同时长和分辨率。

选择前确认：

- 当前模型支持的输入类型；
- 参考图数量限制；
- 单次时长；
- 横竖屏支持；
- 是否会生成有声视频；
- 任务查询和取消能力；
- 失败是否计费；
- 内容审核规则。

不要假设所有视频模型支持相同参数。ArcReel 会统一上层工作流，但供应商特有能力仍然存在差异。

## 8. TTS 配置 {#tts-providers}

ArcReel 的旁白能力可以使用阿里百炼 Qwen TTS 与 qwen-audio TTS、MiniMax 语音、Gemini TTS（AI Studio、Vertex）、Grok TTS、火山方舟 Agent Plan 的豆包语音合成模型 2.0 或兼容的 TTS 接口。

在全局设置和项目设置里选定 TTS 模型后，旁白音色输入框会列出这个模型可选的常用音色。只有能按官方文档确认音色适用于这个模型时才会列出：自定义的型号名、中转站的别名、官方音色列表没有写到的型号，以及走 OpenAI 兼容接口但不是直连 OpenAI 官方地址的模型，都不列音色，也不会借用同一调用端点下其他模型的音色。没有列表不代表模型不能指定音色。列表之外的音色（例如复刻音色）照供应商文档填写音色 ID，已保存的音色不会因为没有列表而被清空或改写。

阿里百炼语音分为两个调用端点：「阿里百炼（语音合成）」调用 Qwen TTS（`qwen3-tts` 等），「阿里百炼（qwen-audio 语音合成）」调用 qwen-audio TTS（`qwen-audio-3.0-tts`、`qwen-audio-3.1-tts` 系列）。两个端点的音色不通用，qwen-audio 的各个模型也只能使用各自的音色，完整列表见百炼[音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。qwen-audio 端点支持配音语速，范围 0.5～2.0，超出范围时按最近的边界值提交。添加模型时，名称含 `qwen-audio` 的模型预填 qwen-audio 端点，其余百炼语音模型预填 Qwen TTS 端点，在[模型设置](#model-settings)里可以修改。

ArcReel 保存百炼配音前会修正 WAV 头中的流式长度占位值。推断音频长度时，文件尾部识别出的 RIFF 块会保留在音频数据之外，包括零长度的 `JUNK` 和 `PAD ` 填充块。无法安全修复的 WAV 会导致配音任务失败，且不会因此再次提交合成请求。

Grok TTS 的配音语速范围是 0.7～1.5。超出范围时合成任务在提交前失败，不产生费用，也不会自动改成边界值，需要在设置里调整或清空配音语速。

火山方舟 Agent Plan 的语音合成使用已配置的 Agent Plan 专属 API Key，不需要另外填写 AK/SK，调用的是套餐内的专属语音接口。套餐未开通语音合成、并发已用尽、音色未授权，或套餐额度已用尽且没有开启超额后付费时，合成任务失败并显示上游错误码。ArcReel 不会改用按量付费的语音接口；如果在方舟控制台开启了[超额后付费](https://docs.volcengine.com/docs/ark/agent-plan-personal-over-quota-postpaid-management?lang=zh)，月额度用尽后的调用会照常完成，超出部分由方舟按后付费出账，以方舟账单为准。音色列表只列出「豆包语音合成模型 2.0」的常用中文音色，其他 2.0 音色按官方[音色列表](https://docs.volcengine.com/docs/6561/1257544)填写音色 ID，1.0 音色不能使用。配音语速范围是 0.5～2.0，超出范围时合成任务在提交前失败，不产生费用。使用记录里的字符数取接口回报的计费字符数，接口未回报时按提交文本的字符数统计。

配置后先验证：

- 中文和英文发音；
- 人名、地名和专有名词；
- 数字和单位；
- 语速；
- 情绪；
- 单段最大长度；
- 输出音频格式。

批量生成前，先试听一段包含典型专有名词的文本。

## 9. 自定义供应商 {#custom-providers}

在「设置 → 供应商」添加自定义供应商，填写接口地址、凭证与模型发现协议。从供应商获取模型或手动添加，再在[模型设置](#model-settings)里核对媒体类型、模型 ID 和调用端点。模型发现协议用于列出模型和检查连通性。实际生成使用各模型挂接的调用端点。

优先选供应商明确支持的调用端点。私有网关仅兼容部分协议时，用[预览请求与测试连接](#custom-endpoint-tests)验证准备使用的输入，例如参考图、首尾帧和参考音频。测试连接会真实生成并可能计费。

**选择或适配调用端点**

- **OpenRouter 图片**：为 OpenRouter 图像模型选择「OpenRouter 图片」，以便用同一个端点进行文生图与图生图。
- **火山方舟**：Seedream 区分「Seedream (1K)」与「Seedream (2K)」。Seedance 按 1.x、2.0 或 2.5 选择对应端点。模型 ID 没写明代际时，例如方舟推理接入点 ID，请手动核对。
- **Gemini 视频**：Gemini Omni 使用 Interactions API，与 Veo 调用端点分开。对兼容 Interactions API 的服务，可用「Gemini 视频 (Omni)」并分别覆盖提交与轮询路径。Vertex AI 的调用端点只用于内置供应商。
- **可灵视频**：按模型支持的 API 版本选择端点。新版 API 使用「Kling 视频（新版 API，固定有声）」，需要 API Key。
- **ComfyUI**：导入 API 格式 workflow，再为供应商模型选择该端点，见[接入 ComfyUI workflow](./comfyui.md)。可用输入取决于节点绑定。
- **其他接口**：先到[市场](./market.md)查找已有端点。供应商使用 JSON 请求与响应时，也可以在「调用端点」中从示例模板新建图片或视频声明式定义。

**能力与请求地址**

在「这个供应商支持的参数」检查生效能力。对于接入同一模型的多家供应商，只有某一家有额外限制时，修改这一家的参数。缺少模型目录条目时可[手动关联或填写模型信息](#model-settings)。

中转站沿用官方协议、只改了请求路径时，在「模型设置 → 请求地址」修改对应请求。修改后的路径直接拼到接口地址后。路径只能使用这一行原有的占位符，如 `{{ model }}`、`{{ task_id }}`。提供查询字符串时会替换原查询参数，需要保留的参数也要写进去。

测试连接和真实生成使用修改后的路径。获取模型和连通性检查仍使用供应商接口地址。切换调用端点会重置路径修改；视频提交后改了路径，重启后的续跑可能失败，ArcReel 不会重新提交。

### 9.1 端点测试三模式 {#custom-endpoint-tests}

在设置页的调用端点详情中，可以按风险从低到高使用三种测试模式：

- **验证响应**：粘贴供应商的提交、查询或取件响应样本，检查每条取值路径、状态映射和错误字段；不向供应商发送请求，也不产生费用。图片定义的 base64 路径命中时，只显示取到的图片字节数，不回显整串。
- **预览请求**：用示例参数渲染将要发送的 URL、方法、请求头和请求体，供你对照供应商文档；同样不向供应商发送请求，也不产生费用。
- **测试连接**：真实提交一次生成并跟踪到终态。界面以计费徽章标明这一模式会产生一次调用费用；必需素材端点须先上传对应的首帧、尾帧、参考图或参考音频。

测试连接进行中可以取消。取消会停止 ArcReel 对这次测试的跟踪并清除本地结果，但供应商的远端任务可能仍会继续，已经发生的费用仍会记入使用记录。成功的视频产物直接在结果卡中播放，图片产物直接显示；调用编号可跳转到使用记录。终态结果与产物由服务端保留 24 小时，之后不再可查。

### 9.2 用 Agent 适配自定义调用端点 {#custom-endpoint-agent}

如果视频或图片供应商采用 JSON 提交任务、再以任务 ID 轮询 JSON 结果，可以把适配工作交给 Claude Code 等外部 Agent。签名鉴权、发往供应商的 multipart 请求或按素材切换路由不在声明式定义首期范围内。

安装公开 skill：

```bash
npx skills add ArcReel/skills
```

在安装列表中同时选择 `setup-arcreel-skills` 与 `adapt-custom-endpoint`。也可以直接[查看或下载同一份适配 skill 源文件](https://github.com/ArcReel/ArcReel/tree/main/agent_runtime_profile/.claude/skills/adapt-custom-endpoint)。

先使用 `setup-arcreel-skills` skill 完成 ArcReel MCP 接入；它会在当前工作区持久化同一连接，供 `adapt-custom-endpoint` 的本地脚本跨会话复用。

然后让 Agent 读取供应商文档并使用该 skill。它会按「写定义 → 共享 validator 校验 → 离线验证响应 → 预览请求 → 测试连接 → 保存」执行；定义格式和薄 HTTP 脚本随 skill 一起下载，适配过程不新增 MCP 或 SDK tool。`验证响应` 与 `预览请求` 不向供应商发请求；`测试连接` 会真实生成并可能计费，Agent 必须先取得你的明确同意。检测到同作者、同名的定义时，另存副本可以直接执行，覆盖既有端点必须先取得你的明确同意。

必需素材通过 CLI 的 `--start-image`、`--end-image`、可重复的 `--reference-images` 和可重复的 `--reference-audio-files` 传入；这些参数使用与设置页相同的 multipart 字段。

## 10. 多 API Key {#multiple-api-keys}

同一供应商可以配置多个 API Key，并选择当前激活 Key。

使用多个 Key 时应遵守供应商条款。它适合：

- 不同项目或客户隔离；
- 测试和生产隔离；
- 额度管理；
- 凭据轮换。

它不应被用于规避供应商限流、风控或服务条款。

密钥轮换建议：

1. 新增新 Key；
2. 用小任务验证；
3. 切换激活；
4. 观察错误率；
5. 删除或停用旧 Key；
6. 更新密钥管理记录。

## 12. 费用追踪 {#cost-tracking}

在「使用记录」按项目、供应商、模型和媒体类型查看调用的结果、用量与参考费用。失败调用也可能产生费用。不同币种分别统计，最终金额以供应商账单为准。

参考生视频调用的详情按提交顺序列出参考音频，并显示音频在项目中的来源路径。

ArcReel 从模型目录取单价，按可取得的用量和请求条件计量，例如 token、缓存、字符数、图片或参考图张数、分辨率、画质、有声与否和视频时长。缺少计量信息或没有适用单价时，调用会显示「未定价」。通过声明式端点或 ComfyUI 调用端点出图时，目录默认档可能与实际输出的分辨率不同。

- **生成费用**按目录单价乘以供应商倍率。自定义供应商的模型和在内置供应商下自己添加的模型还可设置模型倍率，两级倍率相乘。模型未对应到目录条目时，可以[关联模型或补充模型信息](#model-settings)。
- **倍率更新**在生成调用结算时生效，已经记下的费用不重算。倍率通常默认为 1。方舟 Agent Plan 和 ComfyUI 的默认倍率为 0，表示 ArcReel 默认不估算费用。方舟超额调用可能账单另计，见[方舟 Agent Plan](#capability-matrix)。
- **Agent 费用**按实际调用模型的 token 用量计价，每轮对话中每个模型各记一条，包含子智能体的请求。会话使用开始或恢复时的生效 Agent 供应商、倍率与模型绑定。未定价的档位可在 Agent 供应商详情中从模型目录选择条目。解除绑定后恢复按实际模型名对应。

## 13. 故障排查 {#troubleshooting}

### 连通性检查失败 {#connection-test-failed}

检查：

- API Key；
- Base URL；
- 模型名称；
- 网络代理；
- TLS 证书；
- 账号地区；
- 账户余额或额度。

### 文本能用，图片或视频不能用 {#text-works-media-fails}

同一供应商的不同媒体能力可能：

- 使用不同端点；
- 需要单独开通；
- 使用不同模型名称；
- 有不同地区限制；
- 需要异步任务查询。

### 频繁限流 {#frequent-rate-limits}

降低：

- RPM；
- 并发任务数；
- 单次批量分镜数。

同时确认是否有多个 ArcReel 实例共享同一 Key。

### 费用明显高于预估 {#cost-higher-than-expected}

检查：

- 是否重复提交任务；
- 是否发生多次重试；
- 是否切换了更高价模型；
- 实际视频时长是否增加；
- 是否生成了原生音频；
- 价格表是否需要更新；
- 供应商是否调整计费方式。
