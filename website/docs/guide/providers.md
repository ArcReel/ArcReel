# 供应商与模型配置 {#providers}

ArcReel 把 Agent（智能体）、文本生成、图像生成、视频生成和 TTS 分成独立能力。你可以为不同项目和媒体类型选择不同供应商，而不必把整条生产链绑定到一家平台。

## 1. 先区分两类供应商 {#two-provider-categories}

### 1.1 Agent 供应商 {#assistant-providers}

Agent 负责：

- 理解用户意图；
- 分析小说和剧本；
- 规划每集脚本时识别角色、场景和道具；
- 规划分集；
- 规范化剧本；
- 编排后续生成任务。

ArcReel 的 Agent Runtime 基于 Claude Agent SDK，支持 Anthropic 官方服务以及项目所支持的兼容配置。

Agent 供应商不一定承担实际图片和视频生成。

### 1.2 媒体与文本供应商 {#media-and-text-providers}

这些供应商负责：

- 结构化文本生成；
- 图片生成和编辑；
- 视频生成；
- TTS。

一个完整项目可以采用组合策略，例如：

- Agent：高质量推理模型；
- 文本结构化：速度更快的文本模型；
- 角色设计：高质量图像模型；
- 批量分镜：低成本图像模型；
- 样片视频：快速视频模型；
- 最终关键分镜：高质量视频模型；
- 旁白：独立 TTS 供应商。

| 火山方舟 | ✅ | ✅ | ✅ | — | 国内网络环境下的文本、图像和视频 |
| Grok | ✅ | ✅ | ✅ | — | 文本、图像和视频生成 |
| OpenAI | ✅ | ✅ | — | — | 文本和图像 |
| Vidu | — | ✅ | ✅ | — | 图像、图生视频和参考生视频 |
| 阿里百炼 | ✅ | ✅ | ✅ | ✅ | 文本、图像、视频和旁白配音（TTS） |

## 3. 配置层级 {#configuration-layers}

ArcReel 支持：

1. **全局默认供应商**；
2. **项目级供应商覆盖**；
3. **预置供应商内多个 API Key**（自定义供应商每个配置使用一个 API Key）；
4. **不同媒体类型使用不同供应商**。

优先级通常为：

```text
项目级配置 > 全局默认配置
```

适合项目级覆盖的情况：

- 某个项目需要特定画风；
- 某个客户要求固定供应商；
- 不同项目预算差异明显；
- 需要比较两个供应商的效果；
- 某个地区只能访问部分服务。

### 3.1 启用与停用模型 {#enable-models}

预置供应商的详情页按文本、图片、视频、音频分组列出它的全部模型，每行显示模型名称、模型 ID 与价格摘要，
已下架或调用会记为「未定价」的模型另有标记。用「全部 / 已启用」切换显示范围。

- 关掉一个模型的开关即停用，立即生效：停用的模型不再出现在全局与项目的默认模型候选里，供应商的默认模型被停用时，
  自动选择会跳过它；
- 已经在设置或项目里选中的模型停用后照常可用，需要换掉时到默认模型设置里另选；
- 旧版本中隐藏的 Agnes 旧模型升级后显示为停用，需要时可以重新启用。

价格摘要是各计费项的单价范围，按分辨率、时长等分档的模型显示最低到最高档。实际费用还要乘以供应商的倍率，倍率在同一页上方设置。

### 3.2 模型设置 {#model-settings}

点开模型列表里的一行，右侧打开这个模型的设置，预置供应商与自定义供应商相同。上半部分「供应商设置」只作用于当前供应商，
下半部分「模型信息」是这个模型在模型目录里的记录，所有使用这个模型的供应商共用。两部分共用底部的保存栏，在同一次保存里生效，
关闭前有未保存的修改会先询问。

- 官方收录的内置模型只能启用或停用，其他设置由官方维护；
- 自定义供应商的模型，以及在内置供应商下自己添加的模型，另有：
  - 「模型 ID」：调用时发给供应商的模型名称，改了以后，设置和项目里选中这个模型的地方需要重新选择；
  - 「倍率」：这个模型的倍率，供应商倍率不是 1 时会提示两者相乘后的最终倍率；
  - 「这个供应商支持的参数」：供应商实际支持的参数与模型信息不同时在这里修改，比如中转站只开放部分时长或分辨率，
    或者不支持尾帧。每一项显示原值，点「修改」后整项替换，点「恢复」回到原值。对应不上已知模型的模型也可以修改，
    原值是 ArcReel 按模型名称推断的结果。视频模型的「按分辨率限定时长」跟在「可选时长」后面，删掉某个分辨率时，
    它的时长限定一并删除；
  - 「从『供应商名』移除」：移除前先确认，设置或项目正在使用这个模型时，确认框会列出它们，移除后需要为它们改选其他模型；
- 自定义供应商的模型另有「设为默认」「调用端点」「请求地址」与默认分辨率。更换调用端点后，修改过的请求地址恢复默认，
  「这个供应商支持的参数」里的修改也随之清除，保存后再按新的调用端点修改。

「模型信息」可以修改显示名称、能力、可选时长、按分辨率限定时长、分辨率与最大输出长度；模型厂商、官方模型名、类型与别名只能查看。
顶部一行说明这些信息由谁维护：

- 官方维护：随官方数据更新。保存修改前，保存栏上方会提示「保存后，这个模型改用你修改的信息，不再随官方更新」；
- 你改过：官方数据更新时不会覆盖你的修改，模型列表里这一行标「已修改」。改过的字段下方显示官方值，点「采用」换回这一项的官方值；
  点「恢复官方数据」并确认后，丢弃全部修改、回到官方数据，立即生效，不经保存栏，也无法撤销；
- 官方没有、由你填写：模型目录里原本没有这个模型的信息，也不会随官方更新。日后官方数据收录了同一个模型时，
  这里出现「改用官方数据」：确认后，你填写的信息被官方数据替换，立即生效，也无法撤销。

中转站给模型改了名、按名字对应不上模型目录时，自己添加的模型和自定义供应商的模型可以手动指定对应的模型。
下半部分右上角的「关联其他模型」打开模型目录选择面板（默认只列同类型的模型），选中后能力、价格和调用通道的能力都按这个模型取得；
关联后不再按名字对应，点「解除关联」改回。目录里找不到的模型，点「手动填写」填写模型厂商、模型名称、显示名称、类型与能力，
视频模型的可选时长按模型名称预填；价格可以不填，不填时调用费用记为未定价。目录里已有同名的模型时不能填写，请直接选择它。
这些改动都只改草稿，随底部的保存栏一起生效，取消则不留下任何内容。

「模型信息」的「价格」一段按计费项分卡片编辑，也可以在这里补上目录里没有的价格：

- 先选币种（美元或人民币），价目表以模型厂商主站的币种标价，不做汇率换算；
- 「添加计费项」只列出这个类型的模型可用的计费项，如文本的「输入」「缓存命中」「输出」，视频的「视频时长」。不分条件的计费项一行单价；
  点「按条件分价」加上分辨率、有声、服务档（标准、Flex、Fast）等条件后，每档一行「条件 → 单价」，点条件标签可以改取值，「添加一档」增加一行。
  条件加上后不能移除，要换条件就删除整张卡片重新添加；
- 请求没有给出某个条件时，按卡片下方「请求没有给出条件时按」一行的取值计价，没有设置的条件取不到价格，这次调用记为未定价；
- 参考图这类计费项可以「添加免费额度」，每次请求超出额度的部分才计费；
- 不填价格时，调用费用记为未定价。条目被改过时，价格下方显示官方价格，点「采用官方价格」换回；币种与官方不同时不显示对比。

其他供应商也使用这个模型时，「模型信息」会列出它们：修改与恢复官方数据都会对这些供应商一起生效。
只想表达某个供应商与模型信息不同（如中转站只开放部分时长）时，改「这个供应商支持的参数」，不要改模型信息。

自定义供应商的名称、接口地址、密钥、并发上限与供应商倍率仍在供应商详情里统一保存，保存时不会改动模型列表里的模型。

使用记录的详情里，点模型名可以直接打开这个模型的设置；供应商已删除或是 Agent 凭证时只显示模型名。

### 3.3 添加模型与获取模型 {#add-models}

模型列表上方有「添加模型」与「获取模型」两个入口，预置供应商与自定义供应商都有。

「添加模型」可以搜索模型名称，或直接输入模型 ID，并按媒体类型筛选：

- 「未启用的模型」：只在预置供应商下出现，列出停用的官方收录模型，选中即启用；
- 「按模型 ID 添加」：按输入的模型 ID 添加。媒体类型先按模型目录对应，对应不上时按模型名称推断，
  筛选了媒体类型时按所选类型；
- 「模型目录」：从模型目录选一个模型添加，这个模型的价格与模型信息都按所选条目计。已在列表里的条目标为「已添加」；
  预置供应商已收录这个模型时（API 模型名可能与目录里的名字不同），选中即启用收录的那个模型。

添加后会直接打开新模型的设置，可以接着修改调用端点等设置。

「获取模型」调用供应商的模型列表接口，只列出还没有添加的模型，已添加的只显示数量。结果分两组：

- 「已识别」：对应上模型目录中的已知模型，默认勾选；
- 「未识别」：默认不勾选。名字能对应上模型目录中的条目的，行里显示对应的模型名，添加后按它计价；对应不上条目、
  或条目没有价格的，行里提示调用费用会记为「未定价」。可以为每一行点「对应模型」从模型目录选一个，添加后按所选模型计价。

自定义供应商的每一行另有调用端点下拉，默认值按模型名称推断，选了对应模型时改按它的媒体类型推断。获取失败时显示失败原因，
可以检查接口地址与密钥后重试。

预置供应商中，AI Studio、Vertex AI、OpenAI、Grok、阿里百炼、MiniMax 与 Agnes 支持获取模型，需要先添加密钥。
供应商返回的模型 ID 必须与官方收录模型的 API 模型名完全一致才算「已识别」。供应商列出某个模型，不代表当前账号或地区一定能调用它；
同样，没有列出的官方收录模型也照常保留在列表里。

## 4. 选择供应商的六个维度 {#six-selection-dimensions}

不要只看单次生成效果。

### 4.1 质量 {#dimension-quality}

关注：

- 角色身份保持；
- 商品结构保持；
- 画面构图；
- 动作自然度；
- 文本遵循；
- 长镜头稳定性；
- 输出分辨率。

### 4.2 可控性 {#dimension-controllability}

关注是否支持：

- 多参考图；
- 首尾帧；
- 负面提示词；
- 固定种子；
- 视频延展；
- 参考生视频；
- 原生音频；
- 结构化输出。

### 4.3 可靠性 {#dimension-reliability}

关注：

- API 成功率；
- 排队时间；
- 限流行为；
- 超时；
- 任务查询；
- 幂等性；
- 失败后是否可安全重试。

### 4.4 成本 {#dimension-cost}

比较时应使用同一个完整分镜目标，而不是只比较单价。

总成本可能包括：

- 文本 Token；
- 角色、场景和道具图片；
- 分镜图片；
- 视频秒数；
- 失败重试；
- TTS；
- 因质量问题产生的返工。

### 4.5 速度 {#dimension-speed}

区分：

- API 响应时间；
- 排队时间；
- 实际生成时间；
- 高峰期波动；
- 批量任务并发能力。

### 4.6 合规和可用地区 {#dimension-compliance-and-region}

确认：

- 账号所在地区；
- API 是否在部署地区可用；
- 内容政策；
- 数据处理要求；
- 商业使用条款；
- 生成内容标记要求。

## 5. 推荐的分层策略 {#tiered-strategies}

### 5.1 经济型验证 {#strategy-budget}

用于：

- 新项目试跑；
- 提示词验证；
- 分镜数量确认；
- 分镜动作方向测试。

策略：

- 少量内容；
- 快速文本模型；
- 低成本分镜模型；
- 快速视频档位；
- 严格限制批量数量。

### 5.2 平衡型生产 {#strategy-balanced}

用于：

- 常规批量内容；
- 已验证的角色和风格；
- 需要稳定吞吐。

策略：

- 关键资产使用高质量模型；
- 普通分镜使用平衡模型；
- 视频按分镜重要度分层；
- 为失败重试保留预算。

### 5.3 高质量交付 {#strategy-premium}

用于：

- 关键剧情；
- 封面分镜；
- 商品特写；
- 品牌交付；
- 需要更高分辨率的成片。

策略：

- 高质量参考图；
- 更严格的分镜审核；
- 先做低成本预演；
- 只对确认后的分镜使用高成本模型；
- 保留人工后期。

## 6. 图像供应商配置 {#image-providers}

图像能力主要用于：

- 角色设计；
- 场景和道具设计；
- 商品标准参考图；
- 单个分镜；
- 多宫格分镜；
- 风格分析和图像编辑。

选择时重点关注：

- 多参考图支持；
- 角色和商品身份保持；
- 文字和 Logo 表现；
- 目标比例和分辨率；
- 图像编辑能力；
- 失败时返回的错误信息。

建议：

- 角色资产图尽量使用背景简单、主体完整的构图；
- 商品参考图优先使用真实素材和多角度输入；
- 普通分镜不必全部使用最高成本模型；
- 先固定角色和风格，再批量生成。

## 7. 视频供应商配置 {#video-providers}

视频能力可能覆盖：

- 文生视频；
- 图生视频；
- 参考生视频；
- 首尾帧；
- 视频延展；
- 原生音频；
- 固定种子；
- 不同时长和分辨率。

选择前确认：

- 当前模型支持的输入类型；
- 参考图数量限制；
- 单次时长；
- 横竖屏支持；
- 是否会生成有声视频；
- 任务查询和取消能力；
- 失败是否计费；
- 内容审核规则。

不要假设所有视频模型支持相同参数。ArcReel 会统一上层工作流，但供应商特有能力仍然存在差异。

## 8. 文本供应商配置 {#text-providers}

文本能力用于：

- 结构化剧本；
- 提示词生成；
- 多模态理解；
- 费用预估中的文本调用；
- 自定义辅助任务。

关注：

- JSON 或结构化输出稳定性；
- 长上下文；
- 中文表现；
- 视觉理解；
- 速度；
- Token 价格；
- 限流。

高推理模型不一定适合所有任务。可把复杂内容分析和普通结构化转换分给不同模型。

## 9. TTS 配置 {#tts-providers}

ArcReel 的旁白能力可以使用阿里百炼 Qwen TTS、MiniMax 语音、Gemini TTS（AI Studio、Vertex）或兼容的 TTS 接口。

配置后先验证：

- 中文和英文发音；
- 人名、地名和专有名词；
- 数字和单位；
- 语速；
- 情绪；
- 单段最大长度；
- 输出音频格式。

批量生成前，先试听一段包含典型专有名词的文本。

## 10. 自定义供应商 {#custom-providers}

ArcReel 可以接入 OpenAI 兼容或 Google 兼容服务。典型用途：

- 自建 API 网关；
- 企业统一密钥管理；
- 私有模型服务；
- 本地 Ollama 或 vLLM 周边服务；
- 第三方兼容平台。

一般配置包括：

- 名称；
- Base URL；
- API Key；
- 模型名称；
- 媒体类型；
- 可选的供应商特有参数。

模型发现协议只决定 ArcReel 使用哪类模型列表接口；每个模型实际如何调用，由它绑定的调用端点决定。ArcReel 可以按模型名称推断媒体类型和调用端点，但兼容协议不代表所有能力和参数都可用，添加后可以在[模型设置](#model-settings)里调整，也应逐项验证：

1. 文本连通性；
2. 结构化输出；
3. 图片生成；
4. 视频任务创建；
5. 视频任务查询；
6. TTS；
7. 错误码和限流行为。

模型名称会按模型目录对应已知模型：忽略大小写，忽略最后一个 `/` 之前的命名空间，点号视同连字符。对应上的模型，可选时长、分辨率、最大输出长度等信息和价格都取自模型目录；对应不上的模型照常可用，视频的可选时长按模型名称推断，费用记为「未定价」。

视频模型的首尾帧、参考图和参考音频由调用端点按模型名称认定：模型名称能对应到模型目录中的已知模型时，按该模型的官方名称和别名认定。调用端点认不出的视频模型只能用于文生视频和首帧生成，尾帧、参考图和参考音频不可用。图片模型能否用于文生图和图生图，取模型目录的记录与调用端点支持范围都满足的部分；对应不上已知模型时，按调用端点的支持范围。

通过 OpenRouter 接入图片模型时，在[模型设置](#model-settings)里把调用端点改为「OpenRouter 图片」。OpenRouter 不提供 OpenAI 的 `/images/edits` 接口，挂在「OpenAI 图片」上的模型无法图生图；「OpenRouter 图片」的文生图与图生图都走 `/images`，比例、清晰度和参考图上限按 OpenRouter 对该模型声明的参数确定。参考图多于该模型的上限时，只发送前面的参考图，并在任务结果中提示；任一张参考图读取失败时，生成直接报错，不会少带参考图继续生成。

需要的调用端点如果已经有人适配过，可以从[市场](./market.md)直接安装，不必自己编写定义。

供应商以 JSON 提交任务、再用任务 ID 轮询 JSON 结果时，可以在「调用端点」分区点击「新建端点」，自己编写声明式定义。

声明式定义对视频与图片供应商都适用：定义写 `"media_type": "image"` 即为图片定义，不写即为视频定义。图片定义挂到自定义供应商的图片模型后，可用于分镜图与资产图生成；声明了图生图能力的图片定义还可用于图片编辑。

新建时可以在「示例模板」中选择视频或图片的「提交 + 轮询」模板作为起点，选择模板会替换当前草稿。

自建 ComfyUI 可以直接导入 API 格式 workflow，并把提示词、素材、尺寸、时长与产物映射到节点；完整步骤与运行限制见[接入 ComfyUI workflow](./comfyui.md)。

中转站沿用官方协议、只改了路径（加前缀、改版本段或换路径名）时，可以在[模型设置](#model-settings)里修改「请求地址」。调用端点发出的每条请求各占一行，接口地址部分灰显，点击路径即可修改：按 Enter 或点击别处保存，按 Esc 取消。修改后的路径直接接在供应商填写的接口地址之后，不再自动补 `/v1` 或剥去版本段。只想去掉自动补上或剥去的部分时，点开路径不作修改，直接按 Enter。路径中只能使用这条请求本身已有的占位符，例如 `{{ model }}`、`{{ task_id }}`。路径带 `?` 查询参数时，会整体替换原请求的查询参数；原请求中需要保留的参数（例如 Gemini 下载地址的 `alt=media`）要一并写进修改后的路径。

测试连接和真实生成都按修改后的地址发出，获取模型和连通性检查仍按接口地址发出。更换调用端点后，修改过的请求地址会恢复默认。视频任务提交后又修改了请求地址时，服务重启后的续跑会直接失败，不会重新提交。模型设置里没有「请求地址」一栏的调用端点不支持修改。

### 10.1 端点测试三模式 {#custom-endpoint-tests}

在设置页的调用端点详情中，可以按风险从低到高使用三种测试模式：

- **验证响应**：粘贴供应商的提交、查询或取件响应样本，检查每条取值路径、状态映射和错误字段；
  不向供应商发送请求，也不产生费用。图片定义的 base64 路径命中时，只显示取到的图片字节数，
  不回显整串。
- **预览请求**：用示例参数渲染将要发送的 URL、方法、请求头和请求体，供你对照供应商文档；
  同样不向供应商发送请求，也不产生费用。
- **测试连接**：真实提交一次生成并跟踪到终态。界面以计费徽章标明这一模式会产生一次调用费用；
  必需素材端点须先上传对应的首帧、尾帧、参考图或参考音频。

测试连接进行中可以取消。取消会停止 ArcReel 对这次测试的跟踪并清除本地结果，但供应商的远端任务
可能仍会继续，已经发生的费用仍会记入账本。成功的视频产物直接在结果卡中播放，图片产物直接
显示；调用编号可跳转到费用账本。终态结果与产物由服务端保留 24 小时，之后不再可查。

### 10.2 用 Agent 适配自定义调用端点 {#custom-endpoint-agent}

视频或图片供应商采用 JSON 提交任务、再用任务 ID 轮询 JSON 结果时，可以把适配交给 Claude Code 等
外部 Agent。签名鉴权、发往供应商的 multipart 请求或按素材切换路由不在声明式定义首期范围内。

安装公开 skill：

```bash
npx skills add ArcReel/skills
```

在安装列表中同时选择 `setup-arcreel-skills` 与 `adapt-custom-endpoint`。也可以直接[查看或下载同一份适配 skill 源文件](https://github.com/ArcReel/ArcReel/tree/main/agent_runtime_profile/.claude/skills/adapt-custom-endpoint)。

先使用 `setup-arcreel-skills` skill 完成 ArcReel MCP 接入；它会在当前工作区持久化同一连接，供
`adapt-custom-endpoint` 的本地脚本跨会话复用。

然后让 Agent 读取供应商文档并使用该 skill。它会按「写定义 → 共享 validator 校验 → 离线验证
响应 → 预览请求 → 测试连接 → 保存」执行；定义格式和薄 HTTP 脚本随 skill 一起下载，适配过程不新增
MCP 或 SDK tool。`验证响应` 与 `预览请求` 不向供应商发请求；`测试连接` 会真实生成并可能计费，
Agent 必须先取得你的明确同意。检测到同作者、同名的定义时，另存副本可以直接执行，覆盖既有端点必须先
取得你的明确同意。

必需素材通过 CLI 的 `--start-image`、`--end-image`、可重复的 `--reference-images` 和可重复的
`--reference-audio-files` 传入；这些参数使用与设置页相同的 multipart 字段。

## 11. 多 API Key {#multiple-api-keys}

同一供应商可以配置多个 API Key，并选择当前激活 Key。

使用多个 Key 时应遵守供应商条款。它适合：

- 不同项目或客户隔离；
- 测试和生产隔离；
- 额度管理；
- 凭据轮换。

它不应被用于规避供应商限流、风控或服务条款。

密钥轮换建议：

1. 新增新 Key；
2. 用小任务验证；
3. 切换激活；
4. 观察错误率；
5. 删除或停用旧 Key；
6. 更新密钥管理记录。

## 12. 费用追踪 {#cost-tracking}

ArcReel 可以按供应商和媒体类型记录费用，但需要注意：

- 不同供应商使用不同计费单位；
- 不同币种不应直接混为一个未经说明的总数；
- 供应商价格可能调整；
- 某些失败任务也可能产生费用；
- 实际账单以供应商结算为准。

内置供应商的文本、配音、图片与视频调用，费用按模型的官方价格计算：

- 缓存命中与缓存写入按各自的单价计，不按普通输入计；
- 按输入长度分档的模型，按单次请求的输入总量（含缓存）落档，整个请求用同一档的单价；
- 官方按「汉字计 2」计价的配音模型，每个汉字按 2 个字符计；
- 图片按实际发给供应商的分辨率、质量档落档；请求里没有带分辨率时，按供应商的默认档计；
- 官方对参考图另行收费的图片模型（如超出免费张数的参考图），参考图按张计入；
- 视频按实际生成的秒数，以及发给供应商的分辨率、是否有声与时长档计；Vidu 的参考生视频按它自己的单价计；
- 方舟 Seedance 按视频 token 计费：结算取供应商回报的 token 数，提交前预估按官方公式（宽 × 高 × 帧率 × 秒数 / 1024）换算，
  画面比例交给供应商自适应时算不出 token 数，预估记为「未定价」；
- 查不到适用单价的调用记为「未定价」，不按其他模型或其他档的价格估算。

自定义供应商的模型不单独填价格。模型名称能对应到模型目录中的已知模型时，按这个模型的官方价格计费，规则与内置供应商相同；
对应不上时，这个模型的调用记为「未定价」。设置页的模型列表会显示每个模型对应到的已知模型，对应不上的显示「未定价」。

每个供应商可以设置一个倍率，乘在这个供应商全部调用的费用上，用来表达充值折扣或中转站价差。
自定义供应商的模型和在内置供应商下自己添加的模型还可以再设一个倍率，最终费用 = 官方价格 × 供应商倍率 × 模型倍率。例如中转站整体按官方价的
八折收费，把供应商倍率设为 0.8；其中某个模型另按官方价的 1.5 倍收费，把这个模型的倍率设为 1.875（0.8 × 1.875 = 1.5）。
倍率默认是 1；方舟 Agent Plan 按订阅计费，ComfyUI 供应商跑在你自己的机器上，这两类倍率默认是 0，不计算费用。修改倍率只影响之后的调用，
已经记下的费用不会重算。

Agent 会话的费用按同一套模型目录计算，不采用 Claude Agent SDK 回报的费用：

- 每次模型请求按自己的 token 用量与输入总量计价，子智能体的请求一并计入；
- 每轮对话中用到的每个模型各记一条，模型名是实际调用的模型；
- 模型名对应不到模型目录中的已知模型时，照常记下 token，费用记为「未定价」；
- 压缩上下文等在消息流里看不到的调用，按 SDK 回报的累计用量补齐；恢复会话后的第一轮没有可比较的基准，这类调用不计入。

每个 Agent 供应商可以设置一个倍率，乘在经这个供应商的全部 Agent 调用的费用上，默认是 1。按订阅计费的网关可以把倍率设为 0，不计算费用。会话按开始（或恢复）时生效的 Agent 供应商计费，倍率与下文手动选择的模型也取那一刻的设置。会话进行中切换生效的供应商、修改倍率或手动选择的模型，都不影响已经开始的会话，之后开始（或恢复）的会话才按新设置计费。已经记下的费用不会重算。

设置页的 Agent 供应商列表会列出主模型与 Haiku、Sonnet、Opus、子智能体四个档位实际调用的模型名，以及每个档位是否已定价、对应到模型目录中的哪个模型。对应不上的档位显示「未定价」，这个档位的调用会记为「未定价」。Anthropic 官方预设留空的档位由 Claude Code 决定调用哪个模型，费用按实际调用的模型名计算。

未定价的档位可以点「选择模型」，从模型目录里手动选一个模型，之后这个档位的调用按所选模型计价；点「解除绑定」回到按模型名自动对应。手动选择只保存在这个 Agent 供应商上，不修改模型目录里的条目，也不影响条目的官方更新。所选模型之后从目录下架时，档位回到按模型名对应，并提示「所选模型已下架」，此时仍可以解除绑定。

建议把 ArcReel 费用追踪用于：

- 项目预算；
- 分镜成本比较；
- 模型选择；
- 异常调用发现；
- 预估与实际偏差分析。

它不替代供应商官方账单。

## 13. 故障排查 {#troubleshooting}

### 连通性检查失败 {#connection-test-failed}

检查：

- API Key；
- Base URL；
- 模型名称；
- 网络代理；
- TLS 证书；
- 账号地区；
- 账户余额或额度。

### 文本能用，图片或视频不能用 {#text-works-media-fails}

同一供应商的不同媒体能力可能：

- 使用不同端点；
- 需要单独开通；
- 使用不同模型名称；
- 有不同地区限制；
- 需要异步任务查询。

### 频繁限流 {#frequent-rate-limits}

降低：

- RPM；
- 并发任务数；
- 单次批量分镜数。

同时确认是否有多个 ArcReel 实例共享同一 Key。

### 费用明显高于预估 {#cost-higher-than-expected}

检查：

- 是否重复提交任务；
- 是否发生多次重试；
- 是否切换了更高价模型；
- 实际视频时长是否增加；
- 是否生成了原生音频；
- 价格表是否需要更新；
- 供应商是否调整计费方式。

## 14. 文档更新原则 {#doc-update-principles}

供应商模型变化频繁，因此：

- README 只维护能力矩阵；
- 本文维护配置原则；
- 具体模型列表以设置页为准；
- 官方价格以供应商页面为准；
- ArcReel 新增或移除供应商时，应同时更新矩阵、设置页帮助信息和测试。
