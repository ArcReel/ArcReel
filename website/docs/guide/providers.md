# 供应商与模型配置 {#providers}

ArcReel 把 Agent（智能体）、文本生成、图像生成、视频生成和 TTS 分成独立能力。你可以为不同项目和媒体类型选择不同供应商，而不必把整条生产链绑定到一家平台。

## 1. 先区分两类供应商 {#two-provider-categories}

### 1.1 Agent 供应商 {#assistant-providers}

Agent 负责：

- 理解用户意图；
- 分析小说和剧本；
- 提取角色、场景和道具；
- 规划分集；
- 规范化剧本；
- 编排后续生成任务。

ArcReel 的 Agent Runtime 基于 Claude Agent SDK，支持 Anthropic 官方服务以及项目所支持的兼容配置。

Agent 供应商不一定承担实际图片和视频生成。

### 1.2 媒体与文本供应商 {#media-and-text-providers}

这些供应商负责：

- 结构化文本生成；
- 图片生成和编辑；
- 视频生成；
- TTS。

一个完整项目可以采用组合策略，例如：

- Agent：高质量推理模型；
- 文本结构化：速度更快的文本模型；
- 角色设计：高质量图像模型；
- 批量分镜：低成本图像模型；
- 样片视频：快速视频模型；
- 最终关键分镜：高质量视频模型；
- 旁白：独立 TTS 供应商。

## 3. 配置层级 {#configuration-layers}

ArcReel 支持：

1. **全局默认供应商**；
2. **项目级供应商覆盖**；
3. **预置供应商内多个 API Key**（自定义供应商每个配置使用一个 API Key）；
4. **不同媒体类型使用不同供应商**。

优先级通常为：

```text
项目级配置 > 全局默认配置
```

适合项目级覆盖的情况：

- 某个项目需要特定画风；
- 某个客户要求固定供应商；
- 不同项目预算差异明显；
- 需要比较两个供应商的效果；
- 某个地区只能访问部分服务。

## 4. 选择供应商的六个维度 {#six-selection-dimensions}

不要只看单次生成效果。

### 4.1 质量 {#dimension-quality}

关注：

- 角色身份保持；
- 商品结构保持；
- 画面构图；
- 动作自然度；
- 文本遵循；
- 长镜头稳定性；
- 输出分辨率。

### 4.2 可控性 {#dimension-controllability}

关注是否支持：

- 多参考图；
- 首尾帧；
- 负面提示词；
- 固定种子；
- 视频延展；
- 参考生视频；
- 原生音频；
- 结构化输出。

### 4.3 可靠性 {#dimension-reliability}

关注：

- API 成功率；
- 排队时间；
- 限流行为；
- 超时；
- 任务查询；
- 幂等性；
- 失败后是否可安全重试。

### 4.4 成本 {#dimension-cost}

比较时应使用同一个完整分镜目标，而不是只比较单价。

总成本可能包括：

- 文本 Token；
- 角色、场景和道具图片；
- 分镜图片；
- 视频秒数；
- 失败重试；
- TTS；
- 因质量问题产生的返工。

### 4.5 速度 {#dimension-speed}

区分：

- API 响应时间；
- 排队时间；
- 实际生成时间；
- 高峰期波动；
- 批量任务并发能力。

### 4.6 合规和可用地区 {#dimension-compliance-and-region}

确认：

- 账号所在地区；
- API 是否在部署地区可用；
- 内容政策；
- 数据处理要求；
- 商业使用条款；
- 生成内容标记要求。

## 5. 推荐的分层策略 {#tiered-strategies}

### 5.1 经济型验证 {#strategy-budget}

用于：

- 新项目试跑；
- 提示词验证；
- 分镜数量确认；
- 分镜动作方向测试。

策略：

- 少量内容；
- 快速文本模型；
- 低成本分镜模型；
- 快速视频档位；
- 严格限制批量数量。

### 5.2 平衡型生产 {#strategy-balanced}

用于：

- 常规批量内容；
- 已验证的角色和风格；
- 需要稳定吞吐。

策略：

- 关键资产使用高质量模型；
- 普通分镜使用平衡模型；
- 视频按分镜重要度分层；
- 为失败重试保留预算。

### 5.3 高质量交付 {#strategy-premium}

用于：

- 关键剧情；
- 封面分镜；
- 商品特写；
- 品牌交付；
- 需要更高分辨率的成片。

策略：

- 高质量参考图；
- 更严格的分镜审核；
- 先做低成本预演；
- 只对确认后的分镜使用高成本模型；
- 保留人工后期。

## 6. 图像供应商配置 {#image-providers}

图像能力主要用于：

- 角色设计；
- 场景和道具设计；
- 商品标准参考图；
- 单个分镜；
- 多宫格分镜；
- 风格分析和图像编辑。

选择时重点关注：

- 多参考图支持；
- 角色和商品身份保持；
- 文字和 Logo 表现；
- 目标比例和分辨率；
- 图像编辑能力；
- 失败时返回的错误信息。

建议：

- 角色资产图尽量使用背景简单、主体完整的构图；
- 商品参考图优先使用真实素材和多角度输入；
- 普通分镜不必全部使用最高成本模型；
- 先固定角色和风格，再批量生成。

## 7. 视频供应商配置 {#video-providers}

视频能力可能覆盖：

- 文生视频；
- 图生视频；
- 参考生视频；
- 首尾帧；
- 视频延展；
- 原生音频；
- 固定种子；
- 不同时长和分辨率。

选择前确认：

- 当前模型支持的输入类型；
- 参考图数量限制；
- 单次时长；
- 横竖屏支持；
- 是否会生成有声视频；
- 任务查询和取消能力；
- 失败是否计费；
- 内容审核规则。

不要假设所有视频模型支持相同参数。ArcReel 会统一上层工作流，但供应商特有能力仍然存在差异。

## 8. 文本供应商配置 {#text-providers}

文本能力用于：

- 结构化剧本；
- 提示词生成；
- 多模态理解；
- 费用预估中的文本调用；
- 自定义辅助任务。

关注：

- JSON 或结构化输出稳定性；
- 长上下文；
- 中文表现；
- 视觉理解；
- 速度；
- Token 价格；
- 限流。

高推理模型不一定适合所有任务。可把复杂内容分析和普通结构化转换分给不同模型。

## 9. TTS 配置 {#tts-providers}

ArcReel 的旁白能力可以使用阿里百炼 Qwen TTS 或兼容的 TTS 接口。

配置后先验证：

- 中文和英文发音；
- 人名、地名和专有名词；
- 数字和单位；
- 语速；
- 情绪；
- 单段最大长度；
- 输出音频格式。

批量生成前，先试听一段包含典型专有名词的文本。

## 10. 自定义供应商 {#custom-providers}

ArcReel 可以接入 OpenAI 兼容或 Google 兼容服务。典型用途：

- 自建 API 网关；
- 企业统一密钥管理；
- 私有模型服务；
- 本地 Ollama 或 vLLM 周边服务；
- 第三方兼容平台。

一般配置包括：

- 名称；
- Base URL；
- API Key；
- 模型名称；
- 媒体类型；
- 可选的供应商特有参数。

模型发现协议只决定 ArcReel 使用哪类模型列表接口；每个模型实际如何调用，由它绑定的调用端点决定。ArcReel 可以按模型名称推断媒体类型和调用端点，但兼容协议不代表所有能力和参数都可用，保存前可以手动调整，添加后也应逐项验证：

1. 文本连通性；
2. 结构化输出；
3. 图片生成；
4. 视频任务创建；
5. 视频任务查询；
6. TTS；
7. 错误码和限流行为。

## 11. 多 API Key {#multiple-api-keys}

同一供应商可以配置多个 API Key，并选择当前激活 Key。

使用多个 Key 时应遵守供应商条款。它适合：

- 不同项目或客户隔离；
- 测试和生产隔离；
- 额度管理；
- 凭据轮换。

它不应被用于规避供应商限流、风控或服务条款。

密钥轮换建议：

1. 新增新 Key；
2. 用小任务验证；
3. 切换激活；
4. 观察错误率；
5. 删除或停用旧 Key；
6. 更新密钥管理记录。

## 12. 费用追踪 {#cost-tracking}

ArcReel 可以按供应商和媒体类型记录费用，但需要注意：

- 不同供应商使用不同计费单位；
- 不同币种不应直接混为一个未经说明的总数；
- 供应商价格可能调整；
- 某些失败任务也可能产生费用；
- 实际账单以供应商结算为准。

建议把 ArcReel 费用追踪用于：

- 项目预算；
- 分镜成本比较；
- 模型选择；
- 异常调用发现；
- 预估与实际偏差分析。

它不替代供应商官方账单。

## 13. 故障排查 {#troubleshooting}

### 连通性检查失败 {#connection-test-failed}

检查：

- API Key；
- Base URL；
- 模型名称；
- 网络代理；
- TLS 证书；
- 账号地区；
- 账户余额或额度。

### 文本能用，图片或视频不能用 {#text-works-media-fails}

同一供应商的不同媒体能力可能：

- 使用不同端点；
- 需要单独开通；
- 使用不同模型名称；
- 有不同地区限制；
- 需要异步任务查询。

### 频繁限流 {#frequent-rate-limits}

降低：

- RPM；
- 并发任务数；
- 单次批量分镜数。

同时确认是否有多个 ArcReel 实例共享同一 Key。

### 费用明显高于预估 {#cost-higher-than-expected}

检查：

- 是否重复提交任务；
- 是否发生多次重试；
- 是否切换了更高价模型；
- 实际视频时长是否增加；
- 是否生成了原生音频；
- 价格表是否需要更新；
- 供应商是否调整计费方式。

## 14. 文档更新原则 {#doc-update-principles}

供应商模型变化频繁，因此：

- README 只维护能力矩阵；
- 本文维护配置原则；
- 具体模型列表以设置页为准；
- 官方价格以供应商页面为准；
- ArcReel 新增或移除供应商时，应同时更新矩阵、设置页帮助信息和测试。
