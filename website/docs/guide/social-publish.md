# 发布到社交平台 {#social-publish}

成片生成完成后，可以直接从预览器把它投递到 TikTok、YouTube、Instagram、X、LinkedIn 等平台，不必先下载再逐个平台手动上传。投递经由 [Upload-Post](https://upload-post.com) 完成：它统一封装了各平台的发布接口，ArcReel 只需要一份凭证。

投递的永远是预览器里此刻选中的那一版成片——与「下载可编辑包」「剪映草稿导出」同一口径。换了版本再发，发出去的就是新版本。

## 前置条件 {#prerequisites}

- 已完成至少一个分镜/单元的成片生成
- 拥有 Upload-Post 账号，并在其中完成三件事：
  1. 连接要发布的社交账号
  2. 创建一个**档案（profile）**，它把这些账号归成一组
  3. 生成一个 **API Key**

## 配置凭证 {#configure-credentials}

进入 **系统设置 → 社交分发**，填写两项：

- **API Key**：Upload-Post 控制台生成的密钥。只保存在本机数据库，读取时只返回掩码，前端任何时候都拿不到原值。
- **档案名**：Upload-Post 里的档案名称（不是社交账号的用户名）。它决定这次投递会落到哪一组已连接账号。

**服务地址**留空即可，它指向 Upload-Post 官方地址；只有自建代理或联调环境才需要填写，且必须是不含账号口令与查询串的 https 地址。

保存后点击 **读取账号**，确认档案下的账号都在且没有「需重新授权」的标记——带这个标记的连接投递必定失败，需要先到 Upload-Post 重新授权。

## 发布一条成片 {#publish}

1. 在画布中打开任意成片的预览器
2. 点右下角的 **发布** 按钮
3. 勾选目标平台：清单只列出「该档案已连接」且「接受视频投稿」的平台，其余不会出现
4. 填写标题；正文可选
5. 需要定时发布时填写时间，按本机时区解释；留空即刻投递
6. 点 **发布**

投递受理后，弹窗切换到进度面板，按平台逐条显示状态，发布成功的平台会给出贴文链接。

## 平台差异 {#platform-notes}

- **标题**：YouTube 必填，其余平台可选，但都会把它当作文案主体。
- **正文**：只有 LinkedIn、Facebook、YouTube 与 Pinterest 会使用，其余平台忽略。
- **未连接的平台**：如果档案里没有某个平台的账号，投递不会整体失败——该平台标记为「未连接，已跳过」，其余照常发布。
- **AI 生成声明**：ArcReel 的成片全部由模型生成，投递时恒定带上跨平台的 AI 内容标记（TikTok 的 `is_aigc`、X 的 `made_with_ai` 等），不作为可关闭的选项。

## 常见问题 {#troubleshooting}

**提示「尚未配置社交分发」**
API Key 或档案名有一项为空。两者都填齐才能投递。

**提示「拒绝了这份凭证」**
API Key 无效或已过期，到 Upload-Post 控制台重新生成。

**提示「本月的发布额度已用尽」**
Upload-Post 按套餐限制月发布量，需升级套餐或等待额度重置。

**某个平台一直停在「处理中」**
各平台的转码与审核耗时不同，长视频尤其明显。弹窗关掉不影响后台投递，重新打开也不会重复发布。

**投递时提示成片不可用**
预览器选中的版本文件已被清理或改名。重新生成或切换到仍存在的版本再发。
