# Q: 新建项目上传自定义风格参考图后，解析格式、系统提示词和完整处理流程是什么？

## Answer

创建项目先传 style_template_id=null，再 POST /projects/{name}/style-image。后端验证/归一化 png,jpg,jpeg,webp，保存 style_reference.<ext>；以 TextTaskType.STYLE_ANALYSIS（simple tier，必须 vision）调用 TextGenerator，请求仅含 STYLE_ANALYSIS_PROMPT + 图片，没有单独 system_prompt，也没有 response_schema。提示要求只分析 lighting、palette、medium、texture、mood，排除主体内容，输出简短逗号分隔 descriptor。result.text 未结构化解析，原样写入 project.json.style_description；同时 style_image 写文件名、删除 style_template_id、style置空。后续 step2 和最终生图使用 style_description 文本；style_reference 图片不会被普通分镜生成自动作为参考图再次注入。
