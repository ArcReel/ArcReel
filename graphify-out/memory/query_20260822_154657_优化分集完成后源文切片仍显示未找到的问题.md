# Q: 优化分集完成后源文切片仍显示未找到的问题

## Answer

Expanded from original query via graph vocab: [episode, source, review, frontend, fetch, effect, metadata, project, refresh, missing, test, router]. EpisodeSourceReview 当前只以 projectName 和 episode 触发切片请求；同项目同集在 reset 后先得到 404、plan_episodes 落盘并由 SSE 刷新项目快照后不会重新请求。方案是在 EpisodeSourceReview 订阅既有 projectSnapshotRevisions，把修订号纳入请求 key 和 effect 依赖；快照更新后自动重取 source/episode_N.txt，并由现有 disposed 防护拒绝旧请求覆盖新结果。补充 404 后修订号变化恢复成功、旧请求不覆盖新结果和稳定修订号不重复请求的组件测试。仅改前端组件与测试，不改后端、输出格式、API 或数据结构。
