# Q: 你看一下角色拉取的这一块，就是拉取到本地的这个角色，比如说布爸，他还有一些其他的这种数据吗？就比如说鳄鱼爸爸，是吧？他的一些这个形象的一些设定，这个是有的吗？如果有的话，我就需要补充一下这个到他的描述里面去，或者到他的一些这个他的一些meta data里面去。这样的话，后续去做这种角色匹配的时候，他能够匹配到鳄鱼爸爸上面去。你先查看一下具体拉取的数据。

## Answer

Expanded from graph vocabulary: [asset, character, project, apply, import, match, description, metadata, alias, catalog]. The catalog contains detailed prompt, subtitle, category, voice, configs, source and assets for 布爸. ArcReel currently stores the summary as description only on first creation, the TTS voice ID, and image/audio resources. Automatic global matching in _attach_exact_global_asset_matches uses same type plus exact normalized name; it does not use description or metadata, so a project character named 鳄鱼爸爸 will not match a global asset named 布爸. A separate alias field and alias-aware server match are the reliable design.
