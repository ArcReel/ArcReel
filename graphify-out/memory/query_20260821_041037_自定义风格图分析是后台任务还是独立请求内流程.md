# Q: 自定义风格图分析是后台任务还是独立请求内流程？

## Answer

不是 background task/队列。前端先 await createProject，再在自定义模式下 await uploadStyleImage。POST style-image 请求内部保存图片、await TextGenerator 风格分析、写 project.json 后才返回。async endpoint 只是非阻塞 I/O，不代表后台执行。若上传/分析失败，异常被前端局部 catch 并显示 warning，已创建项目保留并继续进入项目页，但没有有效 style_description，可稍后重传。
