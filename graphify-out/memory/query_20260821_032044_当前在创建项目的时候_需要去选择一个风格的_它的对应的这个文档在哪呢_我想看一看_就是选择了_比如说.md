# Q: 当前在创建项目的时候，需要去选择一个风格的，它的对应的这个文档在哪呢？我想看一看，就是选择了，比如说具体的这个风格之后，它是怎么样去做后续的这个链路的一个嵌入的，这个风格是怎么嵌套进去的？那具体的风格文件在哪？

## Answer

Expanded from original query via vocab: [style, styles, template, templates, project, create, generation, prompt, storyboard, workflow, config, cinematic]. 当前权威风格文件是 lib/style_templates.py；前端列表是 frontend/src/data/style-templates.ts，中文名称在 frontend/src/i18n/zh/templates.ts，缩略图在 frontend/public/style-thumbnails。创建时 StylePicker 保存 templateId，CreateProjectModal 以 style_template_id 提交到 POST /projects，server/routers/projects.py 校验并用 resolve_template_prompt 展开为完整 prompt，再由 lib/project_manager.py 把 style_template_id 和展开后的 style 快照写入 project.json。后续分镜、宫格以及角色/场景/道具生成从 project.json 读取 style，分别经 lib/prompt_builders.py 的 build_storyboard_prompt 或风格前缀函数注入 provider prompt。原始 docs/生图画风前置提示词4.10.docx 当前仓库不存在；设计说明在 docs/superpowers/specs/2026-04-14-style-presets-design.md，快照决策在 docs/adr/0023-style-template-expanded-snapshot.md。
