# Q: 用户能否在项目创建后部分调整自定义风格？

## Answer

当前支持在项目设置中重新上传自定义风格图、切换预设模板或取消风格；不支持直接编辑 AI 解析后的 style_description。StylePicker 状态也不携带 style_description，UpdateProjectRequest 未开放该字段。用户可在单镜头详情中编辑 image_prompt.scene、shot_type、lighting、ambiance，实现镜头级局部覆盖，但不是项目级风格文本编辑。风格/style_description 参与分镜 artifact basis，修改会使已生成产物的 basis 不再一致（stale），需重生成才反映画风。建议新增项目设置 textarea/chips，允许保存解析文本的人工修订。
