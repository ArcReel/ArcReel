# Q: 分集的部分，它会使用这个子Agent去做分集吗？

## Answer

Expanded from graph vocab: [episode, planner, planning, agent, subagent, tool, server, text, generator, workflow]. 当前分集规划不创建 SDK SubAgent。主 Agent 调用 MCP Tool plan_episodes；tool handler 直接 EpisodePlanner.create(project_path).plan()；EpisodePlanner 通过 TextGenerator.create(TextTaskType.SCRIPT) 选择项目复杂文本 backend，再用 TextGenerationRequest(response_schema=DramaPlanDraft) 直接调用供应商模型，校验后写账本和派生 episode 文件。ADR 0032 明确将规划 SubAgent 列为未采用方案：多轮能力无收益、流程难单测且消耗 agent 凭证。若 UI 出现 SubAgent 卡片，通常是其他工作流任务或此前阶段，不代表 plan_episodes 的内部执行。
