# 前端

前端任务（新建 UI 或重塑既有界面）动手写组件前先调用 `/frontend-design` 确立视觉与交互方向；完成实现后调用 `/react-doctor` 检查性能、可访问性与架构问题。spawn 前端实现 teammate 时把这条工具链要求写进 prompt。

改页面外壳与档位、工作区布局、路由深链、项目数据刷新、编辑单元与离开拦截、设置页配置问题前，先读 `website/docs/dev/architecture.md`「3. 前端层」的对应小节。

安装或第一次使用 `components/ui/` 的原语、给原语组件写测试、给出站调用打桩前，先读 `docs/agents/frontend.md`。
