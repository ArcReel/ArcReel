# Frontend

For frontend work (building new UI or reshaping an existing interface), invoke `/frontend-design` before writing components to establish visual and interaction direction. After implementation, invoke `/react-doctor` to check performance, accessibility, and architecture. Include this toolchain requirement in prompts when spawning frontend implementation teammates.

Before changing page shells and breakpoints, workspace layout, route deep links, project-data refresh, edit units and navigation interception, or settings-page configuration, read the relevant subsection of “3. 前端层” in `website/docs/dev/architecture.md`.

Before installing or first using primitives from `components/ui/`, writing tests for primitives, or stubbing outbound calls, read `docs/agents/frontend.md`.
