# 内容与生成模式

ArcReel 把内容类型与视频生成路径分开：

- `content_mode` 为 `narration`、`drama` 或 `ad`。
- `generation_mode` 为 `storyboard` 或 `reference_video`。
- `grid_storyboard` 只改变分镜图的拼装方式，不是第三种生成模式。

工作流计划会明确说明每种组合适用哪些步骤。执行时应以 `steps[].required` 和 `next_action.args` 为准，不要自行维护另一份「模式到步骤」映射表，也不要自行推断预处理器。

分镜图生视频项目以逐镜头或逐片段的分镜图作为视频输入；参考生视频项目则采用自包含的视频单元，并直接解析具名资产引用。因此，旁白、短剧和广告可能呈现不同的剧本结构，但这些结构差异不能覆盖工作流计划。

参考生视频使用自包含视频单元，跳过分镜图环节。旁白交付方式属于项目级设置；视频生成独立于旁白配音，剪辑阶段再根据项目设置处理配音。

模式和内容设置属于项目级选择。
