PROTOTYPE自定义调用端点：定义格式与模板语言细则

Wayfinder #2119 · 票 #2123。这是一份可以点的草案，不是产品界面。

要回答的问题：「JSON 结构模板 + {{ }} 占位符 + 唯一的 $each + JSONPath 优先级数组 + 纯字典映射 + header/query 鉴权」这套声明式定义，写成 JSON Schema 后，能否把三份起步模板（通用提交+轮询、NewAPI 视频、ComfyUI 工作流）从「填参数 → 渲染请求 → 读响应 → 归一状态 → 取产物」完整跑通，中途的每一条约定（整串占位符保留原生类型、空值删键、整数状态字符串化查表、只收字符串命中、枚举缺项不发请求……）在真实回包形状面前是否站得住。

用法：左栏选一份起步模板（可直接改 JSON 再「应用」），右栏用「引导走查」按顺序点，或在「自由操作」里任意组合提交 / 轮询响应。所有 HTTP 往来都是假的：你选哪条响应，供应商就「回」哪条。

待你拍板的约定

下面每条都已在本页按「原型选择」实现；走查时觉得哪条别扭，就是要改的地方。

  1. 响应根是 body，且只有 body。JSONPath 的 $ 指向解析后的响应体（不是 n8n 式的 $.body.… 包装对象），没有切换到 headers 的 source。HTTP 状态码不走 JSONPath，也不进定义文件：2xx 即成功；429 / 5xx 由运行时重试（保持上一状态继续轮询）；其余码 ⇒ 任务失败，错误按 error 从 body 取（Segmind 式 422）。
  2. 模板只替运行时区分三个结果：继续 / succeeded / failed。status_map 目标值用与 ProviderJobStatus 同名的四个字面量（queued 与 running 都是「继续轮询」，只影响 UI 文案，不加翻译层）。expired 不由声明式产生：手写模板的 404 多半是 URL 写错而非任务过期，抽样 0/10 有过期状态；声明式 backend 按 v2_video_generations 先例把 EXPIRED 折进 FAILED，日后放开是纯增量。
  3. {{ api_key }} 只在 auth 节可用，且 auth 节优先。请求体 / URL 里出现 {{ api_key }} 即校验失败；submit / poll 声明与 auth 同名的 header（不区分大小写）/ query 也是校验错误，渲染时以 auth 为准——凭证只有 auth 一个写入口。代价是凭证入体的旧式接口不支持。
  4. 轮询允许 POST + body（ComfyUI 托管平台需要）。submit / poll 是同一种请求对象。
  5. 整串单占位符保留原生类型；混合文本一律串化；值为 null 的整串占位符删掉所在键 / 元素；混合文本里遇到 null 报错。
  6. 枚举映射只对 duration / aspect_ratio / resolution / generate_audio 开放，键按字符串化查表，缺项不发请求。数字→字符串枚举（"5"）走这里，不给模板加转换。
  7. 提取只收字符串命中（默认 accept: string），状态字段可声明 accept: scalar 以收整数码；数组 / 对象 / null 一律跳到下一条路径。
  8. json_decode + then 是评估项：固定后缀、非表达式，换来 JSON-in-string 两家可用。要不要进首期？
  9. 素材只有四个来源（start_image / end_image / reference_images / reference_audio_files）与两种编码；列表型只能经 $each。不做 MIME 白名单：不支持的格式由供应商在提交时拒绝（未接单不计费）。
  10. 能力声明与 VideoCapabilities 同名同义，但 first_frame / last_frame 由 inputs 推导（有 start_image / end_image 来源即支持），不再重复声明；capabilities 整节可省略。supported_durations / resolution 仍留在模型行 DB，不进定义文件。
  11. 已砍字段（都是运行时策略或零信息，日后加回是增量）：submit/poll.query（写进 url；auth.query 保留）、success_status_codes、retry_status_codes、expired_status_codes、interval_seconds、timeout_seconds、extract.source、inputs.*.mime_types、poll.extract.duration_seconds / seed、meta.media_type。校验器对这些字段给「字段已移除」错误而不是静默忽略。
  12. ComfyUI 模板把 workflowId 当 {{ model }}（模型行填工作流 id）。可接受的复用，还是需要独立变量？
  13. 自托管 ComfyUI /history 的产物不是 URL（filename / subfolder / type 要拼 /view?…），本原型不覆盖；托管平台形态（返回 fileUrl）可覆盖。
  14. 路径校验器是手写子集解析器（本页所用），前端是否引入 json-p3 做即时求值预览仍是 #2122 的未决项。
