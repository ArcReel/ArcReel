书写层写什么、机器渲染时补什么。验证后的规则落入 `lib/reference_video/shot_parser.py`,本目录整体进 throwaway 分支。

设计输入:`sd2-pe-SKILL.md`(Seedance 2.0 官方提示词技巧,用户提供,随原型收档)、票 #1384 决议(utterances 真相模型)。

## 格式提案(书写层规范)

书写层 = 用户/AI 写进 `unit.shots[*].text` 的部分,仍是唯一真相;其余全部由机器渲染时生成。

```
<可选:开场自由文本 = 总体定调段(首个镜头 header 之前)>

镜头1 (5s)：<镜头描述,运镜→动作→空间,@[名称] 引用资产>
@[角色名]：{台词}          ← 规范台词行,独立成行
{旁白内容}                 ← 裸花括号行 = 画外音

镜头2 (4s)：……
```

| # | 决策点 | 提案 |
|---|--------|------|
| 1 | 三段分工 | 第一段(定调+主体绑定+声音特征)与第三段(风格锚定+画质/稳定/字幕/水印包+多角色双胞胎兜底)全部机器生成;书写层只写镜头分镜段与可选开场定调。第三段替代现行 `_NEGATIVE_TAIL_VIDEO` 尾词 |
| 2 | `@[名称]` 衔接 | 编辑器 mention 语法不变;渲染时 `@[X]` → `<X>`,第一段自动生成简式绑定 `<X>@图片N`(官方"未提前定义"形态,不需要特征文本,不做语义提炼)。图片编号 = mention 首现顺序,**规范台词行的 speaker 位不计入**(附参考图会诱导模型把画外说话的角色画进画面;2026-07-29 拍板)。纯画外角色无参考图,但音色声明与台词行重组照常(按资产表判定) |
| 3 | 台词语法 | 规范行 `@[名称]：{台词}` 独立成行(中英冒号均可);表演提示(笑着/哽咽)写在镜头描述行,不入台词行(`（）` 是官方 BGM 符号,不能用作舞台指示)。规范行渲染为 `<X>说 {台词}`;**音色参考与声音特征集中在第一段声明**(`<X>的台词音色参考 @音频N，声音特征：…`——官方三段论第一段即参考来源声明区,人脸/运镜/音色参考同位;2026-07-29 拍板)。裸 `{…}` 行 = voiceover,渲染 `画外音说 {台词}`。**utterance 只从规范行派生**:台词混在描述行内时原样发送、不派生、出 warning——不做"行内最近 mention 猜 speaker"启发式(推断错误会静默错绑参考音频;2026-07-29 拍板砍除) |
| 4 | 时长承载 | header 的 `(Xs)` 是**书写输入语法**:解析瞬间落 `Shot.duration` 结构字段(计费预估/取档/unit 上限校验的既有消费方不变),落盘 `shots[*].text` 不含 header,无双份真相、无需清理;渲染发给模型的文本不含秒数,符合官方禁绝对秒数 |
| 5 | 存量过渡 | 双格式 header 兼容(`Shot N (Xs):` / `镜头N (Xs)：`),渲染统一走新三段论管线。文稿是唯一真相、渲染是纯函数,**没有需要迁移的落盘数据**;存量文稿自动获得新渲染(`[图N]` 对照表废除) |
| 6 | 降级可见性 | parse/render 全程收集 warnings(未注册引用、花括号未闭合、非规范台词行、无参考音频、超音频上限、C 类无声),即编辑器"解析预览面板"的内容源:保存/预览时展示派生出的 shots/references/utterances + warning 列表。前端具体形态留给实现(fog 中已有前端 UI/UX 条目) |

音频编号:dialogue speaker 首现顺序 → `@音频N`,仅 A 类、仅资产带 `reference_audio`、受 `max_reference_audio_count` 上限;顺序即 `reference_audio_files` 请求字段顺序(#1385 契约)。

## 拍板记录(2026-07-29)

- **声音参考集中在第一段声明**(用户提出方向,官方出处:三段论第一段为参考来源声明区);台词行统一 `<X>说 {台词}`。
- **C 类保留台词**:渲染进 prompt 供口型与表演,warning 明示成片无语音。
- **花括号未闭合行**:原样发出 + warning,不做剥除。
- **A 类同样注入声音特征描述**(官方建议音色还原不佳时补描述,A/B 均注入,C 不注入)。
- **时长不清理**:`Shot.duration` 结构字段维持现状(见决策点 4)。
- **speaker 推断启发式砍除**(YAGNI + 错绑危害):utterance 只从规范行派生。
- **C 类 warning 带模型 id**:「当前视频模型「{model_id}」不生成音频，台词仅用于提示词参考」。

- **台词 speaker 位不计入参考图**(#1384 转入本票的未决点):附图会诱导模型把画外角色画进画面。音频参考不受影响(从 utterances 派生)。
- warning 文案已按用户视角重写并经两轮校对(见 `logic.py`),实现时进 i18n 三语。
