- **施动者写明**：每句动作都点明是谁在做，不用「随后」「接着」这类省略主语的写法。
- **状态写两端**：状态变化写「起点 → 终点」（手从垂在身侧到按上剑柄），不要只写变化后的终点。
- **反应写可见动作**：不写「他有些惊讶」，写「他瞳孔一缩，下颌绷紧」。
- **站位用固定物体锚定**：不写「站在画面左侧」，写「站在 @[灶台] 前的地砖上」。
- **不写四类无效条件**：方位词（画面左 / 右、前景 / 背景）、编号、看不见的概念（气氛压抑、关系紧张）、跨句重复——模型不认这些，写了只会稀释有效指令。
- **不用否定式**：不写「不要出现第三个人」「没有下雨」，改成正向描写当下在场的人与环境状态。
- **光只写四样**：来源、方向、落点、强弱。不写冷暖色词（暖黄、冷蓝）——光色由全局风格承担。剧情要的光写「谁发光、照亮哪块、到哪里暗、何时亮何时灭」。
- **形态偏离类别默认时只写长相**：当要的东西和它所在类别的默认形态不同（不是常规的剑、不是常见的车），写它实际看起来什么样，**不写类别名**，否则模型会拉回默认形态。
- **第 1 镜不写仪式感动词**：不写「祭出」「施法」「发动」，只写物理动作（抬手、捏诀、指向）。
- **暴力血腥换动作与结果**：不写「鲜血喷出」，写「指尖沾血」。
- **单镜动作量**：手部动作不超过 2 步；有明确因果时拆两镜——前镜给原因（道具或动作特写），后镜给结果。
- **关键反应单独给脸**：近景或特写，写「从 X 到 Y」；先写视线落到刺激物上，再写面部变化。
- **相邻镜至少变一样**：景别、角度、人物关系三项里至少变一项，不要连续两镜同景别同角度。
- **表演按景别选通道**：全景写体态、中景写眉眼与嘴、近景写眼神与呼吸、特写只写一个细节。
- **推断词清零**：不写「若有所思」「似乎」「仿佛」「不禁」「心里明白」「眼底藏着」——这些没有可拍载体。
- **无台词就写「无台词」**：该 unit 内没有任何人开口时，正文末尾明确写「无台词」（英文项目写 No dialogue），否则模型会自行给角色添加说话。
- **每段至少一镜前景纵深**：安排一处前景遮挡（门框、枝叶、器物边缘），画面才有层次。
- **竖屏留字幕位**：画面比例为 9:16 时，画面下方五分之一不承载脸、关键手部动作与必读物件——那里要留给后期字幕。
- **竖屏（9:16）景别越推越近**：同一情绪段内按「中景 → 近景 → 特写」推进，制造压迫与情绪爆发；不要反向从特写拉到大远景（换场建立空间除外）。
- **非人形角色形象硬锁**：动物 / 怪物 / 丧尸 / 异变体首次出场或形态变化时，补一句「X 形象硬锁：<外形特征>，<行为边界>」（如「猫形象硬锁：银蓝短毛、比例正常、眼神冷静，不炸毛、不露牙、不快速奔跑」）；之后复用同一 `@` 引用即可，不必每镜重复。普通人类角色不需要。
