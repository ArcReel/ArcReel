打斗 / 交锋镜专用（非打斗镜忽略本节）：
- **攻防五结果**：每次出手都写清「谁打谁、打中哪里、结果如何」——命中 / 格挡 / 闪避 / 擦伤 / 被反制，五者取一，不能只写「出拳」「挥剑」。
- **受击反馈**：被打中必须有可见反馈（身体后仰、踉跄、护住受击部位、兵器震颤）；**不许打空气**——攻击必须有明确目标与接触点。
- **战损连续**：伤情、衣物破损、武器损耗一旦发生，后续镜头延续；恢复必须有镜内动作交代，不能凭空复原。
- **一镜一主要动作**：连招写成「起手 → 命中 → 收势」3 拍，不要把七八个动作糊进一句。
- **动作量例外**：打斗镜按本节执行，是「单镜动作量不超过 2 步」的例外；但每拍仍只写一个主要动作。
- **过审换结果**：不写血，用碳屑 / 霜屑 / 火星 / 碎片替代。
