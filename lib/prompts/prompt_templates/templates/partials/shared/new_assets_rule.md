# 本集新增资产（new_assets）

上方资产表列出全部已登记资产，括号里是别名。本集原文出场的资产，先对照表里的名字、别名与描述认人：认得出就直接引用登记名。认不出的角色 / 场景 / 道具，在引用处写原文称呼，并在 `new_assets` 里为它列一项；列进 `new_assets` 的称呼与登记名一样可以引用。同类同名的称呼只列一项，没有新增资产时写空数组 `[]`。

**提取密度（宁多勿漏）**：出镜的每个角色（含动物、非人形、群像）、每个实际发生剧情的场景空间、每个被剧情用到的关键道具，都要单独成条。判据是「它在分镜里是否需要保持一致」（反复出现、被特写、承载剧情或动作），而不是「它是否显眼」；一次路过、无需固定外观的群演或杂物才可 `skip`。宁多勿漏，但不虚构原文没有的资产。

每项写 `type`、`name`（引用处写的称呼）、`decision` 和一句 `reason`（依据，如「第 3 段首次出场，有台词」）。`decision` 取以下四种之一：

- `register`：登记为新资产。`description` 是后续生成资产图的唯一依据，要写成**能直接画出来的外观**，不是关键词堆砌。
  - 文体与长度：**2-4 句连贯的叙事段落**，按空间顺序落笔；只写外观本体，**不要写构图、镜头、视角、背景版式或打光方案**（这些由图像 builder 注入）。
  - 角色：年龄、体态、脸型与眉眼特征、发型、服饰材质与配色、标志性配饰，突出**能跨镜头一眼认出的独特特征**。示例：「二十出头的女子，身形纤细，鹅蛋脸上一双清澈的杏眼，柳叶眉微蹙时带几分忧郁；身着淡青色绣花罗裙，腰间系同色丝带，端庄而不失灵动。」
  - 角色另需填 `voice_style`（与 `description` 并列的独立字段，register 时必填）：用 1-2 句写清配音风格——**音色**（如清亮少年音 / 低沉烟嗓）、**语速**、**情绪基调**、**口音或语言习惯**；只决定配音与口播语气，**不参与画面**，由渲染器自动注入最终提示词的声音特征行。示例：「清亮偏冷的青年音，语速舒缓，常带漫不经心的戏谑，普通话略带港式尾调。」
  - 场景：空间结构与主要陈设、光线与时间感，以及**可跨镜头复现的标志物**。示例：「村口百年老槐，树干需三人合抱，树皮龟裂沧桑，主干一道雷击焦痕自上蜿蜒而下；树冠浓密，夏日洒下斑驳树影。」
  - 道具：形制、尺寸、材质、纹理与磨损细节。示例：「拇指大小的翠绿玉佩，玉质温润透亮，表面浮雕层层舒展的莲花纹，系一根红色丝绳打着中国结。」
  - 原文没写到的细节，按题材与风格合理补全，**不要留空或只写一个名字**，但**不得新增伤疤、纹身、异色瞳这类识别标记**；原文里的其他称呼写进 `aliases`；需要比称呼更正式的登记名时填 `asset_name`。
  - **外观描述红线**（违反会让资产图不可用）：
    - 颜色只写物体本色（藏青、赭红、鸦青、赭石），**不写整体调子词**（明亮、梦幻、阴森、唯美）——画面调子由项目风格参数承担。
    - **正面写，不写否定**：不写「没有纹饰」「不戴帽子」，改成正向描述实际有什么。否定词反而会把被否定的东西招进画面。
    - **关键物件唯一显眼**：本集要被拿起、会发光、会变化的那一件，写成本场景里唯一显眼的物件；同类物件一律写平平无奇。
    - **角色辨识度**：每个有名字的角色，用一句话、只用看得见的特征（发型 / 脸型 / 体型 / 衣装轮廓 / 标志物，任取至少两样）就能和别的角色分开。
    - 年轻女性角色写明裙长、领口、鞋样；相像的道具用长短、有无雕饰区分，**不要只靠颜色**。
    - 非人形角色写清体型、头、角、肢、翅、尾、毛色，数量写死（写「三头」「两翼」，不写「多头」）。
    - **质感随本体走，不要套真人**：真人写皮肤毛孔、细纹、碎发与布料纤维；骷髅 / 白骨写森白骨质、骨孔、裂纹与磨损哑光，禁毛孔血管汗毛；兽人 / 怪物写兽皮、粗硬毛发、角质褶皱与泥土附着；亡魂 / 灵体保持稳定轮廓 + 低透明冷灰边缘，不写全身发光；群像写「XX群像」的共同外观，不指定单一脸。
    - 天气、雾、湿度这类大气现象只写进室外场景，室内场景不写。
    - 穿戴类道具写「平铺或立放、开口空着」，不写会招出手脚包裹它的句子。
- `merge`：已登记资产的另一种称呼（如「将军」指的是已登记的「裴与」）。`target` 填同类登记名，或本次另一项新增资产的称呼；确认后称呼记为该资产的别名。
- `derivative`：仅限角色，指已登记角色的另一套外观（如少年时期、换装）。`target` 填本体登记名，`asset_name` 填衍生名（如「少年」），`description` 只写相对本体的变化。
- `skip`：一次性出场、无需固定外观的人或物，只用文字描述，确认后不登记。

`name` 与 `asset_name` 都是单个名字，衍生关系由 `target` 表达。已登记资产的描述保持原样，`merge` 与 `skip` 的 `description` 留空。
