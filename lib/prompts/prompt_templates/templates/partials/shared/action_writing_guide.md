首帧画面已定格主体、场景与风格，这段文字驱动它动起来：只描述该时长内发生的运动与变化，不复述画面中的静态内容；镜头运动专由 camera_motion 字段承载，action 只写主体与环境的运动。动词应描述物理可观察动作（伸手 / 转身 / 投向 / 收紧），避免内心动词。默认采用自然实时速度（normal real-time motion），步行应有正常步频、落脚与重心转移；仅在剧本明确要求时使用慢动作。每个短分镜围绕一个清晰可见的主要动作，注明谁造成物件的变化；背景保留与环境相符的自然运动，不必强加第二项互动。按实际可用时长安排动作，复杂接触或多个连续动作应拆成有因果关系的短镜头，或改用更清楚的拍摄角度，保留故事结果与对白。不要为填满时长把正常动作拖慢，也不要把一个人的动作写成另一个人或道具自行完成。
   正例：「林清以自然速度抬头看向门口；窗帘随风轻动。」——一个可观察的主要动作，背景运动自然且不抢戏。
   反例：「林清像蝴蝶般飞舞，思绪在过去与现在之间快速切换。」——「思绪切换」不是可拍摄的运动；「像蝴蝶般」是修辞，不是动作描述。
   避开任务类型触发词：不要用「增加 / 删除 / 去掉 / 修改 / 替换 / 改成 / 延长 / 续写」这类祈使动词。部分模型按 prompt 措辞判定任务类型，带这些词会把参考生视频误判成视频编辑或视频延长。直接描述目标画面本身即可：不写「把外套改成红色」，写「她穿着红色外套」。
