- **用可见生理线索替代情绪词**（image_prompt 的表情描写同样适用）：不写「他很愤怒 / 悲伤 / 紧张」，写具体可见的变化——瞳孔收缩、下颌绷紧、鼻翼微张、喉结滚动、指尖收紧、呼吸变浅、视线游移。
- **每镜只给 1-2 个线索**，按发生顺序写、不并置；全景写体态、中景写眉眼与嘴、近景写眼神与呼吸、特写只写一个细节。
- **避免会诱发假笑的模糊词**（微笑、苦笑、释然、温和、嘴角上扬）；需要克制时写「唇线维持平直、嘴角不上扬」。
- **情绪终态不漂移**：指定「压抑 / 悲愤 / 麻木」时，结尾不要收成暖意或释然；面部与身体线索要互相印证，不写互相矛盾的表演。
- **肢体调度写清四件事**：动作幅度（做多大）、轨迹（从哪到哪）、次数（做几次）、起止与回收（何时开始、何时停下、停在哪、怎么收回），不要只写「抬手」。
- **对白前 / 中 / 后留调度**：开口前有一个起势或停顿，说的时候有一个可见动作配合，说完有一个回收，不要停在半空。
- **情绪按拍演进，不要一个静态词撑满整镜**：把情绪变化写成 2-3 个阶段（压住 → 泄露 → 收束），每阶段落到具体可见线索，并与逐拍时间码对齐；单个表情词只做起始帧的锚点，不代替整段表演。
- **五类情绪的演进规律**：
  - 悲伤 / 崩溃：先压住、再泄露——眼眶先红、呼吸变浅、下颌发抖、吞咽、身体支撑逐步失效。
  - 爱意 / 温柔：不靠大动作——目光聚焦、嘴角自然变化、停顿、「想靠近又克制」的微动作。
  - 笑意：差别在眼睛是否参与、笑意出现快慢、是否遮挡、是否持续对视。
  - 冷意 / 愤怒：张力在「更克制」——嘴角可以在笑、眼底持续降温；动作越慢压迫感越强。
  - 冲击 / 恐惧：瞬间反应快、消化过程慢——先瞳孔与呼吸，再扩散到手 / 肩 / 身体，最后形成接受、逃避或决断。
- **表演服务叙事**：微表情只强化已定稿的情绪与因果，不新增剧情、不改变人物关系。
