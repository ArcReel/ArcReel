# Adding and upgrading dependencies

1. **Let the package manager write the change.** Backend: `uv add <包>` (add `--group dev` for development dependencies). Frontend and documentation site: `pnpm add <包>` in their respective directories. The package manager writes versions and lockfiles; do not enter them manually in `pyproject.toml` / `package.json`.
2. **Assign a Dependabot group.** Add the package to the most semantically appropriate group in `groups` for the corresponding ecosystem in `.github/dependabot.yml`. `all-other` is only for unclassified packages, not a valid assignment for a new package. `uv run python scripts/audit_conventions.py --check` lists direct dependencies matching only `all-other`.
3. **Run dependency-hygiene checks.** Run `uv run deptry lib server alembic scripts tests`. For changed subpackages, also run `uv run deptry src tests` in that subpackage (`packages/arcreel-market-core/` or `packages/arcreel-catalog-core/`). Directly imported third-party packages must be declared (`DEP003`); declared packages without imports must be removed or registered as runtime plugins (`DEP002`).

## Known version constraints

- **Frontend TypeScript is constrained by the `typescript-eslint` peer range.** Before upgrading TypeScript, check the pinned `typescript-eslint` peer range and upgrade it together if necessary.
- **The documentation site's TypeScript ceiling is 6.x.** The reason and unlocking conditions are in the website-section comments in `.github/dependabot.yml`.
- **The backend `anthropic` SDK is pinned to 0.x.** Version 1.x switches its HTTP layer to `httpx2`: respx in the tests (`tests/http_capture.py`) intercepts only `httpx`, and endpoint request-path rewriting at the HTTP transport layer also uses `httpx`. Neither works with 1.x. Unlock when respx supports `httpx2` and the shared HTTP client and transport for Python endpoints in the repository have migrated to `httpx2` (with SDKs such as `openai` migrated together).
- **The `version` fields in `pyproject.toml` and `frontend/package.json` are maintained by release-please** and are read-only.
- **Upgrade shadcn primitives with their dependencies.** Dependabot upgrades npm packages but does not regenerate `frontend/src/components/ui/*.tsx`. Minor and patch upgrades of `@base-ui/react` and `shadcn` belong to `shadcn-stack`; major upgrades require a separate PR. In that PR, run `pnpm exec shadcn add <组件> --diff` for each installed component, manually merge upstream changes, and retain documented local changes. When a primitive has a defect, first use `add --diff` to check whether upstream has already fixed it.

- **Provider icons use only individual SVG entry points from `@lobehub/icons/es/*/components/{Color,Mono}`.** A targeted override in `frontend/package.json` excludes this package's `@lobehub/ui` peer. These entry points depend only on React and do not use its UI components, avoiding automatic introduction of another UI and animation stack. Before using Avatar, combined entry points, or other components that depend on `@lobehub/ui`, reassess this constraint.
