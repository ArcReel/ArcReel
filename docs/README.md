## 维护原则

### README 保持稳定

README 的目标是让第一次访问仓库的人在较短时间内回答四个问题：

1. ArcReel 是什么？
2. 它适合我的场景吗？
3. 它和直接调用模型 API 有什么区别？
4. 我怎样最快跑起来？

具体模型名称、单价、接口参数和内部实现应尽量放在独立文档中，避免每次供应商更新都重写首页。

### 供应商信息以运行时能力为准

模型和参数变化频繁。文档应优先描述：

- 供应商覆盖哪些媒体类型；
- ArcReel 如何统一配置；
- 不同能力如何选择；
- 具体信息在哪里确认。

设置页中实际可选择的模型和供应商官方文档应作为最终依据。

### 文档变更应与功能变更一起提交

以下变化应同步更新文档：

- 新增内容模式或视频制作方式；
- 新增供应商或媒体能力；
- 部署目录、端口、环境变量变化；
- 数据目录、备份方式或迁移行为变化；
- 对外 API、许可证或商业使用方式变化。
