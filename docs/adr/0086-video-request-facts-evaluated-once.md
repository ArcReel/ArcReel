# 视频请求事实在每次求值中共用同一组输入和结果

规划、预检、参考费用预估与执行共用同一套「视频请求事实」纯求值规则，确保用户确认的档位、音轨与输入限制和实际提交一致。求值只消费两份已就绪输入：由 [ADR 0049](0049-generation-context-single-resolution.md) 单次解析产出的不可变能力快照（含供应商模型自带的默认分辨率），以及当前项目与全局的用户偏好（项目分辨率设置、音频意图、生成模式、角色声音绑定方式等），求值过程不访问数据库，也不回查配置解析器。读侧采用当前配置解析出的快照，执行侧采用与调用通道同源的快照，其余规则完全一致；配置预览显式区分未传分辨率覆盖、显式自动与指定分辨率三种输入。排队期间的编辑会在执行时重新投影，已提交任务的续跑沿用执行检查点，不走新请求事实求值。见 [ADR 0054](0054-media-model-capability-buckets.md)。

- 严格区分三个层次的概念：**生成模式**（分镜图生视频 / 参考生视频）决定项目工作流与面向用户的错误码族；**任务类型桶**（图生视频 / 参考生视频）按视频单元的实际可用参考图决定，参考生视频中无参考图的视频单元使用图生视频桶，该桶不可用时报告档位未知与原因，避免用另一个模型的档位放行；**供应商子路径**（如 Vidu 按纯文生、仅首帧、首尾帧、参考图区分的子路径）由完整请求输入决定，参考费用预估与实际发包共用同一组输入特征（含尾帧占位），确保报价与提交落在同一子路径。
- 两条生成模式都按 [ADR 0019](0019-resolution-none-means-omit-param.md) 保留未设置的分辨率。依赖请求条件的通道能力（如可灵在高分辨率或 `pro` 档下同时变化的尾帧与音轨）按完整请求条件（任务类型桶、分辨率与执行档位）一次求值，与执行期闸门同口径。时长、音轨与参考费用读取实际下发的请求值与计量策略，见 [ADR 0056](0056-execution-predicates-same-source-as-request.md) 和 [ADR 0104](0104-capability-sources-split-by-dimension.md)。
- 时长模式显式区分「维度由端点固定」与「应用可选的离散档位」两种互斥状态。常规模型取模型条目的可选时长及生效能力覆盖，按实际分辨率、参考图与尾帧取交集；时长声明缺失、收窄后为空或选择越界，均在付费提交前报错并保留逐项排除原因。ComfyUI 端点的固定时长属于独立合法状态，界面与 Agent 工具见到空集及固定标志，仅在脚本规划内部借用篇幅基准，见 [ADR 0082](0082-node-bindings-are-the-only-truth-of-comfyui-endpoint.md)。Vidu 的端点级时长校正处理同一型号在不同调用端点与输入子路径上的合法值差异，见 [ADR 0104](0104-capability-sources-split-by-dimension.md)。
- 面向 Agent 工具与设置接口的项目级能力投影与单请求事实求值共享同一份能力快照：前者返回声明全集、项目偏好、声音一致性档位与固定时长原因，后者返回收窄后的允许档位、排除原因及生成模式对应的问题码。
