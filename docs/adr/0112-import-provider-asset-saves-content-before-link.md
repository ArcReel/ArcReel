# 导入供应商素材先保存内容，再建立可用关联

从供应商素材库导入选定且可用的图片时，系统先下载并校验实际内容，再按手动上传成品的语义提交为正式图片，最后将关联归属到该内容版本。取不到内容就拒绝，不能把供应商 ID 贴到另一张图片或留下不可预览的占位。保留原始图像内容。路径固定为 PNG 的衍生图允许不改变像素的封装转换，避免压缩导致本地预览与供应商素材出现差异。

签名地址只用于这次服务端下载，不返回、保存或写入日志。下载只接受 HTTPS 与公网地址，重定向逐跳校验并限制响应大小。规则由[导入服务](../../server/services/project/provider_asset_import.py)持有。

图片与关联跨文件和数据库提交。正式图片、版本记录与产物登记准备完成后，在提交钩子里写关联。落库失败就回滚正式写入，避免失败响应却换了当前图片。后续收尾失败也回滚，并尽力删除写过的关联。其版本已不在历史中，生成不会选中。
