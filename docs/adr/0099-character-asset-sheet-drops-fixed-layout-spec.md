# 角色与角色衍生资产图 prompt 去掉固定版式、守卫与 `Avoid:`

ADR 0066 在角色资产图 prompt 里写入了三条固定指令：固定版式（「横版 16:9 三视图，纯白背景：正面 / 正侧（90° 侧视图）/ 背面水平排列。」）、跨面板一致性守卫（「三个面板中角色面部、发型、服装、配饰完全一致。」）、以及末尾 `Avoid:` 负向约束行（角色写自己的反向排除项后追加共享的 `水印、多余文字、Logo`）。角色衍生 prompt 另有一条守卫（「保持原图的三视图版式…」）与 `Avoid:` 行。本决定把这些固定措辞全部移除，让角色资产图只由画风、标题与描述驱动，角色衍生资产图只由描述驱动。

决定：**角色资产图 prompt 只保留画风（`Style:`）、标题（`角色「…」的资产图。`）与描述；角色衍生 prompt 只保留描述；两者都不再写入固定版式、跨面板一致性守卫或 `Avoid:` 负向约束。**

- 角色的 layout / guard / avoid 与角色衍生的 guard / avoid 片段均置空（衍生的 layout / title 本就为空）；`asset/sheet` 模版末尾的 `Avoid:` 行按资产类型取片段（`asset/sheet/avoid`），角色与衍生的该片段为空，故两者 prompt 到此（描述）结束。
- 构图 / 跨面板一致性 / 排除项改由描述承载：需要多面板、一致性约束或排除项时，写进描述，而不是靠固定措辞。
- 16:9 宽高比仍由生成任务显式指定（0066 的宽高比要求不变），与 prompt 措辞解耦——版式 / 负向措辞去掉后宽高比不变。
- 角色衍生（character_derivative）随之精简：去掉守卫（「保持原图的三视图版式…」）与 `Avoid:` 行后，prompt 只剩描述，仍以本体图为基准做局部改写。
- 场景 / 道具 / 商品三类不变：各自保留 layout、guard 与 `Avoid:` 行。

## 取代范围

本决定取代 0066 里**角色与角色衍生的固定指令**：角色的固定三视图版式、跨面板一致性守卫、反向排除项 + 共享图像约束（`Avoid:` 行），以及衍生的守卫与 `Avoid:` 行。0066 的其余决定继续有效：每个资产出单张图、guard 句只保留正向排除项形态、反向排除项维持文本形态并按图种定义、资产图生成必须显式指定宽高比、场景 / 道具 / 商品的版式与排除项。

## Consequences

- 角色图不再被 prompt 钉死成「正面 / 正侧 / 背面」纯白横排，也不再自带跨面板一致性守卫与 `Avoid:` 负向约束；角色衍生图只由描述驱动做局部改写。构图、一致性与排除项由描述驱动。多格版式经 i2i / r2v 继承到下游的风险口径与 0066 相同，只是不再由固定措辞决定。
- 模版改动为「角色与衍生的 guard / avoid 片段置空（角色 layout 一并置空）+ 末尾 `Avoid:` 行按类型取片段」，场景 / 道具 / 商品图种的渲染输出完全不变。
- 版式 / 措辞变更无自动防线（0066 已定）：不设断言模板文本的测试。验收走人工 QA——同一角色按新旧 prompt 各出一张，比对下游 i2i 的身份保真与版式继承。
