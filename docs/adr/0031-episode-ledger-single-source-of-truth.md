# 分集账本持有集的来源和顺序，切出集文件由账本派生

`project.json` 中的分集账本记录了每一集的原文来源、从整本源文切出的范围、钩子以及适用的分集大纲。按磁盘文件名推断进度时无法对账原文范围，滚动剩余文本一旦损坏也难以恢复。账本成为集索引，接续规划的起点按范围推导，播出顺序见 [ADR 0096](0096-episode-identity-separated-from-order.md)。

- 切出集由整本源文范围派生集文件。规划与手工切分在同一项目事务中更新账本和派生文件，保留现有工具按集读取的方式。
- 自带原文的集以创作者逐集上传或填写的内容作为源文，可以独立编辑。
- 无原文的集允许直接手写脚本。后两种集不占整本源文范围，同一项目可同时使用三种来源。

分集状态作为提示。能否续接规划由原文范围与文件事实决定。旧拆分流程没有可靠范围时保留原集及产物供消费，续接须从第一个切出集重规划。按文本相似度回推旧范围会把猜测当成作者已确认的切分。已记录范围的源文变化按 [ADR 0097](0097-whole-source-file-order-and-change-remap.md) 重映射，重新规划如何保留产物见 [ADR 0032](0032-episode-planning-server-side-batched.md)。
