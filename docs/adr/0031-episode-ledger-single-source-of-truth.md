# 分集以 project.json 账本为单一真相源，物理集文件降级为同锁派生物

> 本 ADR 中「手动预拆分上传」与「没有 source_range 的账本条目不参与规划」两条后果已由文末「集原文的三种来源（修订）」取代，其余内容仍然有效。

旧拆分流程以物理文件本身为真相（`episode_N.txt` 存在即已拆、`_remaining.txt` 滚动覆盖作进度指针），没有任何"第 N 集对应原文哪一段"的显式记录——下游选错文件无从对账，后续集靠 Glob 推断集数易错，`_remaining.txt` 损坏即不可恢复。决定把分集真相源并入 project.json `episodes[]`：条目扩展原文素材范围（source_range，narration 为精确切分点、drama 为软素材范围）、钩子（hook）、drama 分集大纲与消费状态字段（ledger_status，planned/consumed/stale 三态，咨询性——能否重造派生文件或续接规划不看该字段，而看 source_range 结构是否完整、引用的源文件是否存在、范围是否在界内、指纹是否与已记录一致），顶层增加 planning_cursor 标记下一批规划起点、source_fingerprints 按候选源文件相对路径记录 `normalize_source_text` 输出文本的 SHA-256 指纹，用于检测规划中途源文件被外部替换。物理 `episode_N.txt` 降级为派生物，由规划/重置工具在同一把项目锁内随账本一并重写并清理账本之外的残留文件，不一致窗口为零；`_remaining.txt` 废除。存量项目沿 ADR 0022 启动迁移只盖版本章，不反推位置记录：它们的集照常消费，要重新规划则先做一次全量重置。

## Considered Options

- 维持物理文件真相源、仅包装更可靠的单一工具：对账依据依旧缺失，"不同集生成了相同内容"类事故无从检测。
- 独立账本文件或 DB 表：集的概念裂成两处需要对账；DB 与"项目级数据一贯在文件系统"的分层相悖，导出/迁移/备份路径全部复杂化。
- 不派生物理文件、下游按范围直读源文：三个预处理 subagent 与 Web 端展示全要改造，爆炸半径过大。
- 消费时按需派生：永不陈旧，但"agent 记得先调派生工具"把可靠性又押回流程遵循。

## Consequences

- 新 session 接续 = 读账本，废除 Glob 推断集数与 `_remaining.txt` 进度指针。
- 重置波及已消费集（已生成 script_plan/剧本/媒体）需显式确认，重新规划到这些集号时其下游产物失效。失效是标记（stale）而非删除：状态检测把该集拉回待预处理，重做沿现有覆盖/版本机制替换，旧版可回滚——贵重媒体产物不因重新规划丢失。
- 手工编辑或重命名 `episode_N.txt` 不再被支持——修改走账本重派生。
- 手动预拆分上传（`source/` 下只有 `episode_N.txt`、没有任何能派生出它们的原文）时，这些文件就是源文：源文枚举、源文修订、资产清单范围与工作流路线共用同一判定（`episode_files_are_derived`）按它们计算，而不是把它们当派生物排除后报「缺源文」；账本条目由分集规划器与内容确认共用的孤儿登记补建（无 source_range），工作流状态读取时只在内存补建、不落盘，路线从资产清单直达逐集脚本规划。`source/` 另有原文时 `episode_N.txt` 仍按派生物处理。
- 没有 source_range 的账本条目（存量项目遗留、或手动预拆分上传）不参与规划：物理集文件即其最终记录，下游消费不受影响，plan 一律拒绝执行并指路全量重置；部分重置时，若这类条目位于保留段则拒绝执行，若位于重置范围内则随该范围一并清除。不按内容反推坐标——派生文件与源文的差异只可能来自人工编辑，近似锚定会让账本失真，宁可让老项目一次性重置进入新机制。
- source_range 绑定的是规划当下的原文内容，原文被替换后会让坐标失真而无从察觉；source_fingerprints 把这条隐含前提显式化为可机械校验的证据，plan 提交与部分重置的前置校验均比对，不一致即拒绝并指路全量重置。

## 集原文的三种来源（修订）

一集的集原文有三种来源：由分集规划从整本源文切出的一段范围（记 `source_range`）；该集自带的一份原文（创作者逐集上传或直接填写，集文件即该集的源文）；或者没有原文（手写脚本）。后两种是与规划切出并列的正常形态，不再是「预拆分例外」或「存量遗留」：

- 集文件是派生物还是源文，由账本条目记录的来源决定，不再按 `source/` 目录里有没有整本原文整体推断——同一项目可以既有整本源文，又有自带原文或没有原文的集。
- 自带原文或没有原文的集不占用整本源文，也不挡分集规划：分集规划只消费整本源文，新集号从当前最大集号往后接续，读取起点取规划游标。
- 重置分集规划只作用于规划切出的集；重置范围内夹有另外两种集时拒绝执行，并点名这些集，由创作者先删除它们或把重置起点移到它们之后——否则重新规划出的集会排到这些集之后，集序与原文顺序错位。
- 自带原文的集可以编辑其原文；规划切出的集文件仍是派生物，修改走账本重派生。
