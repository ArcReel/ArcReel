# Agent 入库须有用户明确要求，工具提交后立即返回

把图片上传到供应商账号可能改变其使用与费用。Agent 仅在对话里收到用户明确要求时发起入库，工具要求 `user_requested=true`，缺少即拒绝。该字段是调用前自检，用户意图仍以对话为准。供应商的审核拒绝不是授权，上传也不授权自动重跑生成。

查询、上传、导入已有素材和解除关联共用 Web 服务与 [ADR 0087](0087-agent-toolset-single-declaration.md) 的工具声明。审核时长不可预测，上传和刷新只提交后台处理并立即返回，有需要时再查询状态。配置入口仍由设置页管理，供应商素材的远端管理仍在供应商控制台。
