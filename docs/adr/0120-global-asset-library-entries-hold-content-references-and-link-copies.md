# 全局资产库以条目键持有正式对象和供应商素材关联

全局资产库没有项目版本历史。每个条目（含衍生图）用 `asset-library:<条目 ID>` 持有引用，每张图片用独立内容身份、摘要与定位。条目换图即更换内容身份，避免新图继承旧图的供应商关联；字节相同的图片可以共享底层正式对象，但各自的关联仍独立持有。旧库条目缺少内容身份时按本地图片解释，重新保存后才可携带关联。

入库、换图和应用到项目时都经正式提交按当前设置选择目标保存位置，源图位置不限制目标位置。每个条目独立持有引用，删除可一次撤下该条目的全部引用，剩余持有方保留其对象。用整个库作为单一持有方会让删除一条记录时必须逐图枚举，以免漏撤引用。回收契约见 [ADR 0118](0118-formal-objects-retained-by-holder-references-and-collected-in-one-place.md)。

保存到库和应用到项目时，按实际字节摘要复制选定且可用的供应商素材关联，保留冻结的云账号与范围。各方换图、删除或解除关联只影响自己的副本。未完成任务不复制，避免再次入库。应用到项目时关联复制参与版本提交，失败回滚本次应用。工作文件由同一缓存清理入口管理，见 [ADR 0117](0117-evicted-work-files-count-as-present-by-recorded-digest.md)。
