# 批量视频统一准入，入队和执行按目标报告结果

Web 与 Agent 均先对整个目标集合做统一准入评估，再创建任务。批量准入共用[规则折叠](../../lib/generation/batch_admission.py)和[服务端请求投影](../../server/services/admission/video_batch_admission.py)。两端逐目标报告阻断、所需确认或放行，避免按前端循环逐一提交，直到遇到第一处缺口才发现已经为半批内容付费。

参考生视频只因参考图超限而不能执行的目标单独剔除并报告，余项仍整体准入。超限目标若还有档位确认以外的阻断问题，整批仍被扣下。剔除后无需确认该目标的费用。分镜图和宫格批量也逐项报告参考图超限。超限需要修改该单元的引用或模型，剔除可以避免阻塞其余目标，同时保证未提交的目标不会计费。

准入结论与入队结果分开。业务层受阻、待确认、放行或部分入队都返回逐目标结果，HTTP 错误用于真正的请求错误。顺序入队中断时保留已创建任务，未创建的目标报告入队失败，之后可按缺失补齐。供应商执行每项独立成败。准入先查在途任务，提交争用仍由队列去重并报告。

费用确认绑定目标与申请档位选项。只有同档全部可报价时才显示合计。worker 在执行时按当前正式内容重投影，避免确认之后的修改被旧快照覆盖，见 [ADR 0056](0056-execution-predicates-same-source-as-request.md)。旁白交付不参与视频准入，见 [ADR 0089](0089-single-speech-owner-per-video-unit-narration-delivery-per-project.md)。
