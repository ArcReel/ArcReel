# 产物清单记录事实，产物时效在读取时判定

产物清单登记正式产物的身份、路径和生成依据摘要。读取时以当前项目与上游产物投影期望依据，再与登记条目比对。扫目录只能发现文件，写时另存时效状态则要求所有内容修改同步更新，容易在外部编辑、恢复和中途失败时留下失真的状态。

- `current` 与 `stale` 都可查看、参与成片与导出，缺失补齐只生成 `missing`，重做过期产物须显式选择。清单或依据读不出时报告 `blocked`，避免把数据故障变成自动付费。
- 产物时效、队列任务状态、整批准入结论和逐条执行结果独立表达。重生失败时，先前登记的产物仍可能是 `current`。批量生成的提交边界见 [ADR 0061](0061-batch-video-admission-all-or-nothing.md)。

## 生成依据

- 登记和比对共用同一个构造器。视觉产物追踪正式内容与直接上游产物，旁白配音追踪旁白正文。供应商、模型、音色、配音语速、像素分辨率、种子、音轨开关和渲染器版本属于下一次生成的配置，修改时不追溯评判已有画面与旁白配音；音色和配音语速随模型整体继承，将其排除出生成依据可避免切换全局默认模型连带令已有旁白配音过期，实际合成参数由版本记录独立保存。字幕草稿、呈现模型、剪映草稿与成片等下游产物仍按实际选中的媒体、字节、时长和字幕内容判定产物时效。正式脚本以项目的持久提示词上下文为依据，内容确认后的脚本规划不再是它的输入，见 [ADR 0080](0080-review-confirm-materializes-script-prompt-authoring-fills-pending.md)。
- 分镜图、宫格图及切格分镜的引用依据以发给模型的编号、参考角色与内容指纹为准。能对应参考图的名称替换为「图 N」，无法对应的提及原样保留。宫格按冻结的参考记录重放，改名需在同一事务里迁移记录，见 [ADR 0057](0057-asset-name-as-identity-cascade-rename.md)。资产图、视频引用声明或台词里的资产名称仍可能是模型实收内容，照常进入依据。
- 作者上传的资产图、分镜图、视频，以及从全局资产库应用的资产图都是成品。当前文件与选中的手动上传版本一致时，按字节本身登记；修改提示词、引用、画风或本体图不会改变这些成品的时效。成品与生成版本可双向切回：切回生成版本时按生成输入判定，切回成品时按字节登记。手动上传视频以自身字节依据作为上游成品进入统一的呈现模型与下游交付依据，派生的字幕草稿、呈现模型、成片和剪映草稿照常随旁白配音、剧本发声及视频版本变化判为过期。宫格联合图是待切分落格的中间图而非成品，手动上传时按当前生成输入登记。读取失败显式报告，避免把无法确认来源的成品改用另一条依据。

## 宫格联合图与显式切格

宫格路线的联合图产出（`status` 为 `completed`）与切分落格（`split_at`）分离，路线锁定见 [ADR 0055](0055-generation-route-locked-at-creation.md)。联合图就绪后不自动切格，避免静默覆盖创作者后来修改过的分镜图；切分落格只由显式切格操作触发。

- 历史兼容按 `split_at` 键是否存在判定：旧 `completed` 记录缺少 `split_at` 键时，读取时以 `created_at` 视作已落格，避免误提示重新切格；显式为 `null` 的记录以及旧 `splitting` 状态（读取时归为 `completed` 且缺 `split_at`）均视为待切分。
- 切格使用的单格目标比例 `video_aspect_ratio` 冻结在宫格记录级，防止项目后续修改宽高比后按新比例中心裁切旧联合图。历史记录缺值时回退到当前项目视频比例；重生成沿用记录的行列与冻结比例并在缺失时补记；手动上传联合图按当前项目视频比例覆盖 `video_aspect_ratio` 并清空 `split_at`。该比例仅冻结在宫格记录级，而非逐版本冻结；将联合图还原到历史版本时仅复位 `split_at` 与非在途的失败态，暂不恢复旧版本对应的比例。代码入口见 [models.py](../../lib/script/grid/models.py)、[grid_split.py](../../server/services/grid/grid_split.py) 与 [grids.py](../../server/routers/grids.py)。

## 文件事实与写入边界

视频与旁白配音在登记时记录内容指纹、字节数及纳秒 mtime。比对时先用字节数和 mtime 快速证明同一版本，出现变化或与清单处在同一时间戳窗口时再计算内容指纹。缺少事实时无法认定为当前。恢复版本、渲染成片等实际消费快照的路径校验快照指纹。图片摘要也可按文件身份与 stat 缓存，但时效比较使用内容摘要。两种优化接受外部修改后刻意还原 stat 可能漏检的代价。远端工作文件的存在与摘要见 [ADR 0117](0117-evicted-work-files-count-as-present-by-recorded-digest.md)。

清单在项目级跨进程锁内原子替换，读取使用完整快照，无需获取写锁。项目元数据锁先于清单锁，付费前复核和激活沿用这一顺序。全量替换和读取成本随条目数增长，保留条目直到正式归属移除，避免按容量裁剪后失去产物的登记事实。代码入口见 [artifact_activation.py](../../lib/artifacts/artifact_activation.py) 与 [artifact_manifest.py](../../lib/artifacts/artifact_manifest.py)。

付费产物的历史保存、当前选中与失败补偿见 [ADR 0124](0124-paid-versions-persist-before-current-selection.md)。

## 升级与归档

升级以项目记录、正式剧本、资产索引和受管宫格记录补录，登记依据与比对依据同源，补录成功即 `current`。生成缺口以缺席事实表示，可证明且可用的产物照常补录。无法计算依据或读不到内容的条目按 [ADR 0098](0098-backfill-keeps-existing-content-gaps-only-gate-generation.md) 处理。

清单只在项目结构达到当前版本时生效。激活先预检和写入整份清单，再提交 schema 版本。版本提交失败时不让新清单提前生效，修复后重跑即可收敛。未升级或迁移失败的项目仍可打开和备份，生成与写入入口共享同一阻断裁决。

归档保留有效清单里的冻结依据，所以导入可能保有过期产物。完整归档能携带仍可自证的旧字幕与呈现模型及其依赖版本，仅当前版本归档只携带对应范围内的内容。未激活项目没有生效的清单可带出，导入时走同一自证补录入口。远端版本与供应商素材关联的归档边界见 [ADR 0119](0119-archives-carry-content-not-storage-locators.md)。
