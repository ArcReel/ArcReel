# 生成要求作者引用的资产已登记且图像可用

用户应能先写作、再补全资产。保存时允许保留未登记的引用并给出警告，但进入付费生成前，所有引用都必须完成登记。角色、场景、道具与角色衍生需要资产图。角色原图用于生成资产图，创作者也可直接上传成品作为资产图。商品原图可直接用于下游生成，理由见 [ADR 0034](0034-product-fidelity-dual-layer-anchor.md)。

准入核对引用登记和资产图字段，执行在提交供应商前核对实际输入。未登记名称、缺失或不可用的资产图、已声明却读不到的原图都给出各自的拒绝原因。商品已声明资产图时，若该图不可用也不能改发仅原图的请求。不可用的上一分镜图可略去，因为它是系统推导的可选连贯性输入。这样可以避免在未征得创作者同意时，付费生成一份缺少明确输入的内容。

最终提示词预览沿用执行输入。时效判定与补录则按 [ADR 0098](0098-backfill-keeps-existing-content-gaps-only-gate-generation.md) 把缺失输入记为缺席，已有产物仍能登记并判断时效。编辑器的正文解析和未登记提示见 [ADR 0064](0064-video-unit-body-is-the-only-truth.md)。
