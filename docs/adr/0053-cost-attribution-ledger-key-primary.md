# 费用归属优先使用调用记录冻结的记账键

调用完成时冻结费用和资源身份。项目预算聚合按冻住的记账键认领图片、视频和音频调用。剧本条目使用其 ID，宫格图片费用用宫格 ID，再按当前剧本中关联的条目均摊。相同记账键和费用类型下的全部调用先按币种汇总，一次估算只认领这一份合计，避免多个条目重复分配同一笔费用。文本调用独立做用量汇总，资产图按产物路径归入项目级资产类型，规则见 [媒体记账入口](../../lib/generation/media_generator.py)。

存量剧本的条目编号可能重复或与所在集不同。给全量历史条目补全局身份会迫使迁移旧剧本和账目，所以保留冻结键优先的归属规则。找不到当前剧本条目的费用保留在项目「未归属」。记账键的编号前缀能定位仍存在的集时，也在该集展示这笔「未归属」。项目合计只计项目级桶，集级展示是同一笔费用的另一种视图。缺少记账键的历史视频或音频只能留在项目「未归属」。
