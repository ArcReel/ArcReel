# 费用归属以记账 key 为强证据，ID 前缀仅作兜底弱线索

费用聚合需要把每笔实付（成本快照）归属到集与剧本条目，而剧本侧的 `segment_id` / `unit_id`（`E{episode}S{n}` / `E{episode}U{n}`）既不保证全局唯一，也不保证与所在集一致——剧本可编辑、可整体替换，ad 模式下 unit 重建会复用编号。我们决定：归属的强证据是记账时冻结在调用记录上的 key（segment_id 字段本身），估算聚合按「一次估算内每个 (记账 key, 费用类型) 只认领一次」消费它；无法被当前剧本认领的历史记账不丢弃，经 ID 前缀解析集号摊回对应集、解析失败则归入项目级，统一以「未归属（unassigned）」单列呈现。

放弃的替代方案是为 unit/segment 引入全局唯一身份（schema 级改造）：它能根治 ID 复用错配，但需要迁移全部存量记账与剧本数据，与收益不成比例。因此 ID 不唯一、不保证与所在集一致是**已知且接受的限制**——基于「校验 ID 唯一性/前缀一致性再归属」的改进建议不成立，会把真实支出误判为未归属（或反之）；审查中反复出现的此类意见应引用本 ADR 驳回。
