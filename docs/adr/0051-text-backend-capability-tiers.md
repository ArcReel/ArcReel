# 文本模型按简单和复杂两档配置

文本调用点分简单和复杂两个档位，归属由代码维护。按调用点逐一配置会让选项随功能增加而膨胀，实际调用也容易漏掉配置项。简单档用于项目概述、风格图分析等任务；复杂档用于分集规划、剧本生成与脚本规划。风格图分析需要图像输入能力，执行模型不满足时给出配置错误。

解析顺序为项目档位、项目默认、全局档位、全局默认。项目默认因此能表达「本项目整体用这个模型」，并可被本项目的具体档位覆盖。缺省后按 [ADR 0099](0099-model-catalog-shared-entries-per-model.md) 处理。内嵌 Agent 的模型经独立的 Anthropic 兼容凭证配置，见 [ADR 0027](0027-provider-secrets-banned-from-process-env.md)。
