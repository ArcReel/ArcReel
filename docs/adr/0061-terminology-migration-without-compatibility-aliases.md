# 领域术语一次性迁移，不保留兼容别名

ArcReel 的产品语言、结构化数据、API 与智能体工具已出现同义词并存和概念错位。领域术语统一时采用一次性迁移：项目及脚本由项目 schema 迁移完整预检、备份并原子升级，数据库由 Alembic 同步升级；REST、OpenAPI、前端与智能体工具在同一发布中切换到新契约，不接受旧字段、旧路由、旧工具名或旧参数。

这是以代码与领域模型的长期清晰度换取一次有计划的升级成本。迁移失败的项目保持旧版本且停止进入创作流程，不允许部分升级；第三方客户端必须随发布更新，前端本地偏好可以重置。禁止为了平滑过渡重新引入双读、双写、别名字段或永久适配器。

参考生视频的视频单元随此次升级收敛为两个独立真相源：`text` 保存正文，`reference_assets` 保存创作者选择的有序参考资产。旧 `shots` 由迁移一次性还原为 `text` 后删除；旧 `references` 改名为 `reference_assets`，不再因正文变化而被自动覆盖。实际发送给模型的 `reference_images` 只在执行期由参考资产展开，不持久化。
