# 剧本骨架按种类登记，规范解析与取证解析分别服务项目配置和已有内容

以创作类型单轴推断骨架曾使项目事件漏掉广告镜头与视频单元。骨架注册表以最终条目种类为键，只登记条目数组和标识等结构事实。各调用方在 [script_skeleton.py](../../lib/script/script_skeleton.py) 中共用这份注册表，校验、编辑和导出各自保有行为规则。

- 规范解析按项目的创作类型与生成路线得出应有骨架。未知创作类型显式报错。
- 取证解析按已有剧本结构判别骨架，用于读、编辑和归档等须支持历史数据的路径。
- 生成按项目路线要求的骨架检查兼容性。分镜族与参考族失配时拒绝，参考路线只读取 `video_units`。路线与数据各有来源，检查不能只看配置，也不能让残留数组改写用户选定的路线。

以两轴组合作为注册键会为多个组合重复登记同一骨架，按脚本类型静默兜底则会掩盖坏数据。两种解析器使调用方能明确表达自己在回答哪一个问题。
