# 成片响度归一是渲染的一部分，BGM 静态增益保持登记时的值

成片的整集混音此前直接封装进成片：各片段的原声、旁白与 BGM 按各自音量相加限幅后，响度完全取决于素材与增益的叠加，同一项目里不同时间线的成片响度可以相差十几 LU。交付目标（−14 LUFS 积分响度、−1.5 dBTP 真峰）只能在混音完成后达成，因此归一作为渲染链路的一步落在 `lib/final_cut/`：整集混音写出后先用 `ebur128` 实测积分响度与真峰，不无声的混音按实测值二遍重编码归一到目标，再与画面合流。BGM 登记时的静态增益（统一到 −16 LUFS，不设峰值上限）保持不变：它决定 BGM 在原声与旁白之间的相对响度，成片归一在叠加之后整体调整，不重写任何一路的音量。

## 规则

- 归一目标是成片的：积分响度 −14 LUFS、真峰 −1.5 dBTP（`lib/final_cut/loudness.py`）。BGM 登记目标 −16 LUFS（`lib/bgm/`）不变，两者不在同一环节生效。
- 混音实测后，积分响度不高于 −70 LUFS 的混音视为无声，保持原样，不放大噪声底；判据与 BGM 登记一致（EBU R128 绝对门限）。
- 实测值提升到目标不超真峰上限时，走 `loudnorm` 二遍线性归一（`linear=true` 加实测参数）：只施加常数增益，积分响度精确落到目标。实测响度范围按目标裁剪、实测门限按选项边界裁剪后传入——这两个值只决定滤镜走线性还是动态分支，线性分支下不参与计算。
- 常数增益会超真峰上限（或实测值不全）时，退回同值的常数增益加 `alimiter` 限幅：积分响度先提到目标，超限峰值压回真峰上限。限幅的包络回落会带走少量积分响度，此类成片按实测偏差记警告。
- 两条路径都保持采样数与时间戳不变：重编码前按混音采样数截止（容器里的 AAC 前置填充不逐代累积），归一后音轨与画面的时长对齐关系不变。
- 成片验收时重测交付文件的积分响度与真峰并记入验收结果：测不出、或偏离目标超出容差（积分 0.5 LUFS、真峰 0.5 dBTP），只记警告，不让验收失败。无声成片不告警。
- 归一只作用于整集混音，不改写 BGM 文件、登记增益、片段音量或旁白音量；这些仍是 BGM 相对响度的唯一来源。

## Considered Options

- **在 BGM 登记处提高峰值上限、按路归一**：每路音频单独归一会改变原声、旁白、BGM 之间的相对响度，等于在登记环节替剪辑做了混音决定；叠加后仍可能削波，需要再叠一层全局处理，两个环节各持一半响度语义。
- **只用 `loudnorm` 二遍（不裁剪、不限幅兜底）**：滤镜在线性判定不通过时回落到动态分支。随包 ffmpeg 7.1 构建的该分支输出损坏：滤镜图对外发出的帧序列采样数是输入的数倍、时间戳错位，封装成 MP4 后音轨时长仍偏离画面约 0.07 秒，逐代重编码还会累积前置填充。成片时长对齐是验收硬条件，不能依赖该分支。
- **归一写成独立的交付后处理步骤（成片再转码一次）**：多一遍全片转码的耗时与画质损失，且交付文件的身份与版本记录要在渲染之外再挂一套产物生命周期；混音后归一只多一次纯音频重编码。

## Consequences

- 成片渲染多一次 `ebur128` 实测与一次音频重编码（无声混音只多实测），耗时按音频秒数计入渲染 deadline；`ebur128` 进入渲染链路的组件自检（P0）。
- 稀疏音轨上常数增益加限幅的落地响度可能低于目标 1 LU 以上（限幅包络回落后整段被压低），验收如实记警告而不是失败；交付文件里的响度值以验收重测为准。
- `lib/bgm/loudness.py` 的实测解析扩展出真峰、响度范围与门限（`LoudnessSummary`），BGM 登记的解析路径沿用；`lib.final_cut` 依赖 `lib.bgm` 的实测与静默判据，与渲染素材对 `lib.bgm` 的既有依赖同向。
- 交付目标按平台差异化（广播 −23 LUFS 等）仍留接口：目标常量集中在 `lib/final_cut/loudness.py`，渲染只读默认值。
