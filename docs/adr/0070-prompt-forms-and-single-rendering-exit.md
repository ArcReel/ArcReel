# 结构化与纯文本都是正式提示词，实发文本共用渲染出口

结构化 JSON 支持字段级投影，纯文本保留创作者已经写定的整体表达，两者均可保存。把文本猜回结构无法保证无损。无论何种形态，最终文本都经媒体对应的统一出口渲染并注入项目画风、反向约束、参考图或发声声明。预览、准入与执行调用同一出口，重复渲染已包装文本时需保持幂等。

产物依据记录正式提示词内容及其形态，切换形态也属于内容变化。系统追加的包装与渲染器版本不进入时效依据，避免模板措辞调整追溯影响已有视觉产物。精确复用某次请求需要独立的执行摘要。模板组织见 [ADR 0077](0077-whole-prompt-templates-with-named-variant-partials.md)，产物时效见 [ADR 0062](0062-artifact-lifecycle-and-currency.md)。
