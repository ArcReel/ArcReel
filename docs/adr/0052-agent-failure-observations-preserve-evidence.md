# Agent 故障观测保留脱敏证据

Agent 启动故障与轮次故障遵循同一套观测契约。外层封装只记录 ArcReel 确知的阶段、时间、项目与会话上下文。故障载荷保留实际收到的异常链、stderr、SDK 消息或上游返回，只遮蔽认证令牌、密码、签名 URL 敏感参数等可冒用身份或产生扣费的秘密值。完整 transcript、正常输出和提示词不另外采集。

轮次故障在 [会话事件日志](0048-session-event-log-single-ui-read-source.md) 写入时定型为系统故障。启动故障即时通过结构化 API 错误返回，两类故障均写入现有诊断日志。历史事件保持原记录，无需新增故障存储。

界面默认显示阶段与一句本地化观测结论。结论仅从 SDK 错误类型、结果状态、上游状态或异常类等结构化证据派生，缺乏证据的事件显示阶段级通用结论。详情保留原始消息、来源和完整脱敏载荷。用户可以复制诊断信息、打开 Agent 设置，或重试启动失败。轮次失败不自动重放，因为工具操作可能已经生效。

这一取舍以原始证据支持诊断，避免从易变的上游文案推断根因。历史事件缺少摘要键时沿用通用结论。
