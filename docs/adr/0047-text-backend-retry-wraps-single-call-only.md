# 文本调用的网络重试在单次调用范围内

结构化生成可能经历原生调用、复验和降级。如果在整个生成流程外层包裹重试，会在降级阶段遇到瞬态错误时重放已经完成并可能已计费的原生调用。重试放在单次网络调用或降级调用的边界。原生复验与降级调度独立，校验失败的输出文本也不会误触发整个流程的网络重试。

OpenAI 兼容通道用独立结果表示 schema 不兼容，使代理包装出来的错误不走网络重试。Instructor 内部包含校验循环，异常可能触发降级边界自身的重试预算，预算耗尽仍只影响降级调用。结构化降级的选择见 [ADR 0014](0014-instructor-selective-structured-output-fallback.md)。
