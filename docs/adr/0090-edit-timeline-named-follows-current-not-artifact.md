# 剪辑时间线保存独立修订，剪辑片段跟随视频单元的当前版本

每一集可以拥有多条具名时间线。新建时间线时，可按脚本顺序装配整段画面，也可复制已有时间线。每次编辑都会追加一条不可变修订，回滚同样以追加新修订的方式完成。提交编辑时需声明所基于的基础修订：若期间有其他操作修改了同一片段，系统会报告冲突；互不重叠的改动则可直接合并应用到最新修订。成片与剪映草稿必须基于一条已保存的时间线生成。时间线本身属于正式内容，只有渲染和导出的交付物才纳入 [ADR 0062](0062-artifact-lifecycle-and-currency.md) 的产物时效管理。

片段引用视频单元，播放该单元选中的当前版本。入出点同时记下所依据的版本，换成别的版本就忽略原裁切、提示复查。钉住每条时间线自己的视频版本会使界面预览与两种导出产生多套选中状态。分镜和视频单元 ID 只分配、不复用，防止旧裁切套到另一个视频单元。恢复已删除条目也分配新 ID，见 [ADR 0107](0107-deletion-goes-to-trash-restore-only-adds.md)。

脚本新增和删除不会自动改时间线。读取时报告未使用的新单元与已删除的引用，输出跳过无法播放的已删除引用。系统不能推断创作者有意省略的内容。转场在时间线表达，脚本里的场景切换点继续用于生成输入。支持的转场须同时有剪映非 VIP 预设与 FFmpeg 对应效果，转场窗口不改变时间线总时长。迁移不把旧脚本转场变成自动剪辑。

## 旁白、字幕和 BGM

- 单元的旁白从指定片段起点播放，可延伸到后续片段。重叠、越界和可能遇到原声均提示创作者。成片与草稿仍可输出，成片按实际时间混音，剪映可用独立轨道承载重叠以便精修。旁白交付见 [ADR 0089](0089-single-speech-owner-per-video-unit-narration-delivery-per-project.md)。
- 字幕文字来自字幕草稿，纠错返回脚本。字幕样式固定，成片和剪映分别处理显示与轨道，尽量贴近。成片可选择是否烧入字幕，剪映草稿保留字幕轨。两种产物的身份和修订快照见 [ADR 0095](0095-final-cut-rendered-locally-with-bundled-ffmpeg.md)。
- BGM 按绝对时间置于独立音轨，同一时刻只有一首。原声和 BGM 的音量是剪辑决策，渲染与导出按设定值处理。自动闪避会虚增剪映里不属于用户意图的音量关键帧，因此保留静态音量与显式淡入淡出。

实现见[剪辑时间线服务](../../lib/edit_timeline/service.py)。
