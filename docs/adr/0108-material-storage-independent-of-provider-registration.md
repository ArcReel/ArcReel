# 素材存储与供应商素材关联独立建模

完整交付范围、验收原则与外部实现参考见 [Spec #3559](https://github.com/ArcReel/ArcReel/issues/3559)。

#2249 的供应商人像素材库接入需要表达素材在供应商侧的身份与使用条件；后续对象存储接入则需要改变素材内容的存储位置。两者独立建模：创作流程引用素材身份，素材存储负责保存内容，供应商素材关联连接某个内容版本与供应商侧素材。同一素材可同时关联多个供应商素材，关联不替换原素材的存储。

不把 `local / s3 / volcano` 建模为互斥类型：一张图片可以存于对象存储，同时通过火山素材库审核。混为一个类型轴会让存储迁移、供应商切换与内容替换互相牵制。

仅迁移存储位置不改变内容，不应因此使供应商素材关联失效或改变已有视频的产物时效。不同图片或内容版本的关联彼此独立：角色从图片 A 改选图片 B 时，B 不继承 A 的关联，A 的关联也不因此失效；改选回 A 后，仍可使用 A 自身有效的关联。角色当前选图与图片的供应商素材关联不是同一个状态，不把换图表达为「旧关联过期、需要更新」。具体消费方按用途取得图片内容、访问地址或供应商素材标识，统一引用不承诺消除供应商的审核、权限与能力差异。

从供应商素材库导入图片时，首期要求取得图片内容并保存到 ArcReel 的素材存储，以支持预览、编辑、归档与其他供应商使用；不能取得图片内容的纯远端 ID 素材首期不支持。

本期包含由用户配置对象存储的上传中转，使本地图片可在 ArcReel 内完成上传、供应商入库与后续生成。中转只上传副本并提供有时效的下载地址，不要求 ArcReel 服务本身公网可达；临时对象须有明确的保留与清理规则。

## 新增图片的远端主存储

本期同时交付新增图片的远端主存储，作为上传中转之后的独立阶段。图片持久内容可保存在对象存储，本地保留暂存文件与可清理、可重新下载的工作缓存；只增加云端镜像、仍要求本地完整持久保存，不算完成此能力。

旧图片与旧版本保持原位，不批量搬迁，支持本地与远端图片并存。音视频、成片、项目文本、数据库与 Agent 工作目录不在本期远端主存储范围内。图片的预览、生成消费、产物时效与规划、版本恢复、回收站、归档及全局资产应用必须完整适配，不能以首期仅覆盖新增图片为由省略生命周期。

上传中转与远端主存储可复用连接配置，但正式素材不进入中转副本的过期清理范围；仍被版本历史、回收站或其他有效引用使用的正式内容须保留。上传失败不发布新版本，正式提交保留原有的内容校验与失败回滚保证。范围证据见[增量评估](../research/material-object-storage-scope.md)。

提供可实际执行的未使用缓存清理入口或策略，保护使用中的工作文件。缓存缺失不能直接视为正式素材缺失；时效与规划按素材内容版本及其存储定位处理，并保留现有内容验证和并发一致性保证，不无条件信任记录摘要。

## 全局存储选择

默认使用本地存储。用户配置并启用对象存储后，新生成、上传或导入的图片使用远端存储，不为每张图片或每个项目增加存储选择。切回本地只影响后续新增图片；已有图片仍从各自原位置读取，不随全局开关自动搬迁。只配置上传中转不等于启用远端主存储。

## 生成时的输入选择

有适用于本次调用的有效关联时使用供应商素材；没有适用关联时沿用普通图片输入，不因尚未关联而一律阻断。供应商拒绝普通图片后，提示用户主动上传到供应商素材库，不自动上传，也不自动重试生成。适用于本次调用的已有关联失效时明确提示，不静默回退为普通图片输入。

供应商素材库的账号、站点／区域和项目范围在配置边界显式绑定到可使用它的推理凭证。生成按实际调用凭证与绑定范围匹配关联，不仅按供应商名称或域名推断；无绑定时按无适用关联处理。更换凭证内容或 endpoint 后须重新确认绑定，历史关联保留原范围，绑定不替代供应商权限校验。支持素材引用的自定义端点遵循同一规则。

用户为当前内容版本和调用范围选定的入库任务仍在处理中或已失败时，按适用但不可用处理，提示等待或失败原因，不静默回退。每个内容版本在同一调用范围内有明确选定的关联或入库任务；异步完成不改选另一张图片，也不复活已解除的关系。

## 复制素材与关联

同实例内以相同内容保存到全局资产库或应用到其他项目时，复制供应商关联及其原调用范围。目标独立持有关联，解除或替换目标关联不修改来源；生成仍按目标实际调用凭证判断适用性。复制不授予其他账号或实例使用资格，归档不携带凭证。

## 首期管理边界

首期提供上传到供应商素材库、选择已有供应商素材与解除关联。供应商素材库内素材的改名和删除留在供应商控制台；解除关联或删除 ArcReel 内图片都不连带删除供应商素材，避免影响其他项目或应用的使用。这一限制不替代 ArcReel 自有对象存储中正式内容与中转副本各自的清理规则。界面动作使用「上传到火山素材库」「从火山素材库选择」「解除关联」等具体措辞，不使用「登记」。

## Agent 操作

向 Agent 提供上传到供应商素材库的能力，允许按用户明确指令执行；生成被拒绝不构成自动上传或重试生成的授权。Agent 同时可以查询、选择已有供应商素材与解除关联，凭证配置留在设置页，供应商素材库的远端改名与删除仍留在供应商控制台。

新增工具遵循 ADR 0087 的单源声明，由 ArcReel Agent 与外部 Agent 共用相同领域行为。两种宿主只保留现有的项目确定方式与长任务等待方式差异。

本决策记录已确认的领域边界，尚未实施。中转连接配置的具体字段、临时对象保留期限、缓存与正式对象清理实现由后续技术方案确定；本决策不批准新增公开取图路由或存量媒体批量迁移。
