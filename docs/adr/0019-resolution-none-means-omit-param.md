# 未设置可省略的分辨率时交由供应商决定

分辨率与比例各有独立参数、且协议允许省略分辨率时，未设置的分辨率保持为空，两条视频路线在请求中均省略该参数。显式设置仍按项目设置及存量兼容规则解析。选择由供应商决定缺省画质，避免在各调用通道维护一份对供应商默认值的猜测。

需要用像素尺寸表达比例的请求按 [ADR 0011](0011-aspect-ratio-first-media-size.md) 得出宽高。视频请求的档位约束和报价按实际下发的分辨率求值，见 [ADR 0086](0086-video-request-facts-evaluated-once.md)。
