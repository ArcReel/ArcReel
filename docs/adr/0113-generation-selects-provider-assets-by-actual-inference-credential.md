# 生成按实际推理凭证选择供应商素材关联

参考生视频根据实际调用通道的推理凭证与绑定范围，为每张参考图选择发送图片或使用 `asset://`。选择只发生在调用端点声明支持素材引用的槽位，编排不按域名或型号猜测。当前声明与范围核对见[参考图关联投影](../../lib/script/reference_video/provider_asset_links.py)和 [ADR 0110](0110-asset-library-binding-confirmed-by-credential-digest.md)。

内容版本摘要必须与实发图片一致。没有适用关联时照常发送图片。已选关联尚不可用、失败或缺少素材 ID 时，给出原因并在写入执行检查点前拒绝。静默退回普通图片可能重现审核失败，还会让用户误以为入库已经生效。供应商拒绝后提示明确的补救途径，由用户决定是否入库与重新生成，见 [ADR 0114](0114-agent-asset-library-upload-needs-explicit-request.md)。

预览、报价与执行共用选择规则，执行暂存后按实际字节复核。素材引用原位替换对应图片，序号和数量不变，跳过该槽位的图片读取、压缩及请求体占用。使用的素材引用记录在执行检查点和请求摘要中，旧检查点照无引用解释。关联选择不进入视觉产物的内容依据，同样的图片按内容计算时效。
