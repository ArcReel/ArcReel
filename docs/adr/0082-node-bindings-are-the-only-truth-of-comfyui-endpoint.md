# ComfyUI 的能力和执行由同一份节点绑定决定

原生 ComfyUI 导出的节点图没有 ArcReel 参数对应关系。导入时系统可自动给出候选绑定，经用户确认后存入端点定义的 `bindings`，执行阶段只读取这份已保存的绑定。每次提交重新推断会让同一份定义在歧义和图变更时指向不同节点。采用导入推断和人工确认，也无需安装专用节点。

节点绑定区分已绑定、经确认不支持和未推断。提示词和产物必须绑定，尚有歧义时需选定。重导入时节点类型与标题帮助找回绑定，确认后才更新定义。推断规则与优先级见 [ComfyUI 推断实现](../../lib/custom_provider/comfyui/inference.py)。

通道的输入能力和音轨从节点绑定推导。把另一份能力声明存进定义或供应商模型会与实际能驱动的节点分歧。用户可为有时长驱动能力的视频端点调整可选档位，这属于使用偏好，存为可选时长能力覆盖。默认时长只有能写回原生帧数的整秒档位。没有帧数绑定、缺帧率来源或无法求出可回写的档位时，端点可声明合法空集。预检、规划与执行共同接受这个状态，界面禁用相关控件。见 [ADR 0086](0086-video-request-facts-evaluated-once.md) 和 [ADR 0104](0104-capability-sources-split-by-dimension.md)。

宽高均已绑定时，按项目比例和分辨率求值。未选分辨率时取 workflow 字面值的短边。任一侧未绑定时，保留 workflow 的宽高。可用帧率与时长按照 [请求构造器](../../lib/custom_provider/comfyui/request_builder.py) 换算帧数。负向提示词从正文抽出，只有负向提示词节点绑定时才发送，避免它被当成正向条件。
