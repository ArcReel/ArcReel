# 第三方 API 文档在仓库中只保存官方链接与代码入口

第三方接口和价格会独立更新，复制整份文档会让维护者在过时副本上作判断。维护[供应商与调用端点索引](../api-docs/AGENTS.md)，记录依赖的官方页面与 ArcReel 的消费代码。运行时事实由模型目录、调用端点及实现持有。开发 SDK 接入时查官方在线文档，并用[本仓 SDK 核验约定](../../.claude/rules/agent-runtime.md)核对。

固定版本的上游源码或本仓契约测试可证明历史语义。测试仅保留复现契约所需的最小请求、响应样本及来源。采用索引会失去离线上游全文和固定行号，换来更少的复制漂移与维护开销。
