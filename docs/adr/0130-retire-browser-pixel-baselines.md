# 页面级浏览器测试退役像素截图基线

[#4139](https://github.com/ArcReel/ArcReel/issues/4139) 核查了 2026 年 10 月 3 日以来触及截图目录的 113 次主线提交、38 个去重合并 PR 和项目教训记录。样本中，由已有 PNG 基线单独检出非预期视觉缺陷并促成产品修复的已证实案例为 0。相反，预期的描边调整一次就需重录 339 张图（#3477），依赖小版本抗锯齿变化（#3511、#3602）与文案微调（#3902）也反复触发跨分片失败；真正检出逐字光标错位和矮屏对比度缺陷的是命中位置断言与无障碍检查（#3579、#3136、#3374）。

页面级浏览器测试取消版本控制的 PNG 基线、像素比对门禁和容器重录流程。本决定取代 [#2991](https://github.com/ArcReel/ArcReel/issues/2991) 与 [#3039](https://github.com/ArcReel/ArcReel/issues/3039) 的像素截图门禁约定。

自动化按具体风险验证可观察行为，例如点击可能被遮挡的控件、沿键盘路径检查焦点、测量编辑器几何与逐字命中位置。布局探针和无障碍扫描只覆盖各自的断言范围；其余外观变化由人工视觉验收判断，诊断时可查看失败 trace 或按需截图。
