# 广告/短片作为第三种创作类型，共用集与路线骨架

广告/短片需要商品与创意简报等专属内容，但仍须使用同一套版本、制作状态、归档、费用与导出机制。将 `ad` 作为第三种创作类型，以一个集承载单条成片，界面隐藏分集语义。

生成路线是独立维度。广告/短片的分镜图生视频使用镜头列表，参考生视频使用统一的视频单元列表。早期归档中的 `shots` 与 `reference_units` 由项目迁移转换成自包含单元，保留可证明的身份、边界与历史产物。广告/短片未开放宫格路线，因为单格分辨率与商品保真目标冲突。现行骨架见 [ADR 0045](0045-script-skeleton-registry-dual-resolvers.md)，商品参考见 [ADR 0034](0034-product-fidelity-dual-layer-anchor.md)。
