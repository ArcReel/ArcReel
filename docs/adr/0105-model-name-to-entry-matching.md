# 模型条目按当前名字匹配，用户绑定优先

中转站可能在 API 模型名前加命名空间、改大小写或更换整段名字。自动匹配每次使用当前目录，优先级依次为精确官方名、精确模型别名、归一化官方名、归一化模型别名。归一化忽略大小写、去掉命名空间并将点号与连字符等同。日期与特殊版本后缀保留，因为快照价格或能力可能与主模型不同。别名由目录发布数据维护。

显式绑定可指定自定义供应商模型或 Agent 凭证档位的条目，绑定无效时继续按名字查。两栖模型按端点媒体类型消歧。发现模型时尚未选端点，先查唯一条目，再用提供或推断的媒体类型解决歧义。内置官方清单直接按其明确的条目引用和 API 模型名定位。参见 [匹配实现](../../lib/catalog/entry_matching.py) 与 [模型发现](../../lib/custom_provider/discovery.py)。

自动匹配结果不存储，新目录可纠正原先错配的名字，无需再迁移持久化引用，历史冻结费用也不会重算。对应不上条目的模型仍可按所挂端点调用，无价目表时显示未定价。可选时长按名字预设回落；其他生效能力按 [ADR 0104](0104-capability-sources-split-by-dimension.md) 求值。发现模型时可以按名字预填端点，保存后请求结构由实际挂接端点决定，发送的仍是原 API 模型名。百炼和 Vidu 视频的提示词长度仍用对应条目的官方名与别名识别，没有条目时用 API 模型名。
