# 入库任务与供应商素材关联共用记录，关联冻结调用范围

素材上传属于异步流程：收到素材 ID 时供应商可能尚未完成取图，请求也可能在供应商实际收妥后才发生超时。从用户发起上传起即登记关联和任务状态，生成端才能分清「没有关联」与「有关联但尚不可用」。每个内容版本在同一调用范围至多有一条选定记录。由用户显式选择或解除，后台只推进状态。解除后的迟到结果不会重新选定，换图也不会把旧图结果挂到新图。

调用范围由冻结的云账号身份、站点、区域和供应商项目组成。用可原地编辑的账号记录 ID 作为范围会在换 Key 后选中旧账号的素材，或用新 Key 接着处理旧任务。当前用带版本前缀的站点与 Access Key ID 摘要确认身份，不保存原始 Key 或把 Secret Access Key 纳入摘要。真实云账号标识尚需供应商接口、权限与跨站验证，摘要可以离线计算并避免跨账号错误复用。代价是同一云账号换 Access Key ID 后也要重新建立关联。只换 Secret Access Key 不改变身份，多条记录使用相同 Key ID 时共享调用范围。存量记录按可证明的旧账号范围补写身份，范围无法确认时使用不可匹配的值。

提交结果不确定时，以本次上传的唯一名称查询已有素材，避免再次创建。进程在提交中途退出也按结果不确定继续核对。账号身份变化时，旧关联保留且对新身份不可选，未提交任务失败，处理中的任务停止自动查询。

中转副本独立登记。下载地址有效期 24 小时，副本在任务有结果时自写入起至少保留 1 小时，无结果时保留至地址过期后 1 小时。这是本应用为异步取图留的余量。清理失败按退避重试。连接离开旧桶时按 [ADR 0116](0116-remote-content-versions-saved-by-formal-commit-with-object-references.md) 选择清理或放弃副本，受影响的入库任务停止。直接为正式对象签发地址时的引用见 [ADR 0118](0118-formal-objects-retained-by-holder-references-and-collected-in-one-place.md)。

范围与验收见 [Spec #3559](https://github.com/ArcReel/ArcReel/issues/3559)。
