# 项目保存风格模板的展开快照

选择风格模板时，把展开后的完整文本写进 `style`，并在 `style_template_id` 保留来源。模板更新只影响再次选用的项目。生成时展开会让同一项目在模板升级后突然换画风，破坏已有成片的一致性。

模板与自定义风格参考图互斥，也可以都不设置。创建、编辑和迁移统一保证至多生效一个来源，显式清空模板时同时清空展开文本。早期短标签由项目迁移解释，已保存的快照继续使用。模板组织规则见 [ADR 0077](0077-whole-prompt-templates-with-named-variant-partials.md)。
