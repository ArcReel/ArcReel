# 迁移与导入保留可用内容，生成缺口在生成时处理

升级曾以今天的生成输入约束审核已经付费的产物。旧描述为空、没有资产图或出现混合发声时，即使产物可用也会消失。现行补录以项目和内容事实投影依据，未满足的生成输入记为缺席。升级中可证明且内容可用的正式产物登记为 `current`，归档导入保留包内有效的冻结依据。之后补齐输入导致依据变化时再按常规判为过期。发起新生成时仍严格拦截缺口，见 [ADR 0073](0073-generation-entry-requires-registered-assets-with-sheets.md)。

旧视频缺少类型化来源时，[v12→v13 迁移](../../lib/project/project_migrations/v12_to_v13_legacy_media_provenance.py) 为仍由剧本引用、与选中快照一致的视频按迁移当下的项目事实补写来源。补录与比对采用同一个构造器，`provenance_backfilled_at` 区分补录与生成时冻结的事实。相比在每个读入口长期支持降级判定，一次补写能保留统一的时效口径。旧旁白配音没有实际合成时的模型、音色与语速，据当前配置无法证明来源，仍不补录，报告里说明未能带入的产物。

- 能按确定规则修复的旧结构就修复，取舍时保留备份。导入时为缺少定义的剧本资产补占位。读不到的草稿原样保留，涉及该草稿的产物不登记。
- 因数据拒绝整个项目，限于项目文件、剧本、版本记录或产物清单读不出，以及导入包不安全。磁盘与写入故障等迁移执行失败仍阻断，排除故障后重试。项目入口与维护约定见 [ADR 0022](0022-project-json-schema-versioned-startup-migration.md)。
- 迁移报告说明修了什么、为何取舍、补了什么占位及未能带入哪些产物。普通生成缺口由操作入口报告，避免迁移报告埋没用户需要审阅的变化。非空报告在升级后告知一次，导入前确认一次。

产物登记与激活见 [ADR 0062](0062-artifact-lifecycle-and-currency.md)，归档修复和存储定位见 [ADR 0119](0119-archives-carry-content-not-storage-locators.md)。
