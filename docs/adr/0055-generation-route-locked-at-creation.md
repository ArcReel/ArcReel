# 项目创建时固定生成路线

项目创建时选择分镜路线（`storyboard`）或参考生视频路线（`reference_video`）。分镜路线把单张分镜作为视频首帧，参考路线直接组织资产参考图。剧集、剧本与配置入口共享项目路线，避免同一剧本在规划、报价、生成和导出时按不同契约解释。

宫格改变分镜图的生产方式。大图生成并切分后仍逐镜头用单张分镜生成视频，因此宫格是分镜路线可切换的装配选项 `grid_storyboard`，广告项目不支持该选项。路线字段只在创建时写入，跨路线创作以新建项目表达。

旧项目的 `grid` 值在 [v4→v5 项目迁移](../../lib/project/project_migrations/v4_to_v5_generation_route.py) 展开为分镜路线与宫格开关。历史剧本仍可查看和编辑。Agent 的生成入口遇到剧本骨架与路线不匹配时要求重新拆分。视频模型怎样按路线及可用输入选择，见 [ADR 0054](0054-media-model-capability-buckets.md)。
