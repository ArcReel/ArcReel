# 路径覆盖按供应商模型及请求名存储

中转站常沿用官方协议，但改写请求路径。自定义供应商的模型可按端点声明的请求名整条替换路径，例如分别配置提交与轮询。覆盖适用于 Python 和声明式端点，对请求结构或响应格式的调整仍使用声明式定义。按供应商和端点共用配置会让需要不同路径的两个模型被迫拆成不同供应商，按模型保存以少量重复填写换取独立配置。

被覆盖的请求相对于用户填写的原样 `base_url` 组装，跳过该请求原有的地址归一化。路径可使用该请求原本提供的占位符，所带查询整体替换原查询。模型发现及连通性检查照常使用供应商的地址与协议。换端点会清除覆盖，定义更新后已不存在的请求名被忽略。从响应中取得的独立下载地址无法覆盖。代码入口见 [路径覆盖实现](../../lib/custom_provider/path_overrides.py)。

视频恢复从执行快照取提交时的协议和路径覆盖。历史快照保存归一化后的地址，根据当前配置的「原样值到归一化值」差量还原覆盖所用的原样地址。仅保留相同归一化差量的前缀变化可可靠回放，例如端点对新旧前缀均追加相同的 `/v1`。差量变化时，归一化结果可能对应多个原样地址。用户改动路径覆盖本身属于协议漂移，按 [ADR 0007](0007-orphan-tasks-not-requeued-on-restart.md) 处理。
