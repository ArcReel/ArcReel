# 图片编辑以当前图和修改指令创建新版本

重新生成会按原生成提示词重画整张图，无法保留当前图中已满意的细节。独立的图片编辑任务在执行时以当前图为唯一参考，以修改指令为唯一提示词。成功后新图成为当前版本，失败时原图和版本历史仍在。原生成提示词不改，再次生成仍按原提示词，需要找回编辑效果时从版本历史恢复。

图片编辑固定走图生图能力。入队前检查模型是否可用，供应商提交前仍按执行时输入复核。只使用当前图作为参考，避免其他自动参考稀释原图。角色衍生以本体资产图为底图的规则见 [ADR 0072](0072-character-derivative-sub-identity.md)。
