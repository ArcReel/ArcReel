# 集的身份独立于标题和播出顺序

旧集号同时决定路径、条目 ID、产物、费用归属与显示顺序，重排就要求改写所有引用。现有整数保留为内部集 ID，只增不复用。播出顺序由分集账本的条目顺序决定，创作者用标题和当前播出位置识别集。

切出集之间沿源文顺序，自带原文和无原文的集可以插在任意位置。重新规划为新集分配新 ID，已有产物不按位置转移。手工调整同一集边界时可以沿用集 ID，见 [ADR 0032](0032-episode-planning-server-side-batched.md)。

ID 分配要覆盖已登记集与仍能指向旧身份的产物、任务及调用记录。条目 ID 中的集前缀是内部引用，位置变化不改前缀。分集账本及原文来源见 [ADR 0031](0031-episode-ledger-single-source-of-truth.md)。
