# 外部图片 URL 供给边界与生成请求 URL 传图

部分模型接口和第三方聚合网关不接受内联 Base64 data URL，要求传入外部可拉取的图片 URL；火山与 BytePlus 供应商素材库入库同样依赖外部取图地址。ArcReel 建立单一的外部图片 URL 供给服务，统一服务于模型生成任务（`task:`）、真实端点试跑（`trial_run:`）与供应商素材库入库（`ingest:`），明确限定两种可控来源并排除第三方图床：

- **对象存储预签名 GET URL 优先**：已配置对象存储连接时优先签发限时预签名地址；已在桶中的正式对象直接签发原图地址（零回源下载、零二次上传）并登记持有方保护引用，本地图片则上传中转副本后签发。对象存储发生访问故障时明确报错，不静默降级至实例公网出口。
- **可选实例公网单文件短时回源兜底**：仅当管理员在设置中主动配置实例公网访问地址且未配置对象存储时启用；纯本地部署留空即关闭。公网回源采用独立只读路由，绝不复用随认证开关放行的普通下载 token，始终强制校验独立单文件高熵凭证并绑定租约标识、冻结内容摘要、用途与到期时间。冻结副本存放在数据根下的独立受管目录，跨重启与整项目删除存活，接口不接受项目名或路径参数、不可枚举。

外部取图租约统一沿用 [ADR 0111](0111-asset-upload-job-and-link-share-one-record.md) 的保留口径（签名有效期 24 小时，确认被拒或受理至终态且自签发满至少 1 小时后清理，提交结果不明或重启孤儿保留至过期后 1 小时兜底）。输入保持在执行冻结阶段固定，URL 推迟到外部提交前签发；已取得供应商任务号的续跑不重新准入或重发付费请求（见 [ADR 0123](0123-provider-submission-and-retrieval-retry-boundaries.md)）。

调用协议层按具体端点、请求变体与图片槽位声明 URL 传图能力（涵盖声明式端点 `encoding: "url"`、支持 JSON URL 或原生 URL 参数的内置图像/视频通道），并在供应商模型层级提供实例本地显式切换开关；默认沿用端点原有传输方式，不静默将 Base64 改为 URL，以免产生意外流量费用或扩大媒体披露范围。走 URL 传图的槽位跳过内联体积压缩（见 [ADR 0012](0012-reference-compression-conservative-ceiling.md)），同时保持适用的供应商素材引用 `asset://` 优先于图片 URL（见 [ADR 0113](0113-generation-selects-provider-assets-by-actual-inference-credential.md)）。

范围与验收见 [Spec #4205](https://github.com/ArcReel/ArcReel/issues/4205)。
