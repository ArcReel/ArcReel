# 整本源文显式排序，文件改动按文本对齐重映射切出集

整本源文可由多个文件组成。文件清单记在项目内，可重排，新增文件默认追加。切出集以「文件 + 文件内偏移」记录范围，范围可跨文件，播出顺序仍遵循源文。按文件名排序或改动任意文件便全量重新规划，都会把局部编辑放大成大范围重做。源文件类型独立于文本，见 [ADR 0036](0036-screenplay-source-kind-extract-first.md)。

替换和编辑按规范化文本对齐，文字未变的切出集只移动偏移，内容变了才标为过期。整段被删除的集按移除切分处理，有产物的集转为无原文并保留产物。两集分界处插入的文字归前一集，落在切分范围外的文字留待规划。插入文件在跨文件集的范围内则归该集，否则也是未切分原文。调序维持内容未变的集及其状态，跨越被移动文件边界的集则保留与原起点仍连续的范围。其他来源的集依 [ADR 0032](0032-episode-planning-server-side-batched.md) 的剧情锚点落位。

源文由服务外改动时，指纹识别变化，确认后以旧文本快照走同一重映射。未处理的指纹冲突会阻断规划，避免规划使用未确认的切分坐标。处理后可继续规划，无须全书重做。长段重写的映射只是近似结果，过期状态为创作者提供复查信号。实现见 [source_file_changes.py](../../lib/episode/source_file_changes.py)。
