# 角色衍生是同一身份的不同外观

同一角色可能换装、变身或易容。衍生挂在本体下面，保有自己的外观描述和资产图，共享本体的身份、声音和说话人绑定。剧本以 `@[角色/衍生]` 或相同的分镜引用值表达外观，说话人归本体。把衍生登记成独立角色会重复管理声音和身份信息，也会让 Agent 把不同外观误认为不同的人。

衍生图可按变化描述编辑本体资产图，也可由作者直接上传成品。生成的衍生图跟踪本体图，后者变化时判为过期，创作者可决定是否更新。上传或从全局资产库应用的成品按自身内容登记，只有切回生成版本才重新跟踪本体。上传成品不增加一张供后续生成使用的衍生原图。时效依据见 [ADR 0062](0062-artifact-lifecycle-and-currency.md)。

同一分镜中可以同时引用本体与多个衍生，每个被引用的外观贡献自己的资产图。衍生名在本体内唯一，改名按 [ADR 0057](0057-asset-name-as-identity-cascade-rename.md) 级联。路径 `characters/derivatives/{角色}/{衍生}.png` 避免角色名 `refs` 与角色原图目录冲突。全局资产库按角色整套携带衍生，远端版本规则见 [ADR 0120](0120-global-asset-library-entries-hold-content-references-and-link-copies.md)。
