# 资产识别并入逐集脚本规划

全书资产提取需要整本源文，也会在任意一处原文变化时使下游等待重提取。现在新资产与角色衍生的识别并入逐集脚本规划，由规划结合本集内容与已登记资产一并完成。模型附上处理依据，创作者在内容确认时可修改，确认时随正式脚本登记。这样也支持自带原文的集与无源文的手写脚本。手写脚本的资产由创作者登记。

模型可读资产别名，程序只按同类资产的规范名称归并，避免泛称在不同集指向不同人。规划与生成保持已有资产描述，外观变化用衍生表达。同一资产被误识别为两个时可在项目内合并。

广告/短片从已有商品与创意出发时也需要识别新增人物或场景。该创作类型采用整份脚本生成，资产直接随生成结果登记，没有独立的内容确认。分阶段规划与提示词编写见 [ADR 0080](0080-review-confirm-materializes-script-prompt-authoring-fills-pending.md)。
