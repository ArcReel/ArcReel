# 自定义供应商按媒体类型存储并发上限

自定义供应商需要对图片、视频和音频三条任务通道分别限制并发。这三个已知的整数上限直接存放在 `custom_provider` 表的可空定型列中，空值由容量表回退至系统默认值；ComfyUI 协议留空时则采用专用默认值 1。内置供应商另可在注册表中声明供应商级的媒体并发默认值。

固定字段用定型列可直接校验和分别更新，避免为通用 JSON 或键值表引入逐键校验与读改写。容量装载见 [生成 Worker](../../lib/generation/generation_worker.py)。

并发上限接受正整数或空值。容量表在内存中用 0 表示供应商没有可用的对应媒体通道。过去允许用户填 0，Worker 会以「供应商不支持此媒体」拒绝原本可用的模型，因此配置和数据库约束都保留正整数边界。
