# 存量数据迁入模型目录：丢弃自定义模型的价格，能力只保留与条目和预设都不同的值

存量自定义模型带着用户填的价格、可选时长与最大输出 token，内置模型的元信息与价格写在 `registry.py` 里。迁入模型目录时，我们不追求把旧数据原样搬过去：旧价格结构表达不了新价目表的计量项与选择维度，旧的时长大多是按名字自动推断的，原样保留只会把过时的值永久盖在条目上。迁移只保留用户明确表达过、且新结构能准确承载的部分，价格的变化在 release note 中说明。

## 规则

- 自定义模型的价格在迁移时全部丢弃，不推导倍率，也不建用户条目。对应上条目的按条目价计费，供应商倍率与供应商模型倍率都取 1；对应不上的记为未定价（见 `docs/adr/0105`）。已冻结的历史费用不重算。
- 迁移时按 `docs/adr/0105` 的规则把存量自定义模型对应到出厂快照中的条目，结果只用于下一条的能力比较，不存储。已存的调用端点保留，不重新推断。
- 已有的能力覆盖按维度映射后原样保留，ComfyUI 端点上的除外（见 `docs/adr/0082`）。存量的可选时长与最大输出 token，只在既不等于所对应条目的值、也不等于按名字推断的预设时转为能力覆盖，其余丢弃；对应不上条目的同样适用，没有可比的值时转为能力覆盖。默认分辨率是用户偏好，原样保留。
- 对应不上条目的供应商模型也能设置能力覆盖：媒体类型取调用端点，未覆盖的维度显示运行时回落的结果。
- 目录数据仓库的第一版数据由 `registry.py` 一次性转换生成，已知的计价缺陷与已下架模型在这一版中一并修正，此后代码不再保存模型与价格。迁移后官方收录的供应商模型默认启用，原先隐藏的默认停用。
- 设置与项目中引用了内置供应商清单之外的模型时，已知改名的模型按退役模型映射改写为后继模型；其余引用原样保留，运行时解析报错并提示用户重新选择，不静默回落到其他模型。

## Considered Options

- **由用户价与官方价推导供应商模型倍率**：能保留中转站的价差。但只有币种一致、官方价没有分档、文本输入输出比值一致时才推导得出；推导不出的情况多半是旧结构本身表达不了的计价，保留下来也算不对。参考费用本身不对齐账单，丢弃后用户可以自己填倍率。
- **为对应不上但填过价格的模型新建用户条目**：保住了用户输入的价格，但不知道模型厂商，条目身份要靠猜，而且与 `docs/adr/0105` 不为对应不上的模型建条目的规则冲突。
- **可选时长全部转为能力覆盖**：一次回填迁移按名字给几乎所有存量视频模型写过时长，全部转成覆盖后，每个视频模型都会永久带一条用户没设过的覆盖，官方同步更新的时长不再生效。
- **扫描设置与项目，把清单之外的引用建成用户添加的供应商模型**：这类引用只来自已删除的模型或绕过界面的写入，为它们自动建模型的收益很小；静默回落到其他模型又会让用户在不知情时换了模型和价格。

## Consequences

- 升级后，在自定义模型上填过价格的用户，费用会改为条目价，或显示为未定价；release note 需要写明这项变化，并说明怎样用倍率表达中转站的价差。
