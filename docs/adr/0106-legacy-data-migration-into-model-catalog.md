# 模型目录迁移保留可表达的用户能力偏好

早期自定义模型把价格和能力直接存在供应商模型上。迁入目录时放弃旧模型价格，旧结构无法准确表达现行计量项和分档。自动换算倍率也会误导币种不同或档位不同的用户。迁移后按对应条目计价，未命中条目时按未定价处理，历史费用继续读原来的冻结金额。

已有同维能力覆盖优先。旧时长与目录条目、旧回填值或名字预设相同，视为系统值。只有无法用现行条目或这些历史系统值解释的时长才转为覆盖。文本最大输出 token 与条目不同时转为覆盖。ComfyUI 的时长按绑定后的原生档位比较，且只有存在原生档位时才可迁成偏好。调用端点与用户分辨率偏好保留。准确规则见 [数据库迁移](../../alembic/versions/c7e2a9d4b6f1_custom_model_catalog_pricing.py)。

旧项目 v16→v17 与 v17→v18 的确切退役模型映射已冻结在各自的迁移文件。当前设置保留所引用的模型名，下线及后继提示由目录给出，避免运行时改成另一模型。生命周期与现行行为见 [ADR 0103](0103-catalog-data-repo-built-from-third-party-sources.md)。
