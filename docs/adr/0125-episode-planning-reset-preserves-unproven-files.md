# 分集规划重置可清除损坏账本，保留无法证明可重建的文件

分集规划使用账本记录切出集与源文范围。普通规划要求这些坐标可用。全量重置则作为账本损坏时的恢复入口，允许跳过分集账本的结构校验。部分重置须先证明按播出顺序保留的切出集仍可继续使用，无法证明时引导改用全量重置。两种重置方式均保留自带原文和无原文的集，被清除的集 ID 也不会重新分配。源文改动后的重映射规则见 [ADR 0097](0097-whole-source-file-order-and-change-remap.md)。

重置会从账本中同集号的全部条目以及磁盘文件收集证据，只要任一处显示该集已消费，就将其列入确认清单。确认后，账本中存在的已消费集转为无原文并标为过期，同时保留剧本、其他下游产物及清单登记。切出集文件只有在该集的每条账本记录都具备可重建所需的坐标结构时才删除，证据缺失或冲突时改名留底。此处仅校验坐标结构，源文范围的合法性仍由规划入口检查。

锁外预扫描用于生成确认清单和提前返回校验错误，此时无需获取写锁，也不写入项目或改动文件。实际重置在项目锁内重新校验和扫描，发现预扫描清单以外的已消费集时要求重新确认。账本和文件处置共用提交边界。实现入口见[分集规划重置](../../lib/episode/episode_reset.py)。
