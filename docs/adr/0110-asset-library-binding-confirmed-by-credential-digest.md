# 素材库绑定须按凭证内容确认，控制面主机由站点登记

素材库控制面采用 Access Key 签名鉴权，而模型推理使用另一套 API Key。用户显式确认推理凭证可用的素材库资源范围。确认时记录推理凭证内容、endpoint 和账号范围的摘要，读取时以当前值复核。凭证换 Key 或改地址后须重新确认，否则用可变记录 ID 绑定会把旧素材 ID 发往新账号。冻结关联的账号身份另见 [ADR 0111](0111-asset-upload-job-and-link-share-one-record.md)。

控制面只访问代码登记的站点与区域官方主机。推理地址可以是任意中转服务，从推理地址推导控制面会把 Access Key 签名请求交给不受相同约束的服务。自定义供应商同样可由用户绑定，能力仍由调用端点声明。
