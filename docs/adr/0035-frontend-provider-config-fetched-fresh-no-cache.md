# 前端按消费时点读取供应商配置

项目设置等前端消费方每次读取内置与自定义供应商配置时，都会直接向服务端发起请求。此前曾使用模块级长期缓存，导致供应商设置修改后，项目里的时长选择器等控件仍沿用旧的模型规格。请求时读取以小型列表请求的成本，换取配置变更后无需跨页面传播失效通知。

配置状态提示可以独立维护。它服务配置提示和媒体类型可用性，不作模型选择与能力约束的数据源。供应商读取入口见 [provider-models.ts](../../frontend/src/utils/provider-models.ts)，能力来源见 [ADR 0104](0104-capability-sources-split-by-dimension.md)。
