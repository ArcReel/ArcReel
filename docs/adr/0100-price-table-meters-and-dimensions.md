# 价目表按计量项和请求维度计算参考费用

一份模型价目表使用模型厂商的单一币种，可叠加 token、张数、秒数与调用次数等计量项。计算器按每次请求的维度查每项单价，先扣单请求免费额度，再将各项相加并乘上倍率。组合计价可直接在同一张表表达，避免为每种计价形状新增策略。各币种分别金额汇总。价目表结构与计量单位见 [目录格式](../../packages/arcreel-catalog-core/README.md)。

- 选择维度由代码定义。上下文档按该次请求的输入 token 总量落档。其余维度读取真实请求事实，见 [ADR 0056](0056-execution-predicates-same-source-as-request.md)。各供应商的用量差异在上报前归一。
- 供应商倍率与供应商模型倍率相乘。官方收录的模型倍率随官方数据，用户负责的模型倍率由用户填写。供应商倍率由用户设置。乘积为 0 时直接计 0。Agent 只用凭证一级倍率，见 [ADR 0102](0102-agent-cost-computed-per-request-from-tokens.md)。
- 上报正用量的 token 类计量项缺单价，整笔未定价，因为它们是同一份 token 总量的组成部分。价目表没列出的计数类计量项视为该项不收费。
- 已有价目表却不能匹配有可计费用量的单价，整笔未定价。结算时，价目表有计量项但所有计量项都没取得用量，也记未定价。预估时，价目表有任一计量项无法取得数量就显示未定价。实际为 0 的费用与未定价分开显示。详见 [计价实现](../../lib/billing/metering.py)。
