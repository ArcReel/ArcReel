# 剧本保存校验采用「不更坏」语义，资产回写热路径豁免

剧本的 Python 保存入口在落盘前做结构校验。修改后合法则放行；如果修改后不合法，且修改前原本合法（或原本没有旧剧本），则拒绝保存。已有结构问题的旧剧本仍可保存，避免 schema 演进突然阻断存量编辑。这项兼容策略只在保存边界使用，批量结构编辑另有完整的候选内容预检，见 [ADR 0003](0003-agent-project-json-edits-via-tools.md)。

结构校验只检查即将写入的数据。若改用依赖磁盘状态的项目校验器，尚未生成分镜图的合法半成品也会被拒。只改 `generated_assets` 的高频回写无需全量结构校验，避免历史字段问题拖住已付费产物的回写。生成准入独立检查本次操作的输入，见 [ADR 0091](0091-admission-belongs-to-ai-actions-not-pipeline-position.md)。
