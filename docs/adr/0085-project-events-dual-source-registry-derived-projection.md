# 项目事件由显式事件与项目快照差分共同提供

浏览器收到项目事件后重新读取项目。显式事件表达任务完成或同路径字节替换等快照无法发现的事实。快照差分覆盖落进项目状态的其他变化。系统通过资产类型和剧本骨架注册表读取完整条目，避免手写字段清单导致新增资产、骨架或设置项的变更对界面不可见。全量通知多报会增加读取成本，漏报则会让界面停在旧状态。

快照排除每次写入都改变的元数据。剧本生成字段只提取媒体就绪信号，其他内容由显式事件表达，避免任务完成重复通知。衍生以「本体/衍生」作为独立事件身份。两路事件的去重、补扫与投影见 [project_events.py](../../server/services/project/project_events.py) 和 [project_state_projection.py](../../server/services/project/project_state_projection.py)。

轮询只读，集索引同步由项目写入完成。界面有没有订阅者不应决定应用是否执行迁移或登记集。
