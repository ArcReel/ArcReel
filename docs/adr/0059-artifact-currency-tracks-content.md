# 产物时效只追踪正式内容

Artifact provenance 按单个产物只散列它直接消费的正式内容及直接上游产物，不构造全项目依赖图，也不纳入执行模型、分辨率、声音参数、provider 设置或 prompt builder 版本。直接依赖限于：集源文到本集 step1、step1 到本集正式剧本、资产定义到对应 sheet、镜头内容与实际引用 sheet 到对应分镜或参考视频、分镜图到对应视频。追加原文只刷新资产清单与后续分集规划，不改变既有集；旁白音频不做内容 stale 判定。完整生成配置与全链传播可以更精确地复现历史产物，但会显著扩大输入构造、配置解析与陈旧传播复杂度；配置变化由下一次显式生成生效，不把既有产物自动标为 stale。
