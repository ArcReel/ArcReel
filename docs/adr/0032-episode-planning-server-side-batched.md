# 分集规划由服务端按窗口执行，重规划经候选确认

逐集切分容易漏掉跨集剧情，一次规划整本又会在试做第一集前花掉整本的费用。服务端分批读取源文，让文本模型找出剧情完整的集并给出标题、钩子和范围。服务端校验结构和原文锚点，只提交到最后一个有效切分点，剩余源文留给下一批。Agent 只负责调用，模型不写分集账本。

每批最多规划多少集，取决于项目文本模型登记的输出上限。窗口字数和每批集数上限由系统决定，Web、Agent 和项目设置都不能覆盖。[ADR 0044](0044-text-output-token-nonbinding-ceiling.md)

逐窗规划的后续任务依赖当前窗口成功。服务进程按当前任务 ID 记录停止请求，在入队前后与当前窗口完成前检查，并在登记停止后复核排队中的后续任务。若停止发生在入队期间或入队刚返回后，刚排入的后续任务会在当前窗口完成前被取消，不中断当窗提交。这样关闭页面后停止仍然生效，之后主动接续会创建新的任务。

## 提交与身份

- 首次及接续规划直接提交。接续从最后一段切出原文的末尾读取，空段也可单独规划，两种入口都不覆盖既有集。
- AI 重规划产出候选。用户可检查、继续、采纳或放弃，停止时已完成内容仍是候选。采纳才替换从选定起点起的旧切出集。新集分配新 ID，不把旧产物按位置套到新内容。退下的有产物集保留为无原文的集并标为过期，无产物的移除。
- 手工切分直接提交。移动分界时两侧集保留身份，拆分保留前一段并给后一段分配新 ID，合并保留前一段身份。范围变化且已有产物时标为过期。

## 播出顺序

切出集遵循源文顺序，其他集由创作者排序，见 [ADR 0096](0096-episode-identity-separated-from-order.md)。接续规划的新集紧跟最后一个切出集，首次无切出集时追加。手工切分不会移动无关集。退下但保留产物的旧集按原相对顺序移至末尾。

重规划的范围内若夹有自带原文或无原文的集，按采纳时的剧情锚点落位。以前面最近切出集的原文末尾为锚，排在第一个覆盖锚点或结束在锚点之后的候选集后。锚在候选范围以外时排到对应一端，旧切出集无范围时移到新切出集之后。相同位置保持原相对顺序。空段规划同样按源文位置插入，夹在其中的非切出集按锚点落位。按原位置序号摆放会在集数变化后把内容带到错误的剧情位置。

剧情演绎的账本提供分集大纲，旁白/解说保留切分点与钩子。模型决定剧情质量，机械校验只保证形式。数据与服务入口见 [ADR 0031](0031-episode-ledger-single-source-of-truth.md) 和 [EpisodePlanner](../../lib/episode/episode_planner.py)。
