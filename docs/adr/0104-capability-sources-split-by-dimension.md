# 模型事实与调用通道共同决定生效能力

同一模型可以经不同通道调用。同一通道也可能因输入组合或档位改变所能表达的请求。模型条目负责记录「模型本身接受什么」，所挂接的调用端点则声明「通道实现了什么」。生效能力按供应商模型逐一求值，供应商级别的展示信息由它们聚合而成。端点来源是供应商官方清单或用户保存的选择。模型名推断用于添加时预填端点，条目绑定只作用于模型事实。文本的图像输入、结构化输出与最大输出 token 也归模型条目，输出上限的实际使用见 [ADR 0044](0044-text-output-token-nonbinding-ceiling.md)。模型名与条目的对应见 [ADR 0105](0105-model-name-to-entry-matching.md)。

## 输入与时长

- 文生图、图生图、文生视频、首帧、尾帧与参考音频由模型和通道两侧共同约束。数值上限取已声明的较小值，包含参考图张数、参考音频段数及总时长。任一侧不支持则拒收，两侧均未声明上限则为未收录，明确的 0 表示上限为零。未收录的模型能力中，文生视频与首帧跟随通道，尾帧与参考音频默认关闭。图片与视频各自共用 [图片能力求值](../../lib/backends/image_capabilities.py) 和 [视频能力求值](../../lib/backends/video_capabilities.py)。
- 候选、提示词预览、预检、执行与设置页都用同一个生效参考图上限。保留完整的参考输入，超量就于付费前提示张数、上限及超出的图。上限为 0 或能力不支持时拒绝带图请求，避免清空后走到另一条生成路径。未收录时将完整有效输入交给上游。批量准入见 [ADR 0061](0061-batch-video-admission-all-or-nothing.md)。
- 模型条目声明分辨率、时长及按分辨率、参考图、尾帧触发的时长约束。触发的时长约束取交集。时长声明缺失或时长超限按 [ADR 0086](0086-video-request-facts-evaluated-once.md) 处理。通道直接使用条目给出的时长和分辨率档位，无需另维护一份型号档位表。挂尾帧之前用当前已知输入求值，挂尾帧后读带尾帧的档位，不能沿用只供无尾帧路径的时长。Vidu 保留端点级时长校正，处理同一模型在不同端点的合法时长差异，见 [Vidu 通道](../../lib/backends/video_backends/vidu.py)。
- 通道按实际请求确定特定输入组合能否传输，例如旧可灵仅在适用档位下接受尾帧。模型条目确定各模型支持的能力，复用既有请求结构的新型号可只更新模型数据。

## 画质与音轨

- 模型条目列出接受的画质取值。通道同时支持显式画质时，用户可选择并原样发送所选值。未选择时保留通道按分辨率映射画质的兼容行为，避免改变既有项目的出图与预估。显式选择时分辨率只决定尺寸，输出 token 预估按发出的画质查模型条目上的规则。调用前无法估算的用量按 [ADR 0100](0100-price-table-meters-and-dimensions.md) 处理。
- 是否下发音轨开关取决于调用端点，成片是否有声是一项独立事实。明确的无声信号或适用的音轨覆盖可改变成片预期，其余默认有声，避免在缺少资料时挡住合法配置。自定义供应商同样按端点声明决定能否下发开关，音轨覆盖只改变出声事实。设置、准入、音频交付和计量分别消费对应事实。

## 覆盖范围

自定义供应商下的模型及内置供应商下用户添加的模型允许按适用维度做整维覆盖。它表达渠道差异，在生效值求出后应用。官方收录模型跟随官方数据。覆盖不得使调用通道承诺自己无法传输的形态，例如未实现的图生图路径；画质取值和图片分辨率档位也保持由模型条目声明。ComfyUI 端点依节点绑定求值，只有可驱动时长的端点可用档位偏好作为覆盖。见 [能力覆盖校验](../../lib/custom_provider/capability_view.py) 和 [ADR 0082](0082-node-bindings-are-the-only-truth-of-comfyui-endpoint.md)。
