# 模型事实与调用通道共同决定生效能力

同一模型可以经不同调用端点调用，同一调用端点也可能因输入组合、执行档位或子路径改变所能表达的请求。生效能力由三类来源分层决定：模型条目记录「模型本身接受什么与产出什么」；调用端点提供单一的协议能力描述，区分物理上可传输的形态与硬上限、无条目时的默认值，以及逐路径或档位例外；能力覆盖在协议硬边界内表达渠道差异。内置供应商（含官方收录与用户添加的供应商模型）和自定义供应商共用同一套能力求值、覆盖校验、任务类型桶判定与设置视图规则，两者仅在数据读取来源和是否允许编辑上区分。

生效能力按供应商模型逐一求值，供应商级别的展示信息由它们聚合而成。端点来源是供应商官方清单或用户保存的选择。模型名推断用于添加时预填端点，条目绑定只作用于模型事实。文本的图像输入、结构化输出与最大输出 token 也归模型条目，输出上限的实际使用见 [ADR 0044](0044-text-output-token-nonbinding-ceiling.md)。模型名与条目的对应见 [ADR 0105](0105-model-name-to-entry-matching.md)。

## 输入与时长

- 文生图、图生图、文生视频、首帧、尾帧与参考音频由模型条目和调用端点两侧共同约束。数值上限取已声明的较小值，包含参考图张数、参考音频段数及总时长。任一侧不支持则拒收，两侧均未声明上限则为未收录，明确的 0 表示上限为零。未收录的模型能力中，文生视频与首帧跟随调用端点，尾帧与参考音频默认关闭。
- 调用端点区分协议硬边界与软默认上限：未实现的输入槽位、服务级物理硬上限（如 OpenRouter 的参考图封顶与远端动态上限）以及输入组合互斥约束（如可灵参考图与首尾帧不可混用）构成最终边界，保存与执行均不得突破。图片的远端动态上限在数据库会话外探测，与本地已冻结的模型条目和能力覆盖合算后作为最终提交限制，不再回查本地目录。
- 候选、提示词预览、预检、执行与设置页共用同一个生效参考图上限。保留完整的参考输入，参考图超限时于付费前提示张数、上限及超出的图。上限为 0 或能力不支持时拒绝带图请求，避免清空后走到另一条生成路径。未收录时将完整有效输入交给上游。批量准入见 [ADR 0061](0061-batch-video-admission-all-or-nothing.md)。
- 模型条目声明分辨率、可选时长及按分辨率、参考图、尾帧触发的时长联动约束。触发的约束取交集。时长声明缺失或时长超限按 [ADR 0086](0086-video-request-facts-evaluated-once.md) 处理。调用通道直接使用条目给出的时长和分辨率档位，无需另维护一份型号档位表。挂尾帧之前用当前已知输入求值，挂尾帧后读带尾帧的档位，不能沿用只供无尾帧路径的时长。Vidu 保留端点级时长校正，处理同一模型在不同调用端点与输入子路径上的合法时长差异，见 [Vidu 通道](../../lib/backends/video_backends/vidu.py)。
- 调用通道按完整请求条件（任务类型桶、分辨率、执行档位与输入组合）确定特定形态能否传输，例如可灵在高分辨率或 `pro` 档下同时改变尾帧与音轨行为。模型条目确定各模型支持的能力，复用既有请求结构的新型号可只更新模型数据。

## 画质与音轨

- 模型条目列出接受的画质取值。调用端点同时支持显式画质时，用户可选择并原样发送所选值。未选择时保留调用通道按分辨率映射画质的兼容行为，避免改变既有项目的出图与预估。显式选择时分辨率只决定尺寸，输出 token 预估按发出的画质查模型条目上的规则。调用前无法估算的用量按 [ADR 0100](0100-price-table-meters-and-dimensions.md) 处理。
- 视频音轨拆为四项独立语义，各自按单一来源推导：用户音频意图来自项目或全局设置；请求体是否下发音轨开关完全由调用端点决定，不可被能力覆盖改写；预期成片是否有声由调用端点子路径的强制无声约束与模型有声事实共同决定（端点无强制无声约束且无模型无声覆盖时默认有声，避免在缺少资料时挡住合法配置）；计费音频档由计量策略统一决定——显式声明恒含音出账的供应商（如 `gemini-aistudio`）固定按有声档计费且优先于模型覆盖，其余渠道在提交前预估与结算时统一按预期成片音轨计费。
- 调用端点对每条子路径的音轨区分三类协议硬形态：可下发音轨开关、无开关但允许模型有声或无声（如百炼无开关端点），以及协议强制无声（如可灵多图主体子路径）。强制无声的子路径禁止覆盖为有声，确保设置页、预检、请求构造与计量一致。
- 端点定义与供应商模型的能力覆盖分开演进：市场和声明式端点的定义保留其既有协议声明格式，经独立解码转换为运行时通道描述；供应商模型的音轨覆盖仅表达模型是否产出有声成片（布尔事实，参考生视频路径未设置时继承主路径），三态音轨枚举仅作只读展示或旧接口兼容投影。设置、准入、音频交付、声音一致性档位和计量分别消费对应事实。

## 覆盖范围

- 自定义供应商下的供应商模型及内置供应商下用户添加的供应商模型允许按适用维度做整维覆盖；官方收录的供应商模型跟随官方数据，只读。
- 能力覆盖在协议硬边界允许的范围内表达渠道差异：在调用端点已实现且未触及物理硬上限的维度上，用户可收窄或放宽软默认上限，以适配同协议新型号或中转渠道；对于档位相关的能力（如可灵 `pro` 档尾帧），保存期按该端点可达的最大允许包络校验并保留覆盖，执行期再按实际请求条件合成。
- 能力覆盖不得使调用通道承诺自己无法传输的形态（如未实现的输入槽位、超出物理硬上限的参考图数量、不可控端点的音轨开关，或强制无声子路径的有声声明）；画质取值和图片分辨率档位保持由模型条目声明。参考音频模式与段数上限须保持组合自洽。
- ComfyUI 端点依节点绑定求值，维度由端点固定时禁止编辑可选时长覆盖，只有可驱动时长的视频端点才允许以可选时长覆盖表达使用偏好。见 [ADR 0082](0082-node-bindings-are-the-only-truth-of-comfyui-endpoint.md)。
