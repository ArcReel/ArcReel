# 图片任务按执行时的参考图确定文生图或图生图

批量生成时，第 N 张分镜可能引用刚生成的第 N−1 张分镜。由于可用参考图要等到执行时才能确认，实际的任务类型桶和供应商也按执行时的参考图决定。入队与认领阶段先按文生图配置估算供应商；占用限流槽后若发现实际供应商不同，则更新路由并重新入队，改由正确供应商的限流槽执行。多一次回队的代价换来准确限流，也避免调度层重复装配参考图。

图片编辑在入队时就确定使用当前图片作为参考，直接按图生图配置路由。普通生成发现参考输入无法读取或超出生效上限时，按 [ADR 0015](0015-image-endpoint-split-by-capability-no-fallback.md) 和 [ADR 0104](0104-capability-sources-split-by-dimension.md) 拒绝请求。
