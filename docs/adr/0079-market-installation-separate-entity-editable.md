# 市场安装来源独立于可编辑的端点定义

从市场安装端点后，系统会生成一个普通的自定义调用端点以及一条独立的安装记录。记录中保存市场源规范键、条目身份、安装版本及当时的定义摘要，同一端点只绑定一个来源。即使后续删除了对应市场源，依然能够追溯该端点的安装出处。普通文件导入，或本地恰好存在同作者同名的定义，都不会自动建立安装关系。安装覆盖仅适用于尚无安装记录的本地端点，且来源不提供独立解绑入口。

安装在一个事务中写入端点定义与安装记录。端点保留本地编辑能力，定义摘要不同时显示已修改。市场上的可更新状态只比较已安装版本和索引版本，因此同版本改内容需要源仓库在发布审查时拦住。更新覆盖本地编辑前给出提示，卸载随端点删除安装记录。

端点定义是可导入、导出的协议载荷，绑定记录服务于安装生命周期。把绑定写入定义会让正常编辑或导出顺带携带安装状态，也会改变一个稳定的分享格式。见 [ADR 0067](0067-custom-endpoint-declarative-definition.md)。
