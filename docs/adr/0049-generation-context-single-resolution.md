# 生成任务从一次配置解析取得实际调用通道和请求事实

生成任务通过 [`resolve_generation_context`](../../server/services/tasks/generation_context.py) 声明所需媒体通道，在单次配置读取中同时产出两份同源结果：**不可变的公开能力快照**（供预检、请求事实求值与编排消费）和**私有装配规格**（完整携带调用端点、端点定义或节点绑定、路径覆盖、凭证与地址等构造输入，供通道装配消费）。调用通道的装配只消费这份装配规格，不再二次回查数据库或模型目录，避免构造与校验之间出现配置竞态。图片任务因此也可在没有视频配置的项目中执行。

配置解析按业务用途显式区分入口，不共用同一套校验口径：

- **按任务类型桶选型**：按分层配置选定执行模型，校验生命周期与桶能力，产出能力快照与装配规格。
- **无桶默认选型**：走默认层；自定义供应商的供应商模型缺失或停用时可回退该供应商默认启用的模型，关联的模型条目已下线仍报错。
- **已物化新任务**：按任务载荷锁定的身份校验可用性与生命周期，不重新按桶选型，由请求期闸门按真实输入判定。
- **已提交任务续跑**：必须依据执行检查点锁定的身份，校验媒体类型与协议守卫（兼容历史守卫与协议等价后继），豁免模型下线拦截，不读取新项目偏好，也不求值新请求事实，确保已付费的供应商任务在配置变更或模型下线后仍可取回。见 [ADR 0007](0007-orphan-tasks-not-requeued-on-restart.md)。

能力和请求参数直接基于同一次解析产出的能力快照求值，不再拿裸供应商与模型标识回查解析器。规范供应商标识来自解析身份，模型取实际收敛后的执行模型；调用通道内部的协议族名可能由多个供应商共用，不能代替供应商标识。需要的调用通道构造失败时结束该次任务，避免静默改用另一模型产生费用。

调用通道实例缓存留在服务端编排层，构造入口见 [ADR 0039](0039-builtin-backend-construction-declarative-seam.md)。缓存代际在开始读取配置与目录之前捕获，复用前提是装配规格等价；跨越失效边界读取的旧对象用完即弃，不得写回新代缓存。

视频的分辨率省略、时长约束、档位联动与预检行为统一由 [ADR 0086](0086-video-request-facts-evaluated-once.md) 决定。
