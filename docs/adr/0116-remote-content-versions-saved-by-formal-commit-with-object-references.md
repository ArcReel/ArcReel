# 正式提交选择图片版本的存储位置，正式对象按内容摘要共享

新写入且建有版本记录的图片经 [formal_commit](../../lib/material/formal_objects.py) 按实例设置保存在本地或对象存储。远端保存与确认发生在写版本记录前，失败时正式写入回滚。接缝放在版本提交中，使图片生成、编辑、上传和导入共用同一套提交语义。选择或恢复已有版本沿用其定位，未建版本记录的图片、视频与音频继续保存在本地。

远端版本定位记录写入时的连接、桶与对象 key。读取按记录核对连接和桶，签名地址不写入定位。正式对象与中转副本使用独立前缀。同一连接内同字节的版本共享对象，提交先登记占用，结束后结算为内容版本引用或撤下占用。进程中断后启动补做结算。零引用回收与供应商直接取正式对象时的持有期由 [ADR 0118](0118-formal-objects-retained-by-holder-references-and-collected-in-one-place.md) 定义。项目路径上的远端工作文件只是缓存，读取契约见 [ADR 0117](0117-evicted-work-files-count-as-present-by-recorded-digest.md)。

连接仍用于保存新图片时不能删除连接。未确认上传、提交占用和项目或全局资产库持有的对象阻止改变远端位置或删除连接，访问密钥可以轮换。只被入库任务持有或已无引用的对象允许离开旧桶。管理员可用当前凭证清理这些已登记对象与中转副本，也可放弃桶内文件。连接变更不接管旧桶位置，清理失败报告结果并结束旧连接的管理义务。旧桶的未定入库任务停止，保留的内容仍可重新入库。

连接变更、存储目标变更、正式提交登记和入库签名共用连接锁，正式对象处置与后台回收还按对象串行。对象上传发生在版本锁内，会延后同项目其他版本写入。两种锁都以单进程部署为前提，见 [ADR 0083](0083-generation-queue-stays-in-house-for-now.md)。

范围与验收见 [Spec #3559](https://github.com/ArcReel/ArcReel/issues/3559)。
