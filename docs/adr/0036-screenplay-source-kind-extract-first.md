# 剧本源按文件记录，提取优先并逐字保留可听内容

剧情演绎允许在同一项目混用小说和作者已写好的剧本。源文件类型随整本源文的各个文件或自带原文的集记录，切出集按范围起点所在文件读取。把类型存在项目级会丢掉混合来源，也会要求用户在看到源文前作出选择。旁白/解说的文字直接作为画外音，广告/短片没有这一源文件类型轴。

剧本源沿用分集规划、脚本规划和项目概览。已有分集边界和作者提供的内容优先提取，缺失时才由相应模型补齐。采用逐步语义提取，避免专用解析器对野生格式施加限制或提前处理整本长稿。逐字保留范围是台词和画外音，排版、运镜、舞台提示与视觉描述可按结构转写。发声结构见 [ADR 0089](0089-single-speech-owner-per-video-unit-narration-delivery-per-project.md)，内容确认见 [ADR 0080](0080-review-confirm-materializes-script-prompt-authoring-fills-pending.md)。

改类型不改文本指纹和原文范围。已有切分仍可使用，脚本规划因其提示词依据变化可能过期，正式脚本独立判定。分集规划从当前文件取窗口，类型口径随窗口文件选择。项目概览在混合类型时走小说口径。源文件顺序和外部变化的处理见 [ADR 0097](0097-whole-source-file-order-and-change-remap.md)。
