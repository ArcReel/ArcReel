# 图片和视频用默认模型加任务类型桶配置

图片分文生图、图生图两个桶。视频分图生视频、参考生视频两个桶。每个媒体类型有一个默认模型和可选的细分桶设置，让常用模型可以一次配置，同时允许不同任务用各自适配的模型。选择顺序为项目桶、项目默认、全局桶、全局默认，缺省再按 [ADR 0099](0099-model-catalog-shared-entries-per-model.md) 处理。执行模型不具备所需能力时明确报出配置问题。自动更换模型会改变用户预期的费用与输出。

图片按执行时的参考图定桶，见 [ADR 0001](0001-image-capability-resolved-at-execution.md)。分镜路线走图生视频桶，参考路线有参考图的单元走参考生视频桶，无参考图的单元走图生视频桶，再按实际请求校验文生能力。空引用与无法取得已声明引用的失败要区分。以可用参考图定桶和执行参数共用 [ADR 0086](0086-video-request-facts-evaluated-once.md) 的视频请求事实，能力约束统一见 [ADR 0104](0104-capability-sources-split-by-dimension.md)。

排队期间，项目、剧本和资产可以编辑。任务行上的供应商是限流路由提示，执行时按当前内容和配置重新投影。即将向供应商提交时才冻结实际执行事实，后续轮询和重启恢复读该快照，避免提交与恢复之间被更改的配置改变请求身份。见 [ADR 0007](0007-orphan-tasks-not-requeued-on-restart.md)。
