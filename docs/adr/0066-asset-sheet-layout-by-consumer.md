# 资产图版式按下游生成用途选择，角色保留三视图

资产图主要用于分镜图、宫格图或参考生视频的生成输入。场景、道具与商品各出一个视图，角色保留正、侧、背三视图横排。三视图沿用创作产品惯例，接受多格构图可能传入下游这一代价。供应商指南和实验更支持分别生成多个角度，但本项目采用单路径资产图。多图将改变版本、重命名和下游引用契约，需要另行决策。证据与适用范围见[资产图提示词研究](../research/arcreel-asset-sheet-prompt-research.md)。

常规资产图显式指定宽高比，避免参考图默认比例传入下游。具体版式、纯色背景、正向边界与排除项由[资产图提示词模板](../../lib/prompts/prompt_templates/templates/partials/asset/sheet/)持有。改版应核对资产图及下游参考生成的版式继承与身份保真。
