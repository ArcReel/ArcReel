# 编辑还是重生

根据用户要保留什么选择路径。

## 局部编辑

用户认可构图与整体设计，只改像素层局部内容，例如换色、去杂物、修手部、调整光线：

1. 保留 `description` / `image_prompt`；
2. 调 `mcp__arcreel__edit_images`；
3. 验证新文件 revision current；
4. 说明以后按原 prompt 整图重生不会自动保留这次局部编辑。

## 语义重生

用户要改变构图、设计定义、角色关系、镜头含义，或明确修改 `description` / `image_prompt`：

1. 先通过结构化 MCP 工具修改真相源；
2. 再调用对应生成工具重生指定 ID；
3. provenance 会把依赖旧输入的下游产物标为 stale；
4. 用户本次要求包含下游更新时，继续补齐 stale 项；否则明确报告 stale 范围。

## 选择原则

- 保留已满意的大部分画面 → 局部编辑；
- 让未来重生也遵循新要求 → 修改真相源并重生；
- 用户同时提出两类要求 → 以语义真相源为先，再决定是否追加局部编辑。
