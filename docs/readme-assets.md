# README 演示素材规范

这份文档不面向普通用户，而是给维护者提供 README 首页所需的截图、动图和成品案例规范。

当前 README 已使用：

- `docs/assets/hero-screenshot.png`
- `docs/assets/feishu-qr.png`

产品型开源项目的首页转化主要依赖真实成果展示。ArcReel 尤其需要同时展示“工作台”和“最终成片”，不能只展示设置页或功能清单。

## 1. 推荐的素材目录

```text
docs/assets/
├── hero-screenshot.png
├── demo-workflow.webp
├── showcase-novel-cover.jpg
├── showcase-narration-cover.jpg

│   ├── novel-final.mp4

│   └── ad-final.mp4
└── feishu-qr.png
```

GitHub README 不适合直接托管超大视频。最终视频可以：

- 放在 GitHub Release；
- 使用 GitHub Issue/PR 上传生成的媒体链接；
- 放在项目官方网站或稳定对象存储；
- 在 README 中使用封面图链接到视频。

## 2. Hero 截图

### 目标

用户在不阅读文字的情况下理解：

- 这是一个完整工作台；
- 右侧有 Agent；
- 中间是视频生产流程；
- 可以看到角色、分镜或任务状态。

### 建议规格

- 比例：16:9
- 推荐尺寸：1600 × 900
- 最低宽度：1200
- 格式：PNG 或高质量 WebP
- 文件大小：尽量小于 1.5 MB

### 截图内容

优先展示一个已经有实际数据的项目：

- 左侧项目或资产导航；
- 中间角色、分镜或时间线；
- 右侧 Agent；
- 一处可见的任务或费用信息。

不要展示：

- 空白项目；
- 大面积设置表单；
- 真实 API Key；
- 客户名称；
- 未脱敏的小说全文；
- 浏览器无关区域。

## 3. 工作流动图

### 目标

用 15～30 秒展示：

1. 打开已有项目；
2. 让 Agent 继续下一阶段；
3. 查看生成任务；
4. 打开分镜或视频结果；
5. 展示版本历史或剪映导出。

### 建议规格

- 优先使用 WebP 动图；
- 宽度：1200～1600；
- 帧率：12～20 FPS；
- 控制在 8 MB 以内；
- 不录制长时间等待；
- 用剪辑跳过供应商排队。

动图应突出“可审核流程”，而不是只展示按钮点击。

## 4. 三个成品案例

README 最少准备三个代表不同场景的案例。

### 4.1 小说转 AI 漫剧

记录：

- 输入字数；
- 创作类型；
- 分镜数量；
- 使用的角色资产数量；
- 生成总时长；
- 视频时长；
- 使用供应商；
- 实际费用范围；
- 最终视频链接。

### 4.2 旁白/解说短视频

记录：

- 旁白字数；
- 分镜数量；
- TTS 音色；
- 是否导出剪映草稿；
- 最终比例；
- 实际费用范围；
- 最终视频链接。

### 4.3 商品广告短片

记录：

- 商品参考图数量；
- 分镜数量；
- 视频时长；
- 是否使用参考生视频；
- 商品真实性审核说明；
- 实际费用范围；
- 最终视频链接。

## 5. 案例文案模板

```markdown
### 案例名称

[![案例封面](docs/assets/showcase/example-cover.jpg)](视频链接)

- **输入**：约 2,000 字小说片段
- **模式**：剧情演绎 + 分镜图生视频
- **输出**：8 个分镜 / 48 秒 / 9:16
- **供应商**：文本 A、图像 B、视频 C
- **生成时间**：约 XX 分钟
- **API 费用**：约 XX，价格和排队时间可能变化
- **可编辑输出**：最终视频 + 剪映草稿
```

费用必须：

- 标明币种；
- 标明只是该案例；
- 标明供应商价格可能变化；
- 不把不同币种无说明相加；
- 不承诺所有用户都能得到相同成本。

## 6. 隐私和安全检查

发布截图和视频前检查：

- [ ] 没有 API Key；
- [ ] 没有 Token；
- [ ] 没有真实管理员密码；
- [ ] 没有内部 Base URL；
- [ ] 没有客户名称；
- [ ] 没有未经授权的小说内容；
- [ ] 没有个人文件路径；
- [ ] 没有浏览器账号头像和通知；
- [ ] 商品和品牌素材拥有展示授权；
- [ ] 示例音乐、字体和图片可合法展示。

## 7. README 接入方式

完成演示素材后，建议在 Hero 图下增加：

```markdown
<p align="center">
  <a href="完整演示视频链接">观看 90 秒完整演示</a>
  ·
  <a href="#效果案例">查看成品案例</a>
</p>
```

并在“适合的创作场景”后增加：

```markdown
## 效果案例

| 小说转 AI 漫剧 | 旁白/解说短视频 | 商品广告 |
|---|---|---|
| 封面与视频链接 | 封面与视频链接 | 封面与视频链接 |
```

没有真实、可公开的案例时，不要使用占位视频、虚构成本或模型宣传素材冒充 ArcReel 输出。
