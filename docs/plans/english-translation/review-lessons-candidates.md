# Translation review lessons for later triage

These are implementation-review observations, not additions to `docs/LESSONS.md` and not evidence that the migration is complete.

- Existing English source quotations must remain verbatim even when the surrounding research prose is Chinese. Independent review caught paraphrased or dequoted quotations. The Markdown auditor now checks sentence quotations, including Chinese quotation delimiters; eleven tests cover this and other literal/metadata failures. Block quotations, shorter excerpts and attribution still require source review.
- Structural translation checks need the right boundary. Preserve schema structure while allowing reviewed description metadata, without excluding instance properties named `description`. Compare executable AST only after removing classified docstrings, and keep executable diagnostic strings and historical migration data unchanged.
- Coverage is a review aid rather than proof. Equal heading, paragraph and code-span counts helped detect omissions, but independent clause review still found lost constraints and weakened language. In particular, an officially unsupported recommendation must not become merely optional advice.
- Generated comments belong to their source generator. Four price-vocabulary comment literals were traced to TypeScript comments, translated at the generator, regenerated and checked for unchanged executable output and repeat stability.
- Comparison helpers can produce misleading findings. A reviewer link matcher initially swallowed adjacent links and reported false navigation changes. Git-object comparisons and destination counters disproved those findings. Inline-code checks must account for matching backtick widths, multiline spans and JSDoc decoration.
- Failed broad test runs and isolated passing reruns are separate evidence. Keep the original failure and its unresolved cause visible; do not label it preexisting merely because both candidate and baseline pass in isolation.
- Source contradictions discovered during translation remain recorded rather than silently repaired. Agent-access-policy prose has historical disagreements about runtime mode changes and built-in tool sandboxing; this translation preserves their original meaning without changing executable policy.

- Tailwind consumes comment text as source candidates, so TypeScript code equality alone misses generated-style changes. Production comparison caught a lost `line-clamp-1` utility after punctuation changed its token boundary, and an added `grow` utility from ordinary English prose. Delimiting the literal and choosing equivalent prose restored byte-identical production CSS. Retain this build comparison for later comment batches.

- A bare TypeScript scanner cannot inventory comments reliably across JSX and nested templates. It omitted untouched prose and overstated completion. A parser-based extractor now has regression cases and an independent range cross-check; previous pair reviews remain valid but earlier scope-completion claims were reopened.
- Test docstrings may be measurement inputs. Synthetic Pydantic, Enum and RootModel documentation stays byte-exact; repeated same-name definitions are counted by occurrence rather than overwritten in name-keyed dictionaries. Passive AST equality alone does not certify this boundary.
- Leading docstrings are not the whole documentation surface. Standalone attribute, type-alias and enum annotations and developer-facing configuration descriptions require separate consumer tracing. Preserve selector identifiers while translating display-only text.
- Reconcile the complete baseline tree, including unchanged configuration files, rather than only assigned directories or modified paths. The final inventory found maintenance comments in seven frontend/website configuration files and a pragma trailing reason; each received a narrow translation, independent review and value/directive checks. Developer lint messages also had exact-message test consumers, so their display text and narrowly identified expectations were reviewed together.
- A remote browser gate can intentionally skip checks that require visible, space-occupying scrollbars. Record the skip condition and exercise those cases through their unchanged local launch path; a green remote gate alone does not establish that coverage.
- Developer diagnostic text is also scanned by Tailwind. The final ESLint translation exposed `z-onboarding` as a standalone candidate and added 42 CSS bytes. Keeping the three literal layer IDs in an equivalent slash-separated list restored all 161 emitted files byte-for-byte, after semantic review and unchanged nonmessage lint diagnostics. Preserve the rejected build comparison alongside the repaired one.
- A translation-lock fingerprint can already be current while its English target still omits source paragraphs. The final provider-page review compared the complete current Chinese source and English target, repaired nine stale/missing blocks, and reviewed those exact clauses independently before rerunning the forward lock check. A current hash alone is not fidelity evidence.
- A global Git ignore rule can hide a newly written ADR from ordinary untracked-file discovery. Reconcile explicitly created files as well as Git's untracked list, and identify ignored delivery artifacts before a later commit.
