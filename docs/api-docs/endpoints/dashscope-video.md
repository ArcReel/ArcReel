# dashscope-video

- 协议：[阿里云百炼视频生成](https://help.aliyun.com/zh/model-studio/use-video-generation)、[Wan 文生视频](https://help.aliyun.com/zh/model-studio/text-to-video-api-reference)、[Wan 图生视频](https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference)、[Wan 参考生视频](https://help.aliyun.com/zh/model-studio/wan-video-to-video-api-reference)、[HappyHorse 文生视频](https://help.aliyun.com/zh/model-studio/happyhorse-text-to-video-api-reference)、[图生视频](https://help.aliyun.com/zh/model-studio/happyhorse-image-to-video-api-reference)、[参考生视频](https://help.aliyun.com/zh/model-studio/happyhorse-reference-to-video-api-reference)；本端点：异步视频请求，不下发音轨开关，能力与计量按固定有声
- 音轨依据：[旧版文生视频](https://help.aliyun.com/zh/model-studio/legacy-wan-text-to-video-api-reference)与 [Wan 文生视频](https://help.aliyun.com/zh/model-studio/text-to-video-api-reference)没有 `parameters.audio`；[旧版图生视频](https://help.aliyun.com/zh/model-studio/legacy-image-to-video-api-reference)只为 wan2.6-i2v-flash 提供 `parameters.audio`，默认有声
- 计费：[模型价格](https://help.aliyun.com/zh/model-studio/model-pricing)
- 代码：`lib/custom_provider/endpoints.py::ENDPOINT_REGISTRY["dashscope-video"]`、`lib/backends/video_backends/dashscope.py::DashScopeVideoBackend`
