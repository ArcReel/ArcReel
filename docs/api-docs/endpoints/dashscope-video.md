# dashscope-video

- Protocol: [DashScope video generation](https://help.aliyun.com/zh/model-studio/use-video-generation), [Wan text-to-video](https://help.aliyun.com/zh/model-studio/text-to-video-api-reference), [Wan image-to-video](https://help.aliyun.com/zh/model-studio/image-to-video-general-api-reference), [Wan reference-to-video](https://help.aliyun.com/zh/model-studio/wan-video-to-video-api-reference), [HappyHorse text-to-video](https://help.aliyun.com/zh/model-studio/happyhorse-text-to-video-api-reference), [Image-to-video](https://help.aliyun.com/zh/model-studio/happyhorse-image-to-video-api-reference), [Reference-to-video](https://help.aliyun.com/zh/model-studio/happyhorse-reference-to-video-api-reference); this endpoint uses asynchronous video requests with no audio toggle; capabilities and metering assume audio is always enabled
- Audio basis: [Legacy text-to-video](https://help.aliyun.com/zh/model-studio/legacy-wan-text-to-video-api-reference) and [Wan text-to-video](https://help.aliyun.com/zh/model-studio/text-to-video-api-reference) have no `parameters.audio`; [Legacy image-to-video](https://help.aliyun.com/zh/model-studio/legacy-image-to-video-api-reference) provides `parameters.audio` only for wan2.6-i2v-flash, with audio enabled by default
- Pricing: [Model pricing](https://help.aliyun.com/zh/model-studio/model-pricing)
- Code: `lib/custom_provider/endpoints.py::ENDPOINT_REGISTRY["dashscope-video"]`, `lib/backends/video_backends/dashscope.py::DashScopeVideoBackend`
