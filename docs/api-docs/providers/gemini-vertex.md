# gemini-vertex

Media provider for Gemini, Imagen and Veo on Google Vertex AI. Some model documentation is shared with AI Studio, but authentication, endpoints and pricing are separate.

- Main entry: [Generative AI on Vertex AI](https://cloud.google.com/vertex-ai/generative-ai/docs)
- Interfaces and capabilities: [Google Gen AI SDK `generate_content`](https://googleapis.github.io/python-genai/genai.html#genai.models.Models.generate_content), [Generate images with Gemini (Vertex AI mode)](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/image-generation), [Veo video generation API](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/veo-video-generation), [Interactions API](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/capabilities/interactions), [Gemini Omni 1.1 Flash](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/omni-1-1-flash), [Gemini 3.8 Flash TTS](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-8-flash-tts)
- Pricing: [Vertex AI generative AI pricing](https://cloud.google.com/vertex-ai/generative-ai/pricing)
- Description sources (`lib/i18n/<locale>/providers.py` for `provider_desc_gemini-vertex`; describe only the platform, not models or capabilities): [Wikidata: Vertex AI](https://www.wikidata.org/wiki/Q59904785), [Vertex AI name changes](https://docs.cloud.google.com/gemini-enterprise-agent-platform/vertex-ai-name-changes)
- Code: `lib/config/registry.py::PROVIDER_REGISTRY["gemini-vertex"]`, `lib/backends/text_backends/gemini.py::GeminiTextBackend`, `lib/backends/image_backends/gemini.py::GeminiImageBackend`, `lib/backends/video_backends/gemini.py::GeminiVideoBackend`, `lib/backends/video_backends/gemini_interactions.py::VertexInteractionsVideoBackend`, `lib/backends/audio_backends/gemini.py::GeminiAudioBackend`
