# ark

火山方舟标准 `/api/v3` 媒体 provider。

- 总入口：[火山方舟文档](https://www.volcengine.com/docs/82379/?lang=zh)
- 接口与能力：[对话 Chat API](https://api.volcengine.com/api-docs/view?action=ChatCompletions&serviceCode=ark&version=2024-01-01)、[图片生成 API](https://www.volcengine.com/docs/82379/1666946?lang=zh)、[模型列表](https://www.volcengine.com/docs/82379/1330310?lang=zh)、[创建视频生成任务](https://www.volcengine.com/docs/82379/1520757?lang=zh)
- 计费：[火山方舟定价](https://www.volcengine.com/pricing?product=ark_bd&tab=1)、[模型价格](https://www.volcengine.com/docs/82379/1544106)；出厂快照价目表见 `lib/catalog/snapshot/catalog.json`。Seedance 视频按视频 token 计费：结算取回报的 `usage.completion_tokens`，提交前预估按模型价格页公布的公式 (输入视频秒数 + 输出秒数) × 宽 × 高 × 24 / 1024 换算（`ArkVideoBackend.estimate_video_tokens`）
- 下线：[模型下线公告](https://docs.volcengine.com/docs/ark/model-deprecation-notice?lang=zh)
- 简介来源（`lib/i18n/<locale>/providers.py` 的 `provider_desc_ark`，只写平台是什么，不列模型与能力）：[Wikipedia: 火山引擎](https://zh.wikipedia.org/wiki/火山引擎)、[火山方舟发布公告](https://www.volcengine.com/docs/6281/1110759)
- 代码：`lib/config/registry.py::PROVIDER_REGISTRY["ark"]`、`lib/backends/text_backends/ark.py::ArkTextBackend`、`lib/backends/image_backends/ark.py::ArkImageBackend`、`lib/backends/video_backends/ark.py::ArkVideoBackend`（计量：`ArkVideoBackend.metered_usage`）
- 素材库控制面（与推理 `/api/v3` 分开，走 AK/SK 签名的 OpenAPI，服务名 `ark`，版本 `2024-01-01`）：[ListAssets](https://docs.volcengine.com/docs/ark/list-assets-api?lang=zh)、[CreateAsset](https://docs.volcengine.com/docs/ark/create-asset-api?lang=zh)、[GetAsset](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh)（`Status` 为 `Active` / `Processing` / `Failed`，失败时 HTTP 仍为 200、原因在 `Error`）、[CreateAssetGroup](https://docs.volcengine.com/docs/ark/create-asset-group-api?lang=zh)、[ListAssetGroups](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh)、[签名方法](https://docs.volcengine.com/docs/6369/67269)；TOS Python SDK：[快速入门](https://www.volcengine.com/docs/6349/92785)，代码 `lib/object_storage/client.py::ObjectStorageClient`。代码：`lib/asset_library/sites.py::SITES`、`lib/asset_library/control_plane.py`（`list_assets` / `create_asset` / `get_asset` / `ensure_asset_group`）、入库编排 `lib/asset_library/links.py` 与 `lib/asset_library/ingest.py`、`lib/asset_library/bindings.py::resolve_bound_scope`
- 生成时引用素材：[Seedance 人像素材使用指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh) 只给出 Seedance 2.0 / 2.5 在 `content[].image_url.url` 填 `asset://<素材 ID>`、`role: reference_image` 的用法，素材引用可与普通图片混发；首帧、尾帧、1.x 系列与 Seedream 没有说明，不发素材引用。输入图片未通过审核在创建任务时以 400 返回（如 `InputImageSensitiveContentDetected.PrivacyInformation`），错误不带图片下标。是否声明按供应商模型对应的条目认定，不按 API 模型名。代码：`ArkVideoBackend.provider_asset_roles_for_entry`、`lib/backends/provider_assets.py`、`lib/asset_library/generation_inputs.py::choose_reference_image_assets`、`lib/script/reference_video/provider_asset_links.py`
