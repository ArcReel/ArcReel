# ark

火山方舟标准 `/api/v3` 媒体 provider。

- 总入口：[火山方舟文档](https://www.volcengine.com/docs/82379/?lang=zh)
- 接口与能力：[图片生成 API](https://www.volcengine.com/docs/82379/1666946?lang=zh)、文档总入口中的“视频生成 API”与“模型列表”
- 计费：[火山方舟定价](https://www.volcengine.com/pricing?product=ark_bd&tab=1)
- 代码：`lib/config/registry.py::PROVIDER_REGISTRY["ark"]`、`lib/text_backends/ark.py`、`lib/image_backends/ark.py`、`lib/video_backends/ark.py`
