# ark

Volcengine Ark standard `/api/v3` media provider.

- Main entry: [Volcengine Ark documentation](https://www.volcengine.com/docs/82379/?lang=zh)
- Interfaces and capabilities: [Chat API](https://api.volcengine.com/api-docs/view?action=ChatCompletions&serviceCode=ark&version=2024-01-01), [Image generation API](https://www.volcengine.com/docs/82379/1666946?lang=zh), [Model list](https://www.volcengine.com/docs/82379/1330310?lang=zh), [Create a video generation task](https://www.volcengine.com/docs/82379/1520757?lang=zh)
- Pricing: [Volcengine Ark pricing](https://www.volcengine.com/pricing?product=ark_bd&tab=1), [Model pricing](https://www.volcengine.com/docs/82379/1544106); see the factory snapshot price table in `lib/catalog/snapshot/catalog.json`. Seedance video is billed by video tokens: settlement uses reported `usage.completion_tokens`; pre-submit estimates use the model pricing page formula (input video seconds + output seconds) × width × height × 24 / 1024 (`ArkVideoBackend.estimate_video_tokens`)
- Discontinuation: [Model discontinuation notice](https://docs.volcengine.com/docs/ark/model-deprecation-notice?lang=zh)
- Description sources (`lib/i18n/<locale>/providers.py` for `provider_desc_ark`; describe only the platform, not models or capabilities): [Wikipedia: Volcengine](https://zh.wikipedia.org/wiki/火山引擎), [Volcengine Ark launch announcement](https://www.volcengine.com/docs/6281/1110759)
- Code: `lib/config/registry.py::PROVIDER_REGISTRY["ark"]`, `lib/backends/text_backends/ark.py::ArkTextBackend`, `lib/backends/image_backends/ark.py::ArkImageBackend`, `lib/backends/video_backends/ark.py::ArkVideoBackend` (metering: `ArkVideoBackend.metered_usage`)
- Asset-library control plane (separate from inference `/api/v3`, using AK/SK-signed OpenAPI with service name `ark`, version `2024-01-01`)：[ListAssets](https://docs.volcengine.com/docs/ark/list-assets-api?lang=zh), [CreateAsset](https://docs.volcengine.com/docs/ark/create-asset-api?lang=zh), [GetAsset](https://docs.volcengine.com/docs/ark/get-asset-api?lang=zh) (`Status` is `Active` / `Processing` / `Failed`; failures still return HTTP 200, with the reason in `Error`), [CreateAssetGroup](https://docs.volcengine.com/docs/ark/create-asset-group-api?lang=zh), [ListAssetGroups](https://docs.volcengine.com/docs/ark/list-asset-groups-api?lang=zh), [Signing method](https://docs.volcengine.com/docs/6369/67269); TOS Python SDK: [Quick start](https://www.volcengine.com/docs/6349/92785), code `lib/object_storage/client.py::ObjectStorageClient`. Code: `lib/asset_library/sites.py::SITES`, `lib/asset_library/control_plane.py` (`list_assets` / `create_asset` / `get_asset` / `ensure_asset_group`), ingestion orchestration `lib/asset_library/links.py`  and  `lib/asset_library/ingest.py`, `lib/asset_library/bindings.py::resolve_bound_scope`
- Provider asset references during generation: [Seedance portrait asset guide](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh) documents only Seedance 2.0 / 2.5 using `content[].image_url.url` set to `asset://<素材 ID>`, `role: reference_image`. Asset references may accompany ordinary images. First-frame, last-frame, 1.x and Seedream usage is undocumented, so no asset references are sent for them. Input-image moderation failures return 400 at task creation (such as `InputImageSensitiveContentDetected.PrivacyInformation`); errors contain no image index. The attached endpoint determines whether the provider model declares support (`ark-seedance-2`, `ark-seedance-2-5` declare it; `ark-seedance-1` does not), rather than the model name. Code: `ArkVideoBackend.provider_asset_roles`, `lib/backends/video_backends/ark.py::SeedanceEndpoint`, `lib/backends/provider_assets.py`, `lib/asset_library/generation_inputs.py::choose_reference_image_assets`, `lib/script/reference_video/provider_asset_links.py`
